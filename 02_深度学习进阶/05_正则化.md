# 2.4 正则化（Regularization）

> **一句话**：防止网络"死记硬背"训练数据，让它学会"举一反三"。

---

## 一、过拟合问题

### 1.1 什么是过拟合？

```
训练集准确率：99%  ← 很好！
测试集准确率：60%  ← 很差！

这个模型"背住"了训练数据，但不会泛化。
```

就像一个学生：
- 把课本上的例题全部背下来了（训练集 99%）
- 但考试时题目稍有变化就不会做了（测试集 60%）

### 1.2 过拟合的本质

**为什么会出现过拟合？**

```
模型复杂度 vs 数据量

假设我们有 10 个数据点，用 9 次多项式拟合：

  y = w₀ + w₁x + w₂x² + ... + w₉x⁹

这个多项式有 10 个参数，刚好可以完美穿过 10 个点：
  → 训练误差 = 0
  → 但曲线在数据点之间剧烈震荡
  → 新数据点来了，预测很差
```

**数学解释：偏差-方差权衡**

```
期望误差 = 偏差² + 方差 + 噪声

偏差（Bias）：
  模型预测的期望值与真实值的差距
  → 模型太简单 → 偏差高（欠拟合）

方差（Variance）：
  模型预测的波动程度
  → 模型太复杂 → 方差高（过拟合）
```

**生活类比：考试复习**

```
偏差高（欠拟合）：
  学生只看了一遍课本，什么都没记住
  → 训练集考不好，测试集也考不好

方差高（过拟合）：
  学生把所有例题都背下来了
  → 训练集考得很好，但题目稍有变化就不会

刚刚好（泛化）：
  学生理解了原理，能举一反三
  → 训练集考得好，测试集也考得好
```

### 1.3 过拟合的信号

```
epoch 10:  train_loss=0.5,  val_loss=0.6   ✓ 正常
epoch 50:  train_loss=0.2,  val_loss=0.3   ✓ 正常
epoch 100: train_loss=0.05, val_loss=0.4   ⚠ val_loss 开始上升！
epoch 200: train_loss=0.01, val_loss=0.8   ✗ 过拟合了！
```

**关键指标**：val_loss 开始上升，而 train_loss 还在下降 → 过拟合。

**为什么会这样？**

```
训练时，模型在优化 train_loss
  → train_loss 一直在下降

但当模型开始"记忆"训练数据时：
  → train_loss 继续下降（因为记忆更精确了）
  → val_loss 开始上升（因为记忆的模式不适用于新数据）
```

## 二、正则化的本质定义

### 2.1 什么是正则化？

**正则化 = 任何减少模型泛化误差（而非训练误差）的技术**

```
训练误差：模型在训练集上的表现
泛化误差：模型在新数据上的表现

正则化的目标：不是让训练误差更低，而是让泛化误差更低
```

**生活类比：考试**

```
没有正则化：
  学生把课本例题全背下来了
  → 课本例题考得很好（训练误差低）
  → 考试遇到新题就不会（泛化误差高）

有正则化：
  学生理解了原理，能举一反三
  → 课本例题考得不错（训练误差略高）
  → 考试遇到新题也会做（泛化误差低）
```

### 2.2 正则化的统一视角

所有正则化方法的核心思想都是**约束模型的复杂度**：

```
┌─────────────────────────────────────────────────────────┐
│                    正则化方法                             │
├─────────────────────────────────────────────────────────┤
│  损失函数约束：L1、L2 正则化                              │
│    → 在损失函数中加入惩罚项，让权重变小                    │
├─────────────────────────────────────────────────────────┤
│  结构约束：Dropout                                       │
│    → 随机丢弃神经元，减少共适应                           │
├─────────────────────────────────────────────────────────┤
│  训练约束：Early Stopping                                │
│    → 在过拟合前停止训练                                   │
├─────────────────────────────────────────────────────────┤
│  数据约束：数据增强                                       │
│    → 增加数据多样性，防止记忆                             │
└─────────────────────────────────────────────────────────┘
```

### 2.3 为什么数据增强是正则化？

**数据增强通过增加数据多样性来约束模型的复杂度：**

```
原始训练集：{(x₁, y₁), ..., (xₙ, yₙ)}
增强后训练集：{(x₁₁, y₁), (x₁₂, y₁), ..., (xₙ₁, yₙ), (xₙ₂, yₙ), ...}

每次训练看到的都是"略有不同"的同一张图片
  → 模型不能简单地"记忆"原始数据
  → 模型学会了对变换不敏感的特征
  → 这些特征更可能在新数据上有效
```

**数学视角：**

```
数据增强相当于在数据空间中"平滑"了决策边界

原始数据：只有 10 个点，模型可以画一条复杂的曲线穿过所有点
增强后：100 个点（每个点变出 10 个变体），曲线必须更平滑才能穿过大多数点

→ 平滑的曲线 → 对新数据泛化更好
```

**生活类比：**

```
没有数据增强：
  学生只需要背 10 道例题 → 考试遇到新题就不会

有数据增强：
  学生需要做 100 道题（10 道例题的变化版本）→ 必须理解原理 → 考试会做新题
```

### 2.4 正则化的贝叶斯视角

从贝叶斯角度看，正则化相当于**引入先验知识**：

```
L2 正则化 ≈ 假设权重服从高斯先验 N(0, 1/λ)
  → 权重应该集中在 0 附近

L1 正则化 ≈ 假设权重服从拉普拉斯先验
  → 权重应该很多为 0

数据增强 ≈ 假设数据具有平移、旋转不变性
  → 猫的图片旋转后还是猫

Dropout ≈ 假设特征应该独立学习
  → 不应该依赖特定的神经元组合
```

## 三、L2 正则化（权重衰减）

### 3.1 核心思想

在损失函数中加入**惩罚项**，惩罚大的权重：

```
原始损失：L_original = (1/n) Σ(yᵢ - ŷᵢ)²

L2 正则化损失：L = L_original + (λ/2) Σwⱼ²
                        ↑ 惩罚项
```

**wⱼ 是什么？**

```
wⱼ = 神经网络中的权重参数（weight）

例如，一个简单的神经元：
  输入：x = [x₁, x₂, x₃]
  权重：w = [w₁, w₂, w₃]
  偏置：b
  
  输出：z = w₁·x₁ + w₂·x₂ + w₃·x₃ + b

这里的 w₁, w₂, w₃ 就是 wⱼ（j = 1, 2, 3）
```

**Σwⱼ² 是什么？**

```
Σwⱼ² = w₁² + w₂² + w₃² + ... + wₙ²
       ↑
       所有权重参数的平方和

一个网络可能有成千上万个权重：
  第 1 层：w₁, w₂, ..., w₁₀₀
  第 2 层：w₁₀₁, w₁₀₂, ..., w₂₀₀
  ...
  
Σwⱼ² = 所有这些权重的平方和
```

**为什么惩罚大权重？**

```
大权重 → 模型对输入敏感 → 输入的小变化导致输出的大变化 → 过拟合

小权重 → 模型对输入不敏感 → 输入的小变化不会导致输出的大变化 → 泛化好
```

**生活类比：考试复习**

```
没有正则化：
  学生把每个例题的每个细节都记住了
  → 例题稍微变化就不会做

有正则化：
  学生只记住了主要规律，忽略了细节
  → 例题变化了也能做对
```

### 3.2 数学推导

**为什么叫"权重衰减"？**

```
∂L/∂wⱼ = ∂L_original/∂wⱼ + λ·wⱼ

更新规则：
wⱼ = wⱼ - lr · (∂L_original/∂wⱼ + λ·wⱼ)
   = wⱼ - lr · ∂L_original/∂wⱼ - lr·λ·wⱼ
   = (1 - lr·λ) · wⱼ - lr · ∂L_original/∂wⱼ
     ↑
     每次更新，权重先乘以一个小于1的数
```

**具体例子：**

```
假设 lr=0.01, λ=0.1

wⱼ = (1 - 0.01×0.1) · wⱼ - 0.01 · ∂L_original/∂wⱼ
   = 0.999 · wⱼ - 0.01 · ∂L_original/∂wⱼ

每次更新，权重先乘以 0.999
  → 权重会不断"衰减"
  → 直到找到一个平衡点（梯度推大 ↔ 衰减推小）
```

### 3.3 直觉理解

```
没有正则化：
  w₁ = 10, w₂ = -8, w₃ = 15, w₄ = -12
  → 大权重 → 模型复杂 → 容易过拟合

有 L2 正则化：
  w₁ = 2, w₂ = -1.5, w₃ = 2.5, w₄ = -1.8
  → 小权重 → 模型简单 → 泛化更好
```

**为什么小权重更好？**

```
假设输入 x = [1, 2, 3, 4]

大权重：w = [10, -8, 15, -12]
  z = 10×1 + (-8)×2 + 15×3 + (-12)×4 = 10 - 16 + 45 - 48 = -9
  如果 x₁ 变化 0.1：z 变化 10×0.1 = 1

小权重：w = [2, -1.5, 2.5, -1.8]
  z = 2×1 + (-1.5)×2 + 2.5×3 + (-1.8)×4 = 2 - 3 + 7.5 - 7.2 = -0.7
  如果 x₁ 变化 0.1：z 变化 2×0.1 = 0.2

大权重：输入的小变化导致输出的大变化
小权重：输入的小变化导致输出的小变化
```

### 3.4 λ 的作用

```
λ = 0:    没有正则化（原始损失）
λ = 0.01: 轻度正则化
λ = 0.1:  中度正则化
λ = 1.0:  强正则化（权重很小）
```

**λ 太大的问题：**

```
如果 λ 非常大，惩罚项会主导损失函数
  → 模型只关心让权重变小，不关心拟合数据
  → 欠拟合

就像学生：
  λ 太大：只记住了"不要太依赖细节"，但什么都没学会
  λ 太小：把所有细节都记住了，过拟合
  λ 刚好：学会了主要规律，忽略不重要的细节
```

### 3.5 PyTorch 实现

```python
# PyTorch 中使用 L2 正则化
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, weight_decay=0.001)
#                                                ↑ L2 正则化系数 λ
```

**注意**：PyTorch 的 `weight_decay` 就是 L2 正则化的 λ。

## 四、L1 正则化

### 4.1 核心思想

```
L1 正则化损失：L = L_original + λ Σ|wⱼ|
```

**与 L2 的区别：**

```
L2 惩罚：λ/2 · Σwⱼ²  →  权重变小
L1 惩罚：λ · Σ|wⱼ|   →  权重变稀疏（很多变为 0）
```

### 4.2 数学推导

**L1 的梯度：**

```
∂L/∂wⱼ = ∂L_original/∂wⱼ + λ · sign(wⱼ)

其中 sign(wⱼ) 是符号函数：
  sign(wⱼ) = +1  如果 wⱼ > 0
  sign(wⱼ) = -1  如果 wⱼ < 0
  sign(wⱼ) = 0   如果 wⱼ = 0
```

**L2 的梯度：**

```
∂L/∂wⱼ = ∂L_original/∂wⱼ + λ · wⱼ
```

**关键区别：**

```
L1 的梯度：λ · sign(wⱼ)
  → 不管 wⱼ 多小，梯度都是 λ（常数）
  → 小权重也会被"推"到 0

L2 的梯度：λ · wⱼ
  → wⱼ 越小，梯度越小
  → 小权重几乎不动（停在接近 0 的位置，但不是 0）
```

### 4.3 为什么 L1 产生稀疏？

**直觉解释：**

```
L1 的梯度是常数 λ，不管 wⱼ 多小：
  wⱼ = 0.1 时，梯度 = λ
  wⱼ = 0.01 时，梯度 = λ
  wⱼ = 0.001 时，梯度 = λ

→ 小权重会被"推"到 0
→ 大权重也会被"推"，但需要更多步

L2 的梯度是 λ·wⱼ，与 wⱼ 成正比：
  wⱼ = 0.1 时，梯度 = 0.1λ
  wⱼ = 0.01 时，梯度 = 0.01λ
  wⱼ = 0.001 时，梯度 = 0.001λ

→ 小权重几乎不动（停在接近 0 的位置，但不是 0）
→ 大权重被强力推小
```

**几何解释：**

```
L1 的约束区域是菱形（|w₁| + |w₂| ≤ C）
L2 的约束区域是圆形（w₁² + w₂² ≤ C）

损失函数的等高线是椭圆形

L1：等高线与菱形的交点往往在顶点上（w₁=0 或 w₂=0）
L2：等高线与圆形的交点通常不在坐标轴上

→ L1 产生稀疏解，L2 不产生稀疏解
```

```
  L1 约束（菱形）         L2 约束（圆形）
      w₂                      w₂
      |                        |
      /\                       /\
     /  \                     /  \
    /    \                   /    \
---/------\---→ w₁      ---/------\---→ w₁
    \    /                   \    /
     \  /                     \  /
      \/                       \/
      
  等高线与菱形顶点相交     等高线与圆形相交
  → w₁=0 或 w₂=0          → w₁,w₂ 都不为 0
```

### 4.4 L1 vs L2 对比

| 特性 | L1 | L2 |
|------|----|----|
| 惩罚项 | λ·Σ\|wⱼ\| | (λ/2)·Σwⱼ² |
| 梯度 | λ·sign(wⱼ) | λ·wⱼ |
| 效果 | 权重变稀疏（很多变为 0） | 权重变小（接近 0 但不等于 0） |
| 用途 | 特征选择 | 防止过拟合 |
| 计算 | 不可导（在 w=0 处） | 处处可导 |

**什么时候用 L1？**

```
当你想进行特征选择时：
  → L1 会让不重要的特征权重变为 0
  → 相当于自动选择了重要特征

例如：
  输入特征：[年龄, 收入, 邮编, 身高, 体重]
  L1 正则化后：[0.8, 0.5, 0, 0.3, 0.1]
  → 邮编的权重为 0，说明邮编对预测没有帮助
```

### 4.5 PyTorch 实现

```python
# PyTorch 中使用 L1 正则化（需要手动实现）
def l1_regularization(model, lambda_l1=0.001):
    l1_loss = 0
    for param in model.parameters():
        l1_loss += torch.sum(torch.abs(param))
    return lambda_l1 * l1_loss

# 在训练循环中
loss = criterion(output, target) + l1_regularization(model)
```

**注意**：PyTorch 的 `weight_decay` 只支持 L2，L1 需要手动实现。

## 五、Dropout

### 5.1 核心思想

训练时，**随机**把一些神经元的输出变成 0：

```
训练时（dropout=0.5）：
  原始：[0.5, 0.8, 0.3, 0.9, 0.1]
  之后：[0.5, 0.0, 0.3, 0.0, 0.1]  # 50%概率丢弃
```

**问题：训练和测试的输出不一致！**

```
假设 dropout=0.5，原始输出 h = [1, 2, 3, 4, 5]

训练时（一半被丢弃）：
  [1, 0, 3, 0, 5]
  期望输出 = (1+0+3+0+5)/5 = 1.8

测试时（不丢弃）：
  [1, 2, 3, 4, 5]
  期望输出 = (1+2+3+4+5)/5 = 3.0

问题：训练时输出小，测试时输出大！
```

**解决方案：缩放补偿**

```
方案一：训练时补偿（PyTorch 采用）
  保留的神经元输出 ÷ (1-p) = ÷ 0.5 = × 2
  [1, 0, 3, 0, 5] → [2, 0, 6, 0, 10]
  期望输出 = (2+0+6+0+10)/5 = 3.6 ≈ 3.0 ✓

方案二：测试时补偿（文档示例）
  所有输出 × (1-p) = × 0.5
  [0.5, 0.8, 0.3, 0.9, 0.1] → [0.25, 0.4, 0.15, 0.45, 0.05]
  期望输出 ≈ 原始输出的一半
```

**PyTorch 的做法（inverted dropout）：**

```python
# 训练时：自动补偿
self.dropout = nn.Dropout(p=0.5)
output = dropout(input)  # 保留的输出自动 ÷ (1-p)

# 测试时：不需要补偿
output = input
```

### 5.2 为什么有效？

**直觉1：集成学习**

```
每次前向传播都是一次"子网络"：

原始网络有 n 个神经元
  → 有 2ⁿ 个可能的子网络
  → Dropout 相当于训练了所有这些子网络的"平均"

就像考试：
  没有 Dropout：一个学生答题
  有 Dropout：2ⁿ 个学生分别答题，取平均
  → 平均答案更可靠
```

**直觉2：减少共适应**

```
没有 Dropout：
  神经元 A 和 B 可能会"共谋"：
    A 负责特征1，B 负责特征2
    → 如果 A 坏了，B 也跟着坏
    → 模型脆弱

有 Dropout：
  A 随时可能被丢弃，B 必须独立工作
  → 每个神经元都学到有用的特征
  → 模型鲁棒
```

**生活类比：团队合作**

```
没有 Dropout：
  团队中每个人只负责自己的部分
  → 如果有人请假，整个项目就停了

有 Dropout：
  每个人都要了解整个项目
  → 随时有人请假，项目也能继续
  → 团队更鲁棒
```

### 5.3 数学表示

```
训练时：
  rⱼ ~ Bernoulli(1-p)  # 每个神经元以概率 p 被丢弃
  h̃ⱼ = rⱼ · hⱼ         # 被丢弃的输出为 0
  y = W · h̃ / (1-p)     # 缩放补偿（inverted dropout）

测试时：
  y = W · h              # 不丢弃，不缩放
```

**为什么要缩放补偿？**

```
假设 dropout=0.5，隐藏层输出 h = [1, 2, 3, 4]

训练时（平均）：
  一半被丢弃，剩下的一半要乘以 2 来补偿
  E[h̃] = 0.5 × 0 + 0.5 × 2h = h

测试时：
  不丢弃，不缩放
  E[h] = h

→ 训练和测试的期望输出一致
```

### 5.4 注意事项

```
1. Dropout 通常加在隐藏层，不加在输出层
2. 测试时必须关闭 Dropout（model.eval()）
3. p 一般取 0.2~0.5
4. 如果网络已经很小，可以不加 Dropout
5. CNN 中常用 Dropout2d（丢弃整个通道）
6. Dropout 通常加在全连接层，不加在卷积层
```

### 5.5 PyTorch 实现

```python
import torch.nn as nn

class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)
        self.dropout = nn.Dropout(p=0.5)  # 50% 概率丢弃
        self.fc2 = nn.Linear(256, 10)
    
    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = self.dropout(x)  # 训练时随机丢弃
        x = self.fc2(x)
        return x

# 训练时
model.train()  # 开启 Dropout
output = model(x)

# 测试时
model.eval()  # 关闭 Dropout
output = model(x)
```

## 六、Early Stopping

### 6.1 核心思想

**在过拟合发生前停止训练**：

```
epoch 1:   val_loss=1.0
epoch 10:  val_loss=0.5
epoch 20:  val_loss=0.3   ← 最佳！保存这个模型
epoch 30:  val_loss=0.35  ← 开始上升了，停止！
epoch 40:  val_loss=0.5
```

### 6.2 实现方法

```
记录验证集损失：
- 如果当前损失 < 历史最佳 → 更新最佳，保存模型
- 如果当前损失 ≥ 历史最佳 → 计数器+1
- 如果计数器达到 patience → 停止训练
```

**patience 参数：**

```
patience = 5：如果连续 5 个 epoch val_loss 都没有下降，就停止

太小：可能过早停止（还没学到最佳）
太大：可能已经过拟合了才停止
```

### 6.3 为什么有效？

**数学解释：**

```
训练时，模型在优化 train_loss
  → train_loss 一直在下降

但 val_loss 会先下降后上升
  → 下降阶段：模型在学习有用的模式
  → 上升阶段：模型在记忆训练数据的噪声

Early Stopping 在 val_loss 最低点停止
  → 模型学到了有用的模式
  → 还没开始记忆噪声
```

**生活类比：考试复习**

```
没有 Early Stopping：
  学生一直复习到考试前一秒
  → 可能复习过度，把不重要的细节也记住了

有 Early Stopping：
  学生在感觉自己"学得最好"的时候停止复习
  → 保持最佳状态去考试
```

### 6.4 PyTorch 实现

```python
class EarlyStopping:
    def __init__(self, patience=5, min_delta=0.001):
        self.patience = patience
        self.min_delta = min_delta
        self.counter = 0
        self.best_loss = None
        self.best_model = None
    
    def __call__(self, val_loss, model):
        if self.best_loss is None:
            self.best_loss = val_loss
            self.best_model = model.state_dict().copy()
        elif val_loss < self.best_loss - self.min_delta:
            # 损失下降超过 min_delta，更新最佳
            self.best_loss = val_loss
            self.best_model = model.state_dict().copy()
            self.counter = 0
        else:
            # 损失没有明显下降
            self.counter += 1
            if self.counter >= self.patience:
                return True  # 停止训练
        return False

# 使用
early_stopping = EarlyStopping(patience=5)

for epoch in range(100):
    train_loss = train(model)
    val_loss = validate(model)
    
    if early_stopping(val_loss, model):
        print(f"Early stopping at epoch {epoch}")
        break

# 恢复最佳模型
model.load_state_dict(early_stopping.best_model)
```

## 七、数据增强

### 7.1 核心思想

**人工增加训练数据的多样性**：

```
原始图片：🐱（猫）
增强后：
  - 旋转 10°：🐱（稍微歪一点）
  - 翻转：🐱（镜像）
  - 裁剪：🐱（只看脸）
  - 调亮度：🐱（亮一点/暗一点）
  - 加噪声：🐱（模糊一点）
```

### 7.2 为什么有效？

**数学解释：**

```
假设真实数据分布是 P(x, y)
我们只有有限的训练样本 {(x₁, y₁), ..., (xₙ, yₙ)}

数据增强相当于：
  从 xᵢ 生成多个变体 {xᵢ₁, xᵢ₂, ...}
  → 增加了训练样本数量
  → 更好地覆盖了数据分布 P(x, y)
```

**生活类比：考试复习**

```
没有数据增强：
  学生只做了 10 道例题
  → 考试时遇到新题目就不会做

有数据增强：
  学生把每道例题变化出 5 个版本
  → 做了 50 道题
  → 考试时遇到新题目也会做
```

### 7.3 常见的增强方法

**图像增强：**

```
几何变换：
  - 旋转（rotation）
  - 翻转（flip）
  - 裁剪（crop）
  - 缩放（scale）
  - 平移（translation）

颜色变换：
  - 亮度（brightness）
  - 对比度（contrast）
  - 饱和度（saturation）
  - 色调（hue）

噪声：
  - 高斯噪声（Gaussian noise）
  - 椒盐噪声（salt-and-pepper noise）
```

**文本增强：**

```
- 同义词替换
- 随机插入
- 随机删除
- 回译（back translation）
```

### 7.4 注意事项

```
1. 增强要合理：
   - 猫的图片可以翻转，但数字 "6" 翻转后变成 "9"
   - 医学图像不能随意增强

2. 增强不要太强：
   - 太强的增强会破坏原始信息
   - 例如：旋转 180° 可能把 "6" 变成 "9"

3. 测试时不要增强：
   - 训练时增强，测试时用原始数据
```

### 7.5 PyTorch 实现

```python
from torchvision import transforms

# 训练时的数据增强
train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),  # 随机水平翻转
    transforms.RandomRotation(10),      # 随机旋转 ±10°
    transforms.RandomCrop(32, padding=4),  # 随机裁剪
    transforms.ColorJitter(brightness=0.2, contrast=0.2),  # 颜色变换
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])

# 测试时不要增强
test_transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])

# 使用
train_dataset = MNIST(root='./data', train=True, transform=train_transform)
test_dataset = MNIST(root='./data', train=False, transform=test_transform)
```

## 八、本节小结

| 方法 | 原理 | 效果 | 适用场景 |
|------|------|------|----------|
| L2 正则化 | 惩罚大权重 | 权重变小，泛化更好 | 通用 |
| L1 正则化 | 产生稀疏权重 | 特征选择 | 特征多但有用特征少 |
| Dropout | 随机丢弃神经元 | 集成学习效果 | 全连接层 |
| Early Stopping | val_loss 不降就停 | 防止过拟合 | 通用 |
| 数据增强 | 增加数据多样性 | 提高泛化能力 | 数据少 |

**如何选择？**

```
数据少：数据增强 + Early Stopping
特征多：L1 正则化（特征选择）
通用：L2 正则化 + Dropout + Early Stopping
```
