## 一、项目概述

### 1.1 什么是 MNIST？

```
MNIST：Modified National Institute of Standards and Technology

- 60,000 张训练图片 + 10,000 张测试图片
- 每张图片：28×28 像素，灰度图
- 标签：0-9 的数字
- 被称为"深度学习的 Hello World"
```

### 1.2 项目目标

```
输入：一张手写数字图片（28×28）
输出：这是哪个数字（0-9）

目标准确率：> 98%
```

## 三、数据预处理

### 3.1 归一化

```
原始像素值：0 ~ 255（整数）

第一步：转为 Tensor，值域变为 [0, 1]
  x = pixel / 255.0

第二步：标准化（使均值为0，标准差为1）
  x = (x - mean) / std

MNIST 的统计值：
  mean = 0.1307
  std = 0.3081
```

### 3.2 为什么要归一化？

```
不归一化：
  像素值范围 [0, 255]
  → 梯度很大 → 训练不稳定

归一化后：
  像素值范围 [-1, 1]
  → 梯度适中 → 训练稳定
```

## 四、模型选择

### 4.1 MLP vs CNN

| 特性 | MLP | CNN |
|------|-----|-----|
| 输入 | 展平为一维向量 | 保持二维结构 |
| 参数量 | 多（全连接） | 少（局部连接+权值共享） |
| 空间信息 | 丢失 | 保留 |
| 准确率 | ~97% | ~99% |
| 训练速度 | 快 | 慢一点 |

### 4.2 推荐结构

**简单任务（如 MNIST）**：
```
Conv(1→32, 3×3) → ReLU → MaxPool
Conv(32→64, 3×3) → ReLU → MaxPool
Flatten → Linear→ReLU→Dropout→Linear
```

**复杂任务（如 CIFAR-10）**：
```
更多卷积层 + BatchNorm + 数据增强
```

## 五、训练策略

### 5.1 损失函数

**交叉熵损失（CrossEntropyLoss）**：

```
对于分类任务，交叉熵衡量预测概率分布与真实标签的差异：

L = -Σ yᵢ · log(ŷᵢ)

其中：
  yᵢ = 1 如果是类别 i（one-hot）
  ŷᵢ = 模型预测的概率
```

### 5.2 优化器

**Adam（推荐）**：

```
lr = 0.001（默认）
betas = (0.9, 0.999)
weight_decay = 0（可选 L2 正则化）
```

### 5.3 学习率调度

```
方法：阶梯衰减
  前 5 个 epoch：lr = 0.001
  第 6-10 个 epoch：lr = 0.0005
  第 11-15 个 epoch：lr = 0.00025
  ...
```

### 5.4 早停（Early Stopping）

```
patience = 5
如果验证集损失连续 5 个 epoch 没有改善，停止训练
```

## 六、评估指标

### 6.1 准确率（Accuracy）

```
准确率 = 正确预测数 / 总样本数

例如：9920 / 10000 = 99.2%
```

### 6.2 混淆矩阵

```
         预测 0  预测 1  预测 2 ...
真实 0  [  978     1      0   ...]
真实 1  [    0  1130      2   ...]
真实 2  [    1     1   1028   ...]
...
```

### 6.3 错误分析

查看模型在哪些数字上犯错最多：
- 4 和 9 容易混淆
- 3 和 8 容易混淆
- 这些通常是书写相似的数字
