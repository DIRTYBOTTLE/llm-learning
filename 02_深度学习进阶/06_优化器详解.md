# 2.5 优化器详解（Optimizers）

> **一句话**：梯度告诉我们方向，优化器决定走多快、怎么走。

---

## 一、回顾：梯度下降

### 1.1 基本公式

```
θ = θ - lr · ∂L/∂θ
  ↑      ↑      ↑
参数   学习率   梯度
```

**问题**：学习率怎么选？太大震荡，太小太慢。

### 1.2 学习率的困境

```
lr = 0.01:  收敛太慢（1000步才到）
lr = 0.1:   快但震荡
lr = 1.0:   直接发散！
```

---

## 二、SGD + Momentum

### 2.1 动量（Momentum）

**直觉**：像球滚下山坡，有惯性。

```
普通 SGD：只看当前梯度
Momentum：累积历史梯度
```

### 2.2 数学公式

```
vₜ = β · vₜ₋₁ + ∂L/∂θ        # 速度 = β × 历史速度 + 当前梯度
θ  = θ - lr · vₜ              # 参数 = 参数 - lr × 速度
```

其中 β 通常取 0.9。

### 2.3 为什么有效？

```
场景：梯度方向一致（应该加速）
  普通 SGD：每步走 lr
  Momentum：累积后走 2lr, 3lr, ...（加速！）

场景：梯度方向震荡（应该减速）
  普通 SGD：来回跳
  Momentum：正负抵消，走直线
```

## 三、AdaGrad

### 3.1 核心思想

**自适应学习率**：频繁更新的参数用小学习率，稀疏更新的参数用大学习率。

### 3.2 数学公式

```
Gₜ = Gₜ₋₁ + (∂L/∂θ)²          # 累积梯度平方和
θ  = θ - lr · (∂L/∂θ) / (√Gₜ + ε)  # 除以累积梯度的平方根
```

### 3.3 直觉

```
经常更新的参数（如"的"、"是"）：
  G 很大 → 分母大 → 有效学习率小 ✓

很少更新的参数（如"量子力学"）：
  G 很小 → 分母小 → 有效学习率大 ✓
```

### 3.4 缺点

**学习率会单调递减到 0！**

```
Gₜ 只增不减 → √Gₜ 越来越大 → 有效学习率越来越小 → 训练停滞
```

---

## 四、RMSProp

### 4.1 核心思想

**修复 AdaGrad 的学习率衰减问题**：用指数移动平均代替累积和。

### 4.2 数学公式

```
vₜ = β · vₜ₋₁ + (1-β) · (∂L/∂θ)²   # 指数移动平均
θ  = θ - lr · (∂L/∂θ) / (√vₜ + ε)
```

β 通常取 0.999。

### 4.3 对比

```
AdaGrad：G = G + g²  （累积，只增不减）
RMSProp：v = 0.9·v + 0.1·g²  （移动平均，可以减小）
```

---

## 五、Adam（推荐）

### 5.1 核心思想

**结合 Momentum + RMSProp**：

- 用一阶矩（均值）估计方向（像 Momentum）
- 用二阶矩（方差）自适应学习率（像 RMSProp）

### 5.2 完整数学推导

```
Step 1: 计算一阶矩（均值）和二阶矩（方差）
  mₜ = β₁ · mₜ₋₁ + (1-β₁) · gₜ        # 一阶矩：梯度的均值
  vₜ = β₂ · vₜ₋₁ + (1-β₂) · gₜ²       # 二阶矩：梯度平方的均值

  其中 gₜ = ∂L/∂θ

Step 2: 偏差修正（解决初始化为0的问题）
  m̂ₜ = mₜ / (1 - β₁ᵗ)                   # 修正一阶矩
  v̂ₜ = vₜ / (1 - β₂ᵗ)                   # 修正二阶矩

Step 3: 更新参数
  θ = θ - lr · m̂ₜ / (√v̂ₜ + ε)
```

### 5.3 偏差修正的原因

```
初始化时 m₀ = 0, v₀ = 0

Step 1: m₁ = β₁·0 + (1-β₁)·g₁ = (1-β₁)·g₁
  → m₁ 被低估了！因为 β₁ 通常取 0.9
  → m₁ ≈ 0.1·g₁（只有真实值的 10%）

Step 2: m̂₁ = m₁ / (1-β₁¹) = m₁ / 0.1 = 10·m₁ = g₁
  → 修正后等于真实值！
```

### 5.4 默认超参数

```
β₁ = 0.9     # 一阶矩衰减率（Momentum）
β₂ = 0.999   # 二阶矩衰减率（RMSProp）
ε  = 1e-8    # 防止除以零
lr = 0.001   # 默认学习率
```

### 5.5 为什么 Adam 是默认选择？

```
SGD：需要调学习率和 momentum，但泛化可能更好
Adam：调参简单，收敛快，适合大多数场景
```

**但注意**：在某些任务上，SGD + Momentum 的最终性能可能比 Adam 更好。

## 六、其他优化器

### 6.1 AdamW（Adam + 解耦权重衰减）

```
Adam 的 weight_decay 实现有问题（与 L2 不等价）
AdamW 修正了这个问题
```

### 6.2 学习率调度

**随着训练进行，逐渐降低学习率**：

```
方法1：阶梯衰减
  每 30 个 epoch，学习率 × 0.1

方法2：余弦退火
  lr = lr_min + 0.5·(lr_max - lr_min)·(1 + cos(π·t/T))

方法3：Warmup
  训练初期慢慢增大学习率（前几个 epoch）
```

## 七、对比总结

| 优化器 | 学习率 | 动量 | 自适应 | 适用场景 |
|--------|--------|------|--------|----------|
| SGD | 固定 | × | × | 简单任务，需要调参 |
| SGD+Momentum | 固定 | ✓ | × | 经典选择，泛化好 |
| AdaGrad | 自适应 | × | ✓ | 稀疏数据（NLP） |
| RMSProp | 自适应 | × | ✓ | RNN |
| **Adam** | **自适应** | **✓** | **✓** | **默认推荐** |
| AdamW | 自适应 | ✓ | ✓ | 需要正则化时 |

## 八、本节小结

| 要点 | 内容 |
|------|------|
| Momentum | 累积梯度，加速收敛 |
| AdaGrad | 自适应学习率，但会衰减到0 |
| RMSProp | 用移动平均修复 AdaGrad |
| Adam | Momentum + RMSProp，默认推荐 |
| 学习率调度 | 随训练降低学习率 |
