# 2.2 权重初始化（Weight Initialization）

> **一句话**：网络开始训练前，权重的初始值决定了训练能否成功。

---

## 一、为什么初始化很重要？

### 1.1 全零初始化：对称性陷阱

如果所有权重都初始化为 0：

```
h₁ = ReLU(0·x₁ + 0·x₂ + 0·x₃ + 0) = 0
h₂ = ReLU(0·x₁ + 0·x₂ + 0·x₃ + 0) = 0
h₃ = ReLU(0·x₁ + 0·x₂ + 0·x₃ + 0) = 0
h₄ = ReLU(0·x₁ + 0·x₂ + 0·x₃ + 0) = 0
```

**所有神经元完全一样，梯度也一样，永远无法区分。**

就像让4个学生做同一道题，但不给他们任何不同的思路，他们永远只会给出同一个答案。

### 1.2 随机初始化：尺度问题

随机初始化打破了对称性，但**方差（尺度）很关键**！

---

## 二、尺度问题：消失与爆炸

先理解一个核心概念：**反向传播时，梯度要从后往前逐层连乘**。

```
网络结构：输入 x → 第1层 → 第2层 → 第3层 → 损失 L

反向传播计算梯度时：
  第3层梯度 = ∂L/∂h₃ × W₃
  第2层梯度 = 第3层梯度 × W₂
  第1层梯度 = 第2层梯度 × W₁

如果每层的梯度都乘以一个小于1的数 → 连乘后变得极小（消失）
如果每层的梯度都乘以一个大于1的数 → 连乘后变得极大（爆炸）
```

---

### 2.1 梯度消失：一步步算给你看

**场景**：Sigmoid 激活函数，权重太小（σ = 0.01）

**Sigmoid 的导数特点**：σ'(z) 最大只有 0.25

```
σ'(z) = σ(z) × (1 - σ(z))

当 σ(z) = 0.5 时，σ'(z) = 0.5 × 0.5 = 0.25（最大值）
当 σ(z) = 0.9 时，σ'(z) = 0.9 × 0.1 = 0.09
当 σ(z) = 0.1 时，σ'(z) = 0.1 × 0.9 = 0.09
```

**现在看一个3层网络的梯度计算**：

```
假设输入 x = 1，权重 W = 0.01，激活函数是 Sigmoid

前向传播（从前往后算）：
  第1层：z₁ = W·x = 0.01×1 = 0.01
         h₁ = sigmoid(0.01) = 0.5025

  第2层：z₂ = W·h₁ = 0.01×0.5025 = 0.005025
         h₂ = sigmoid(0.005025) = 0.5013

  第3层：z₃ = W·h₂ = 0.01×0.5013 = 0.005013
         h₃ = sigmoid(0.005013) = 0.5013

发现了吗？h₁ ≈ h₂ ≈ h₃ ≈ 0.5，几乎没变化！
```

**反向传播（从后往前算梯度）**：

先理解链式法则。假设网络结构：

```
x → [第1层] → h₁ → [第2层] → h₂ → [第3层] → h₃ → L
     z₁=W·x        z₂=W·h₁        z₃=W·h₂
     h₁=σ(z₁)      h₂=σ(z₂)      h₃=σ(z₃)
```

要算 ∂L/∂W₁（第1层权重的梯度），需要链式法则：

```
∂L/∂W₁ = ∂L/∂h₃ × ∂h₃/∂h₂ × ∂h₂/∂h₁ × ∂h₁/∂W₁
```

**逐项计算**：

```
第1项：∂L/∂h₃ = 1（假设起点）

第2项：∂h₃/∂h₂ = ？
  因为 h₃ = σ(z₃) = σ(W₃·h₂)
  所以 ∂h₃/∂h₂ = σ'(z₃) × W₃
               = 0.25 × 0.01
               = 0.0025

第3项：∂h₂/∂h₁ = ？
  因为 h₂ = σ(z₂) = σ(W₂·h₁)
  所以 ∂h₂/∂h₁ = σ'(z₂) × W₂
               = 0.25 × 0.01
               = 0.0025

第4项：∂h₁/∂W₁ = ？
  因为 h₁ = σ(z₁) = σ(W₁·x)
  所以 ∂h₁/∂W₁ = σ'(z₁) × x
               = 0.25 × 1
               = 0.25
```

**连乘起来**：

```
∂L/∂W₁ = 1 × 0.0025 × 0.0025 × 0.25
        = 0.00000156
```

**每往前一层，就多乘一个 σ'(z) × W**：

```
∂L/∂W₁ = ∂L/∂h₃ × (σ'(z₃)×W₃) × (σ'(z₂)×W₂) × (σ'(z₁)×x)
        = 1     × (0.25×0.01)   × (0.25×0.01)   × (0.25×1)
        = 1     × 0.0025        × 0.0025        × 0.25
        ≈ 0.00000156

每层乘以 0.0025（= 0.25 × 0.01），3层就连乘3次
```

**3层之后，梯度从 1 变成了 0.0000000156！**

如果有10层呢？

```
每层乘以 0.25 × 0.01 = 0.0025
10层连乘：0.0025¹⁰ ≈ 0.00000000000000000000000001

梯度几乎为 0，第1层完全收不到学习信号！
```

---

### 2.2 梯度爆炸：一步步算给你看

**场景**：ReLU 激活函数，权重太大（σ = 2.0）

**ReLU 的导数特点**：ReLU'(z) = 1（当 z > 0 时）

**链式法则推导**：

```
网络结构：x → h₁ → h₂ → h₃ → L

前向传播：
  h₁ = ReLU(W₁·x)
  h₂ = ReLU(W₂·h₁)
  h₃ = ReLU(W₃·h₂)

反向传播算 ∂L/∂W₁：
  ∂L/∂W₁ = ∂L/∂h₃ × ∂h₃/∂h₂ × ∂h₂/∂h₁ × ∂h₁/∂W₁

逐项计算：
  ∂L/∂h₃ = 1（起点）

  ∂h₃/∂h₂ = ReLU'(W₃·h₂) × W₃
           = 1 × 2.0
           = 2.0

  ∂h₂/∂h₁ = ReLU'(W₂·h₁) × W₂
           = 1 × 2.0
           = 2.0

  ∂h₁/∂W₁ = ReLU'(W₁·x) × x
           = 1 × 1
           = 1

连乘：
  ∂L/∂W₁ = 1 × 2.0 × 2.0 × 1 = 4.0
```

**对比 Sigmoid**：

```
Sigmoid 每层乘：σ'(z) × W = 0.25 × 0.01 = 0.0025（小于1，消失）
ReLU 每层乘：ReLU'(z) × W = 1 × 2.0 = 2.0（大于1，爆炸）
```

如果有10层呢？

```
每层乘以 W = 2.0
10层连乘：2.0¹⁰ = 1024

梯度从 1 变成了 1024！
```

**前向传播也在放大**：

```
输入 x = 1，W = 2.0，ReLU 激活

第1层：h₁ = ReLU(2.0 × 1) = 2.0
第2层：h₂ = ReLU(2.0 × 2.0) = 4.0
第3层：h₃ = ReLU(2.0 × 4.0) = 8.0
...
第10层：h₁₀ = 2.0¹⁰ = 1024
```

**结果**：数值变得巨大，计算机溢出（NaN），训练崩溃。

---

### 2.3 总结：为什么会消失/爆炸？

```
梯度消失：每层乘以一个 <1 的数 → 连乘后趋近于 0
梯度爆炸：每层乘以一个 >1 的数 → 连乘后趋向无穷

关键因素：
  1. 权重的大小（σ）
  2. 激活函数的导数（Sigmoid最大0.25，ReLU是0或1）
  3. 网络的深度（层数越多，连乘效应越强）
```

### 2.4 理想情况：为什么方差不变能解决问题？

**先理解一个关键问题**：前向传播的"信号大小"和反向传播的"梯度大小"是同步的。

```
前向传播：信号从输入 → 输出
反向传播：梯度从输出 → 输入

如果前向传播时信号逐层放大 → 反向传播时梯度也逐层放大（爆炸）
如果前向传播时信号逐层缩小 → 反向传播时梯度也逐层缩小（消失）
```

**用具体数字说明**：

```
假设一个简单网络，每层只有1个神经元，ReLU 激活

前向传播（从左到右）：
  输入 x = 1
  h₁ = ReLU(W₁ × x) = ReLU(2.0 × 1) = 2.0
  h₂ = ReLU(W₂ × h₁) = ReLU(2.0 × 2.0) = 4.0
  h₃ = ReLU(W₃ × h₂) = ReLU(2.0 × 4.0) = 8.0

信号：1 → 2 → 4 → 8（每层翻倍）
```

```
反向传播（从右到左）：
  假设损失对 h₃ 的梯度 = 1

  ∂L/∂h₂ = ∂L/∂h₃ × ReLU'(z₃) × W₃
          = 1 × 1 × 2.0
          = 2.0

  ∂L/∂h₁ = ∂L/∂h₂ × ReLU'(z₂) × W₂
          = 2.0 × 1 × 2.0
          = 4.0

  ∂L/∂x = ∂L/∂h₁ × ReLU'(z₁) × W₁
         = 4.0 × 1 × 2.0
         = 8.0

梯度：1 → 2 → 4 → 8（也是每层翻倍）
```

**发现了什么？**

```
前向传播信号：1 → 2 → 4 → 8（放大了8倍）
反向传播梯度：1 → 2 → 4 → 8（也放大了8倍）

它们是同步的！
```

**为什么同步？**

```
因为前向和反向用的是同一个 W！

前向：hₗ = ReLU(Wₗ × hₗ₋₁)
反向：∂hₗ/∂hₗ₋₁ = ReLU'(zₗ) × Wₗ

Wₗ 是同一个数，所以：
  前向放大多少倍 → 反向也放大多少倍
```

**所以，解决方法就是**：

```
让前向传播的信号大小不变（方差不变）

如果 Var(hₗ) = Var(hₗ₋₁)：
  → 信号每层大小一样，不放大也不缩小
  → 梯度每层大小一样，不放大也不缩小
  → 问题解决！
```

**那怎么保证 Var(hₗ) = Var(hₗ₋₁)？**

先推导 Var(hₗ) 的公式，分两步。

**第一步：线性变换 z = W × h 的方差**

```
假设：
  - h = [h₁, h₂, ..., hₙ]（n个输入）
  - W = [w₁, w₂, ..., wₙ]（对应的权重）
  - h 和 W 独立，且均值都为 0

线性变换：
  z = w₁·h₁ + w₂·h₂ + ... + wₙ·hₙ

方差（因为独立，方差可以相加）：
  Var(z) = Var(w₁·h₁) + Var(w₂·h₂) + ... + Var(wₙ·hₙ)

对于每一项：
  Var(wᵢ·hᵢ) = Var(wᵢ) × Var(hᵢ) + Var(wᵢ) × E[hᵢ]² + Var(hᵢ) × E[wᵢ]²

因为 E[wᵢ] = 0 且 E[hᵢ] = 0：
  Var(wᵢ·hᵢ) = Var(wᵢ) × Var(hᵢ)

所以：
  Var(z) = Var(w₁)×Var(h₁) + Var(w₂)×Var(h₂) + ... + Var(wₙ)×Var(hₙ)

假设所有权重方差相同 Var(W)，所有输入方差相同 Var(h)：
  Var(z) = n × Var(W) × Var(h)
```

**第二步：ReLU 激活后的方差**

```
z 通过 ReLU：
  hₗ = ReLU(z)

ReLU 的作用：
  如果 z > 0，hₗ = z（保留）
  如果 z < 0，hₗ = 0（丢弃）

假设 z ~ N(0, σ²)（均值为0的正态分布）：
  - 50% 的 z > 0，保留
  - 50% 的 z < 0，变成 0

方差计算：
  E[hₗ] = E[ReLU(z)] = σ/√(2π) ≈ 0.4σ
  E[hₗ²] = E[z² | z > 0] × 0.5 = σ²/2

  Var(hₗ) = E[hₗ²] - E[hₗ]²
           = σ²/2 - (σ/√(2π))²
           = σ²/2 - σ²/(2π)
           = σ² × (1/2 - 1/(2π))
           ≈ σ² × 0.5

简化结论：
  Var(ReLU(z)) ≈ 0.5 × Var(z)
  
（ReLU 把方差减半！因为约一半的值变成了0）
```

**合并两步**：

```
线性变换：Var(z) = n_in × Var(W) × Var(hₗ₋₁)
ReLU 激活：Var(hₗ) ≈ 0.5 × Var(z)

所以：
  Var(hₗ) = 0.5 × n_in × Var(W) × Var(hₗ₋₁)
```

**要使 Var(hₗ) = Var(hₗ₋₁)**：

```
0.5 × n_in × Var(W) × Var(hₗ₋₁) = Var(hₗ₋₁)

两边消掉 Var(hₗ₋₁)：
  0.5 × n_in × Var(W) = 1

解出 Var(W)：
  Var(W) = 2 / n_in

标准差：
  σ = √(2 / n_in)

这就是 He 初始化！
```

**总结**：

```
问题：梯度消失/爆炸
  ↓
本质：前向传播信号逐层放大/缩小
  ↓
解决：让前向传播的方差不变
  ↓
方法：选择合适的权重方差 σ = √(2/n_in)
```

## 三、Xavier 初始化

### 3.1 数学推导

对于 Sigmoid / Tanh 激活函数：

假设 h⁽ˡ⁾ = σ(z⁽ˡ⁾)，其中 z⁽ˡ⁾ = W⁽ˡ⁾ · h⁽ˡ⁻¹⁾

```
Var(h⁽ˡ⁾) = Var(Σ wᵢ · hᵢ⁽ˡ⁻¹⁾)
           = n_in · Var(w) · Var(h⁽ˡ⁻¹⁾)
```

（假设 w 和 h 独立，均值为 0）

要使 Var(h⁽ˡ⁾) = Var(h⁽ˡ⁻¹⁾)，需要：

```
n_in · Var(w) = 1

→ Var(w) = 1 / n_in
→ σ = 1 / √n_in
```

但这只考虑了前向传播。反向传播呢？

```
∂L/∂h⁽ˡ⁻¹⁾ = Wᵀ · ∂L/∂h⁽ˡ⁾

类似推导：Var(w) = 1 / n_out
```

折中方案：**Xavier 初始化**

```
Var(w) = 2 / (n_in + n_out)

σ = √(2 / (n_in + n_out))
```

---

## 四、He 初始化

### 4.1 为什么需要 He 初始化？

Xavier 初始化假设激活函数是**线性的**（如 Sigmoid 在中间区域近似线性）。

但 **ReLU 不是线性的**！ReLU 会把大约一半的输出变成 0：

```
如果 x ~ N(0, 1)，则 ReLU(x) ~ N(0, 0.5)（方差减半）
```

所以需要补偿这个"减半"效应：

```
Var(h) = n_in · Var(w) · Var(ReLU(x))
       = n_in · Var(w) · 0.5

要使 Var(h) = Var(x) = 1：
n_in · Var(w) · 0.5 = 1
→ Var(w) = 2 / n_in
→ σ = √(2 / n_in)
```

这就是 **He 初始化**（Kaiming 初始化）。

## 五、对比实验

不同初始化对训练的影响：

| 初始化方法 | σ 值 | 训练效果 |
|-----------|------|---------|
| 全零初始化 | 0 | 完全无法训练（对称性） |
| 太小 | 0.01 | 学得很慢（梯度消失） |
| 太大 | 1.0 | 不稳定（梯度爆炸） |
| Xavier | √(2/(n_in+n_out)) | 适合 Sigmoid/Tanh |
| He | √(2/n_in) | **适合 ReLU（推荐）** |

### 怎么选？

| 激活函数 | 推荐初始化 |
|----------|-----------|
| Sigmoid / Tanh | Xavier |
| ReLU / Leaky ReLU | **He** |
| 默认（不知道用什么） | **He** |

| 要点 | 内容 |
|------|------|
| 全零初始化 | 不行，对称性问题 |
| 太小 | 梯度消失，学不动 |
