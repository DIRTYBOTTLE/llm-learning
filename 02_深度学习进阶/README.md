## 章节内容

### 2.1 多层感知机

从单层到多层：
- 单层网络只能做线性分类
- 多层网络可以学习复杂模式
- 万能近似定理的数学证明

**代码实践**：`code/01_mlp_xor.py` - MLP 解决 XOR 问题

### 2.2 数据标准化

让所有特征站在同一起跑线上：
- 为什么需要标准化：不同特征尺度差异大
- 标准化（Standardization）：x' = (x - μ) / σ
- 归一化（Normalization）：x' = (x - min) / (max - min)
- 两种方法的区别和适用场景

**代码实践**：`code/02_data_standardization.py` - 对比有无标准化的训练效果

### 2.3 权重初始化

为什么初始化很重要？
- 初始化太小：梯度消失
- 初始化太大：梯度爆炸
- Xavier 初始化：σ = √(2/(n_in + n_out))
- He 初始化：σ = √(2/n_in)

**代码实践**：`code/03_weight_init.py` - 对比不同初始化方法

### 2.4 批归一化

让每层的输入分布稳定：
- 均值和方差的计算
- 归一化公式：x̂ = (x - μ) / √(σ² + ε)
- 缩放和平移：y = γx̂ + β

**代码实践**：`code/04_batch_norm.py` - BatchNorm 效果演示

### 2.5 正则化

防止"死记硬背"：
- 过拟合问题：偏差-方差权衡的数学解释
- L2 正则化：权重衰减的梯度推导与直觉理解
- L1 正则化：稀疏性的几何解释
- Dropout：集成学习与减少共适应
- Early Stopping：在过拟合前停止
- 数据增强：增加训练数据的多样性

**代码实践**：`code/05_regularization.py` - L1/L2/Dropout/Early Stopping 效果对比

### 2.6 优化器详解

如何更快找到最优解：
- SGD + Momentum
- AdaGrad, RMSProp
- Adam 的完整公式推导
- 学习率调度策略

**代码实践**：`code/06_optimizers.py` - 对比不同优化器

用"滑动窗口"看图片：
