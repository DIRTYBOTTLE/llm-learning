# 第2章 深度学习进阶

> 从"一个隐藏层"到"很多层"，理解深度学习为什么更强。

## 学习目标

学完这章，你能：
- 理解为什么需要更深的网络
- 掌握权重初始化、批归一化、正则化等技巧
- 了解卷积神经网络的原理
- 掌握各种优化器的数学原理

## 章节内容

### 2.1 多层感知机

从单层到多层：
- 单层网络只能做线性分类
- 多层网络可以学习复杂模式
- 万能近似定理的数学证明

### 2.2 权重初始化

为什么初始化很重要？
- 初始化太小：梯度消失
- 初始化太大：梯度爆炸
- Xavier 初始化：σ = √(2/(n_in + n_out))
- He 初始化：σ = √(2/n_in)

### 2.3 批归一化

让每层的输入分布稳定：
- 均值和方差的计算
- 归一化公式：x̂ = (x - μ) / √(σ² + ε)
- 缩放和平移：y = γx̂ + β

### 2.4 正则化

防止"死记硬背"：
- L1 正则化：稀疏化
- L2 正则化：权重衰减
- Dropout：随机丢弃神经元

### 2.5 优化器详解

如何更快找到最优解：
- SGD + Momentum
- AdaGrad, RMSProp
- Adam 的完整公式推导
- 学习率调度策略

### 2.6 卷积神经网络

用"滑动窗口"看图片：
- 卷积操作的数学定义
- 池化操作
- 经典架构：LeNet, AlexNet, ResNet
