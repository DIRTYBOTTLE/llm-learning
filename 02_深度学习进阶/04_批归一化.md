# 2.3 批归一化（Batch Normalization）

> **一句话**：把每一层的输入"拉回"到均值为0、方差为1的稳定分布，让训练更快更稳。

---

## 一、问题：Internal Covariate Shift

### 1.1 什么是 ICS？

训练过程中，每一层的输入分布都在变化：

```
第1层输出 h⁽¹⁾ 的分布：
  epoch 1: N(0.5, 2.0)
  epoch 10: N(-0.3, 0.8)
  epoch 100: N(0.1, 1.2)
```

**第2层需要不断适应新的分布**，就像：

> 你学开车，但每次上车方向盘的位置都不一样。

### 1.2 为什么分布会变？

因为前面层的权重在更新！

```
h⁽²⁾ = σ(W₂ · h⁽¹⁾ + b₂)

当 W₂ 更新后，h⁽²⁾ 的分布就变了
→ h⁽³⁾ 的输入分布变了
→ ... 逐层传递
```

---

## 二、批归一化原理

### 2.1 核心思想

在每一层的**激活前**（或**激活后**），对输入做归一化：

```
原始输入: x = [x₁, x₂, ..., xₘ]  （一个 batch 的 m 个样本）

Step 1: 计算 batch 均值
  μ_B = (1/m) Σᵢ xᵢ

Step 2: 计算 batch 方差
  σ²_B = (1/m) Σᵢ (xᵢ - μ_B)²

Step 3: 归一化
  x̂ᵢ = (xᵢ - μ_B) / √(σ²_B + ε)

Step 4: 缩放和平移（可学习参数）
  yᵢ = γ · x̂ᵢ + β
```

### 2.2 为什么需要 γ 和 β？

如果只做归一化，所有层的输出都是 N(0, 1)，可能**限制了网络的表达能力**。

```
假设某层的最佳输出是 N(2, 0.5)

只做归一化：强制变成 N(0, 1) → 表达能力受限
加 γ 和 β：可以学回 N(2, 0.5) → 保持灵活性
```

当 γ = σ，β = μ 时，归一化是恒等变换：

```
y = γ · x̂ + β
  = σ · (x - μ) / σ + μ
  = x  （还原了！）
```

所以**网络可以"选择"是否要归一化**。

### 2.3 ε 是什么？

`ε` 是一个很小的数（如 1e-5），防止除以 0：

```
如果 σ²_B = 0（所有样本都一样）：
  √(σ²_B + ε) = √ε ≈ 0.003

  x̂ = (x - μ) / 0.003  → 不会除以零
```

## 三、数学推导

### 3.1 前向传播

给定 batch {x₁, ..., xₘ}：

```
μ_B = (1/m) Σᵢ xᵢ                              # 均值

σ²_B = (1/m) Σᵢ (xᵢ - μ_B)²                     # 方差

x̂ᵢ = (xᵢ - μ_B) / √(σ²_B + ε)                  # 归一化

yᵢ = γ · x̂ᵢ + β = BN_{γ,β}(xᵢ)                 # 缩放平移
```

### 3.2 反向传播

需要对 γ, β, x 求梯度：

```
∂L/∂γ = Σᵢ ∂L/∂yᵢ · x̂ᵢ                         # 对缩放参数

∂L/∂β = Σᵢ ∂L/∂yᵢ                               # 对平移参数

∂L/∂x̂ᵢ = ∂L/∂yᵢ · γ                            # 对归一化输出

∂L/∂xᵢ = (1/mγ) · (m · ∂L/∂x̂ᵢ - Σⱼ ∂L/∂x̂ⱼ - x̂ᵢ · Σⱼ ∂L/∂x̂ⱼ · x̂ⱼ)  # 对原始输入
```

最后一个公式看起来复杂，但 PyTorch 会自动处理。

### 3.3 测试时怎么办？

训练时用 batch 的均值和方差，但测试时可能只有一个样本！

**解决方案**：用**滑动平均**估计全局均值和方差：

```
训练时：
  running_mean = (1-α) · running_mean + α · μ_B
  running_var  = (1-α) · running_var  + α · σ²_B

  α 通常取 0.1（PyTorch 默认 momentum=0.1）
```

测试时直接用 running_mean 和 running_var：

```
x̂ = (x - running_mean) / √(running_var + ε)
y = γ · x̂ + β
```

## 四、BatchNorm 的好处

### 4.1 加速训练

```
没有 BatchNorm：学习率 = 0.01
有 BatchNorm：学习率 = 0.1（可以大10倍！）
```

**为什么能用大学习率？**

```
没有 BatchNorm 时：
  每层的输入分布不断变化（ICS 问题）
  → 学习率太大，后面的层还没适应，前面的层又变了
  → 训练震荡，不稳定
  → 只能用小学习率

有 BatchNorm 时：
  每层的输入被"拉回"到 N(0, 1)
  → 分布稳定，不会剧烈变化
  → 即使大学习率，也不会震荡
  → 训练更快
```

### 4.2 减少对初始化的依赖

```
没有 BatchNorm：需要仔细初始化（He/Xavier）
有 BatchNorm：初始化不那么敏感
```

**为什么对初始化不敏感？**

```
没有 BatchNorm 时：
  如果初始化太小 → 信号逐层消失 → 训练失败
  如果初始化太大 → 信号逐层爆炸 → 训练失败
  → 必须用 He/Xavier 精确控制方差

有 BatchNorm 时：
  不管初始化多大多小，BatchNorm 都会把输出"拉回" N(0, 1)
  → 初始化的影响被 BatchNorm 抵消了
  → 随便初始化也能训练
```

### 4.3 正则化效果

BatchNorm 引入了噪声（因为用 batch 统计量代替全局统计量），有轻微的正则化效果。

**为什么有正则化效果？**

```
训练时：
  用当前 batch 的均值和方差
  → 不同 batch 的均值和方差略有不同
  → 同一个样本在不同 batch 中，输出不同
  → 相当于给数据加了随机噪声

测试时：
  用全局的 running_mean 和 running_var
  → 输出是确定的，没有噪声

这种"训练时的随机性"起到了类似 Dropout 的正则化效果
```
