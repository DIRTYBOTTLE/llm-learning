# 2.2 数据标准化（Data Standardization）

> **一句话**：让所有特征站在同一起跑线上，训练更快更稳定。

---

## 一、为什么需要数据标准化？

### 1.1 问题：不同特征的尺度差异大

```
假设我们要预测房价，有两个特征：

特征1：面积（平方米）
  范围：50 ~ 200

特征2：房间数
  范围：1 ~ 5

数据：
  [150, 3]  → 300万
  [80,  2]  → 150万
  [200, 5]  → 500万
```

**问题：尺度大的特征会主导梯度更新**

```
假设模型：y = w₁·面积 + w₂·房间数 + b

梯度更新：
  ∂L/∂w₁ ∝ 面积（范围 50~200）
  ∂L/∂w₂ ∝ 房间数（范围 1~5）

面积的梯度是房间数的 40 倍！
  → w₁ 更新很快，w₂ 更新很慢
  → 训练不稳定，收敛慢
```

**生活类比：考试评分**

```
语文满分 150，数学满分 150，英语满分 100

如果不标准化：
  语文和数学的分数变化范围大，英语的分数变化范围小
  → 总分主要由语文和数学决定
  → 英语的成绩被"忽略"了

标准化后：
  所有科目的分数都变成 0~1 的范围
  → 每个科目同等重要
```

### 1.2 标准化的效果

```
标准化前：
  面积：[50, 80, 100, 150, 200]  → 范围大
  房间数：[1, 2, 3, 4, 5]        → 范围小

标准化后（均值为0，标准差为1）：
  面积：[-1.2, -0.6, -0.1, 0.8, 1.1]  → 范围相似
  房间数：[-1.4, -0.7, 0, 0.7, 1.4]   → 范围相似

现在两个特征同等重要了！
```

## 二、常见的标准化方法

### 2.1 标准化（Standardization）

**公式：**

```
x' = (x - μ) / σ

其中：
  μ = 均值（mean）
  σ = 标准差（standard deviation）
```

**效果：**

```
标准化后：
  均值 = 0
  标准差 = 1
  数据分布形状不变（只是平移和缩放）
```

**例子：**

```
原始数据：[150, 80, 200, 100, 170]
均值 μ = 140
标准差 σ = 45.3

标准化后：
  (150-140)/45.3 = 0.22
  (80-140)/45.3 = -1.32
  (200-140)/45.3 = 1.32
  (100-140)/45.3 = -0.88
  (170-140)/45.3 = 0.66

结果：[0.22, -1.32, 1.32, -0.88, 0.66]
均值 ≈ 0，标准差 ≈ 1
```

### 2.2 归一化（Normalization）

**公式：**

```
x' = (x - min) / (max - min)

其中：
  min = 最小值
  max = 最大值
```

**效果：**

```
归一化后：
  范围 = [0, 1]
  数据分布形状可能改变（压缩到固定范围）
```

**例子：**

```
原始数据：[150, 80, 200, 100, 170]
min = 80, max = 200

归一化后：
  (150-80)/(200-80) = 0.58
  (80-80)/(200-80) = 0
  (200-80)/(200-80) = 1
  (100-80)/(200-80) = 0.17
  (170-80)/(200-80) = 0.75

结果：[0.58, 0, 1, 0.17, 0.75]
范围 = [0, 1]
```

### 2.3 如何选择？

| 方法 | 公式 | 效果 | 适用场景 |
|------|------|------|----------|
| 标准化 | (x-μ)/σ | 均值0，标准差1 | 大多数情况，数据无明确边界 |
| 归一化 | (x-min)/(max-min) | 范围[0,1] | 数据有明确边界，如图像像素 |

**经验法则：**
```
不确定用哪个？ → 用标准化（Standardization）
数据有明确边界？ → 用归一化（Normalization）
图像数据？ → 通常用归一化（像素范围 0~255 → 0~1）
```

## 三、数学解释：为什么标准化能加速训练？

### 3.1 标准化前的梯度更新

```
假设两个特征：x₁ ∈ [50, 200], x₂ ∈ [1, 5]

模型：y = w₁·x₁ + w₂·x₂ + b

损失函数对权重的梯度：
  ∂L/∂w₁ ∝ x₁  （范围 50~200）
  ∂L/∂w₂ ∝ x₂  （范围 1~5）

更新规则：
  w₁ = w₁ - lr · ∂L/∂w₁  → 更新幅度大
  w₂ = w₂ - lr · ∂L/∂w₂  → 更新幅度小

问题：
  - w₁ 更新太快，可能震荡
  - w₂ 更新太慢，收敛慢
  - 学习率 lr 很难同时适合两个特征
```

### 3.2 标准化后的梯度更新

```
标准化后：x₁' ∈ [-1.5, 1.5], x₂' ∈ [-1.5, 1.5]

模型：y = w₁·x₁' + w₂·x₂' + b

梯度：
  ∂L/∂w₁ ∝ x₁'  （范围 -1.5~1.5）
  ∂L/∂w₂ ∝ x₂'  （范围 -1.5~1.5）

更新：
  w₁ = w₁ - lr · ∂L/∂w₁  → 更新幅度适中
  w₂ = w₂ - lr · ∂L/∂w₂  → 更新幅度适中

好处：
  - 两个特征的更新幅度相似
  - 学习率 lr 可以统一设置
  - 训练更稳定，收敛更快
```

### 3.3 几何直觉

```
标准化前的损失函数等高线：
  w₂
  |  ___________
  | /           \
  |/             \
  |_______________→ w₁
  
  椭圆形，长轴在 w₁ 方向（因为 x₁ 尺度大）
  → 梯度下降会沿着 w₁ 方向震荡

标准化后的损失函数等高线：
  w₂
  |    ___
  |   /   \
  |  /     \
  | /       \
  |___________→ w₁
  
  更接近圆形
  → 梯度下降直接指向最小值
```

## 四、PyTorch 实现

### 4.1 使用 scikit-learn 预处理

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler
import numpy as np

# 准备数据
X_train = np.array([[150, 3], [80, 2], [200, 5], [100, 2]])
X_test = np.array([[120, 3], [180, 4]])

# 标准化
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)  # 计算均值和标准差，然后标准化
X_test_scaled = scaler.transform(X_test)  # 用训练集的均值和标准差标准化测试集

print("标准化前：")
print(X_train)
print("\n标准化后：")
print(X_train_scaled)
print(f"\n均值：{X_train_scaled.mean(axis=0)}")  # 接近 0
print(f"标准差：{X_train_scaled.std(axis=0)}")  # 接近 1
```

### 4.2 在 PyTorch 中使用

```python
import torch
from torch.utils.data import DataLoader, TensorDataset

# 准备数据
X_train = torch.tensor([[150, 3], [80, 2], [200, 5], [100, 2]], dtype=torch.float32)
y_train = torch.tensor([300, 150, 500, 200], dtype=torch.float32)

# 标准化
mean = X_train.mean(dim=0)
std = X_train.std(dim=0)
X_train_scaled = (X_train - mean) / std

# 创建 DataLoader
dataset = TensorDataset(X_train_scaled, y_train)
dataloader = DataLoader(dataset, batch_size=2, shuffle=True)

# 训练时使用标准化后的数据
for X_batch, y_batch in dataloader:
    # X_batch 已经是标准化后的数据
    pass
```

### 4.3 注意事项

```
1. 只在训练集上计算均值和标准差
   → 用训练集的统计量标准化测试集
   → 不能用测试集的统计量（否则是数据泄露）

2. 对于图像数据，通常用归一化：
   transform = transforms.Compose([
       transforms.ToTensor(),  # 像素值从 [0, 255] 变成 [0, 1]
       transforms.Normalize((0.5,), (0.5,))  # 变成 [-1, 1]
   ])

3. 某些模型不需要标准化：
   - 决策树、随机森林（对特征尺度不敏感）
   - 神经网络、SVM、线性回归（需要标准化）
```

## 五、数据标准化 vs 批归一化

| 特性 | 数据标准化 | 批归一化（BatchNorm） |
|------|------------|----------------------|
| 作用对象 | 输入数据 | 每层的输出 |
| 作用时间 | 训练前预处理 | 训练过程中 |
| 计算位置 | 数据加载时 | 网络内部 |
| 目的 | 让所有特征同等重要 | 稳定每层的输入分布 |

**关系：**

```
数据标准化：处理输入数据，让训练开始时更稳定
批归一化：处理中间层输出，让训练过程中更稳定

两者互补，不是替代关系
```

## 六、本节小结

| 方法 | 公式 | 效果 | 适用场景 |
|------|------|------|----------|
| 标准化 | (x-μ)/σ | 均值0，标准差1 | 大多数情况 |
| 归一化 | (x-min)/(max-min) | 范围[0,1] | 数据有明确边界 |

**核心思想：**
- 让所有特征站在同一起跑线上
- 训练更快、更稳定
- 学习率更容易设置
