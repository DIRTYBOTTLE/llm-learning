# 6.5 模型保存与加载

> 保存你的模型，以后可以直接使用！

## 从你已经知道的开始

在上一节，你学了如何微调模型。

**这一节，我们来学习如何保存和加载模型！**

---

## 一、保存模型

### 保存完整模型

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

# 假设你已经训练好模型
model = ...  # 你的模型
tokenizer = ...  # 你的分词器

# 保存到本地
model.save_pretrained("./my-model")
tokenizer.save_pretrained("./my-model")

print("模型保存完成！")
```

### 保存 LoRA 权重

```python
from peft import PeftModel

# 如果使用 LoRA 训练
model = ...  # LoRA 模型

# 只保存 LoRA 权重（很小）
model.save_pretrained("./my-lora-weights")

print("LoRA 权重保存完成！")
```

### 查看保存的文件

```bash
ls ./my-model/
# 输出：
# config.json           # 模型配置
# pytorch_model.bin     # 模型权重
# tokenizer.json        # 分词器
# tokenizer_config.json # 分词器配置
# special_tokens_map.json
```

## 二、加载模型

### 加载完整模型

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

# 加载模型
model = AutoModelForCausalLM.from_pretrained("./my-model")
tokenizer = AutoTokenizer.from_pretrained("./my-model")

print("模型加载完成！")
```

### 加载 LoRA 权重

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel

# 1. 加载基座模型
base_model = AutoModelForCausalLM.from_pretrained("gpt2")
tokenizer = AutoTokenizer.from_pretrained("gpt2")

# 2. 加载 LoRA 权重
model = PeftModel.from_pretrained(base_model, "./my-lora-weights")

print("LoRA 模型加载完成！")
```

### 合并 LoRA 权重到基座模型

```python
from transformers import AutoModelForCausalLM
from peft import PeftModel

# 加载基座模型
base_model = AutoModelForCausalLM.from_pretrained("gpt2")

# 加载 LoRA
model = PeftModel.from_pretrained(base_model, "./my-lora-weights")

# 合并 LoRA 到基座模型
merged_model = model.merge_and_unload()

# 保存合并后的模型
merged_model.save_pretrained("./merged-model")

print("模型合并完成！")
```

## 三、上传到 Hub

### 准备工作

```python
# 1. 安装 huggingface_hub
pip install huggingface_hub

# 2. 登录
from huggingface_hub import login
login()  # 会提示输入 token
```

### 上传模型

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

# 加载你的模型
model = AutoModelForCausalLM.from_pretrained("./my-model")
tokenizer = AutoTokenizer.from_pretrained("./my-model")

# 上传到 Hub
model.push_to_hub("your-username/my-awesome-model")
tokenizer.push_to_hub("your-username/my-awesome-model")

print("模型上传完成！")
```

### 使用上传的模型

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

# 其他人可以直接使用
model = AutoModelForCausalLM.from_pretrained("your-username/my-awesome-model")
tokenizer = AutoTokenizer.from_pretrained("your-username/my-awesome-model")
```

## 四、模型格式转换

### 转换为其他格式

```python
from transformers import AutoModelForCausalLM

# 加载模型
model = AutoModelForCausalLM.from_pretrained("gpt2")

# 保存为 SafeTensors 格式（更安全）
model.save_pretrained("./my-model", safe_serialization=True)

# 保存为 GGUF 格式（用于 llama.cpp）
# 需要使用专门的转换工具
```

### 使用 SafeTensors

```python
from transformers import AutoModelForCausalLM
from safetensors.torch import load_file

# 加载 SafeTensors 格式的权重
state_dict = load_file("./my-model/model.safetensors")

# 加载到模型
model = AutoModelForCausalLM.from_pretrained("gpt2")
model.load_state_dict(state_dict)
```

## 五、模型管理最佳实践

### 文件组织

```
my-project/
├── models/
│   ├── base-model/          # 基座模型
│   ├── fine-tuned/          # 微调后的模型
│   └── lora-weights/        # LoRA 权重
├── data/
│   ├── train.json           # 训练数据
│   └── test.json            # 测试数据
├── scripts/
│   ├── train.py             # 训练脚本
│   └── evaluate.py          # 评估脚本
└── README.md
```

### 模型版本管理

```python
# 使用时间戳命名
import datetime

timestamp = datetime.datetime.now().strftime("%Y%m%d_%H%M%S")
model_path = f"./models/model_{timestamp}"

model.save_pretrained(model_path)
```

## 六、常见问题

### 问题1：模型太大，无法保存

```python
# 使用量化保存
model.save_pretrained(
    "./my-model",
    safe_serialization=True,
    max_shard_size="5GB"  # 分片保存
)
```

### 问题2：加载时显存不足

```python
# 使用 device_map 自动分配
model = AutoModelForCausalLM.from_pretrained(
    "./my-model",
    device_map="auto",
    torch_dtype=torch.float16
)
```

### 问题3：找不到模型文件

```python
# 检查路径是否正确
import os

model_path = "./my-model"
if os.path.exists(model_path):
    print(f"模型路径存在: {model_path}")
    print(f"文件列表: {os.listdir(model_path)}")
else:
    print(f"模型路径不存在: {model_path}")
```

## 七、总结

### 保存加载的关键点

| 操作 | 代码 |
|------|------|
| 保存模型 | `model.save_pretrained(path)` |
| 加载模型 | `AutoModelForCausalLM.from_pretrained(path)` |
| 保存分词器 | `tokenizer.save_pretrained(path)` |
| 加载分词器 | `AutoTokenizer.from_pretrained(path)` |
| 上传 Hub | `model.push_to_hub("username/model")` |
| 下载 Hub | `AutoModelForCausalLM.from_pretrained("username/model")` |

### 最佳实践

```
1. 定期保存模型
   训练过程中定期保存，防止丢失
   
2. 使用版本管理
   用时间戳或版本号命名
   
3. 上传到 Hub
   方便分享和协作
   
4. 使用 SafeTensors
   更安全的序列化格式
```
