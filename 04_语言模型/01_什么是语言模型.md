# 4.1 什么是语言模型

> 语言模型就是"文字接龙"高手，它的任务是预测下一个词。

## 从你已经知道的开始

在第3章，你学了 GPT 用的是**解码器**，它的任务是**生成下一个词**。

**语言模型就是专门做这件事的模型！**

---

## 一、语言模型的核心任务

### 一句话定义

```
语言模型的任务：给定前面的词，预测下一个词
```

### 用"文字接龙"来理解

```
游戏规则：我说前面的词，你猜下一个词

我："今天"
你："天气"（猜对了！）

我："今天天气"
你："真"（猜对了！）

我："今天天气真"
你："好"（猜对了！）

我："今天天气真好"
你："！"（猜对了！）
```

**GPT 就是玩这个游戏的高手！**

---

## 二、语言模型的数学定义

### 核心公式

```
P(w₁, w₂, ..., wₙ) = P(w₁) × P(w₂|w₁) × P(w₃|w₁,w₂) × ... × P(wₙ|w₁,...,wₙ₋₁)
```

**用大白话说**：

```
一句话的概率 = 每个词在前面词出现的条件下的概率的乘积
```

### 用具体例子理解

句子："我 爱 学习"

```
P("我 爱 学习") = P("我") × P("爱"|"我") × P("学习"|"我 爱")
```

- P("我")："我"这个词出现的概率
- P("爱"|"我")：在"我"后面出现"爱"的概率
- P("学习"|"我 爱")：在"我 爱"后面出现"学习"的概率

### 怎么计算这些概率？

**用 Transformer（解码器）来计算！**

```
输入："我 爱"
  ↓
Transformer 解码器
  ↓
输出：下一个词的概率分布
  P("学习"|"我 爱") = 0.8
  P("吃"|"我 爱") = 0.1
  P("看"|"我 爱") = 0.05
  ...
```

## 三、自回归模型

### 什么是自回归？

**自回归**：每次生成一个词，然后把它加入输入，继续生成下一个词。

```
第1步：输入 "" → 预测 "我"
第2步：输入 "我" → 预测 "爱"
第3步：输入 "我 爱" → 预测 "学习"
第4步：输入 "我 爱 学习" → 预测 "<END>"
```

### 用代码理解

```python
def generate_text(model, start_text, max_len=50):
    """自回归生成文本"""
    
    text = start_text
    
    for _ in range(max_len):
        # 输入当前文本
        input_ids = tokenize(text)
        
        # 预测下一个词的概率
        probs = model(input_ids)
        
        # 选择概率最大的词
        next_token = argmax(probs)
        
        # 如果是结束符，就停止
        if next_token == "<END>":
            break
        
        # 把新词加入文本
        text += next_token
    
    return text
```

## 四、语言模型的应用

### 1. 文本生成

```
输入："今天天气"
输出："今天天气真好，适合出去玩。"
```

### 2. 对话系统

```
用户："你好"
模型："你好！有什么可以帮你的吗？"
```

### 3. 代码生成

```
输入："def fibonacci(n):"
模型输出：
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)
```

### 4. 翻译

```
输入："Translate to Chinese: I love you"
输出："我爱你"
```

## 五、语言模型的训练

### 训练数据

```
句子："今天 天气 真 好"

训练样本：
  输入：""          → 目标："今天"
  输入："今天"       → 目标："天气"
  输入："今天 天气"   → 目标："真"
  输入："今天 天气 真" → 目标："好"
```

### 训练目标

```
最大化：P(下一个词 | 前面的词)

等价于最小化：-log P(下一个词 | 前面的词)
```

这就是**交叉熵损失**！

### 训练过程

```python
for batch in dataloader:
    # 输入：前面的词
    input_ids = batch["input_ids"]
    
    # 目标：下一个词
    targets = batch["targets"]
    
    # 前向传播
    logits = model(input_ids)
    
    # 计算损失
    loss = cross_entropy(logits, targets)
    
    # 反向传播
    loss.backward()
    
    # 更新参数
    optimizer.step()
    optimizer.zero_grad()
```

## 六、总结

### 语言模型的核心

| 概念 | 含义 |
|------|------|
| 任务 | 预测下一个词 |
| 公式 | P(wₜ | w₁, ..., wₜ₋₁) |
| 方法 | 自回归生成 |
| 模型 | Transformer 解码器 |
| 训练 | 最大化下一个词的概率 |

### 关键理解

1. **语言模型 = 文字接龙高手**
2. **GPT 就是一个语言模型**
3. **训练目标 = 预测下一个词**
4. **生成方式 = 自回归（一个词一个词生成）**

1. 语言模型的任务是什么？

### 练习2：计算概率

假设语言模型给出了以下概率：
- P("我") = 0.1
- P("爱"|"我") = 0.5
- P("学习"|"我 爱") = 0.8

请计算 P("我 爱 学习")。

---

## 练习答案

### 练习1答案

1. **语言模型的任务**：给定前面的词，预测下一个词。
2. **自回归生成**：每次生成一个词，然后把它加入输入，继续生成下一个词。
3. **GPT 和语言模型的关系**：GPT 就是一个语言模型，它用 Transformer 解码器来预测下一个词。

### 练习2答案

```
P("我 爱 学习") = P("我") × P("爱"|"我") × P("学习"|"我 爱")
               = 0.1 × 0.5 × 0.8
               = 0.04
```

所以"我 爱 学习"这个句子的概率是 0.04（4%）。
