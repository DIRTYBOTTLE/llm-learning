# 4.3 词嵌入

> 把 token 变成向量，让模型能理解词的含义。

## 从你已经知道的开始

在上一节，你学了 Tokenization：把文字切成 token，每个 token 有一个索引。

```
"我爱学习" → ["我", "爱", "学", "习"] → [1, 2, 3, 4]
```

**但是，索引只是数字，没有语义信息！**

```
"我"=1，"爱"=2，"学习"=3

模型看到 1, 2, 3，不知道它们是什么意思
```

**我们需要把索引变成有意义的向量！这就是词嵌入的工作！**

---

## 一、什么是词嵌入？

### 简单定义

```
词嵌入 = 把 token 索引转换成向量的过程
```

### 用例子理解

```
"我"的索引 = 1
"我"的词嵌入 = [0.2, -0.5, 0.8, 0.1, ...]  （d_model 维的向量）
```

**每个词都被表示成一个向量，向量包含了词的语义信息！**

---

## 二、词嵌入的实现

### 用 PyTorch 实现

```python
import torch
import torch.nn as nn

# 假设词表大小 = 1000，向量维度 = 64
vocab_size = 1000
d_model = 64

# 创建词嵌入层
embedding = nn.Embedding(vocab_size, d_model)

# 输入：词的索引
word_idx = torch.tensor([1, 2, 3, 4])  # "我", "爱", "学", "习"

# 输出：词的向量
word_vectors = embedding(word_idx)
print(word_vectors.shape)  # (4, 64)
```

### 词嵌入的本质

**词嵌入就是一个查找表！**

```
索引 1 → [0.2, -0.5, 0.8, ...]
索引 2 → [0.1, 0.3, -0.2, ...]
索引 3 → [-0.4, 0.6, 0.1, ...]
...
```

**这些向量在训练过程中会不断更新，学习到词的语义信息！**

---

## 三、词向量的语义

### 相似的词，向量也相似

```
"国王"的向量 ≈ "皇帝"的向量
"猫"的向量 ≈ "狗"的向量（都是宠物）
"北京"的向量 ≈ "上海"的向量（都是大城市）
```

### 向量可以做运算

著名的例子：

```
"国王" - "男人" + "女人" ≈ "女王"
```

**这说明词向量学到了语义关系！**

---

## 四、位置编码

### 为什么需要位置编码？

在第3章学过，Transformer 没有位置信息，需要额外添加。

```
"我爱学习" 和 "学习爱我"
词相同，但顺序不同，意思完全不同！

词嵌入只能表示词的意思，不能表示位置
所以需要位置编码
```

### 最终输入

```
最终输入 = 词嵌入 + 位置编码

"我"的最终输入 = [0.2, -0.5, 0.8, ...] + [0, 0.1, 0, ...]
```

---

## 五、维度选择

### d_model 的选择

| 模型 | d_model | 说明 |
|------|---------|------|
| 小型模型 | 128 | 实验用 |
| BERT-base | 768 | 常用 |
| GPT-2 small | 768 | 常用 |
| GPT-2 large | 1024 | 更大 |
| GPT-3 | 4096 | 很大 |

**维度越大，表达能力越强，但参数也越多！**

## 六、代码示例

### 完整的词嵌入流程

```python
import torch
import torch.nn as nn

class TokenEmbedding(nn.Module):
    """词嵌入 + 位置编码"""
    
    def __init__(self, vocab_size, d_model, max_len=5000):
        super().__init__()
        
        # 词嵌入
        self.word_embedding = nn.Embedding(vocab_size, d_model)
        
        # 位置编码（使用正弦余弦函数）
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-torch.log(torch.tensor(10000.0)) / d_model))
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        self.register_buffer('pe', pe.unsqueeze(0))
        
    def forward(self, x):
        """
        x: 词的索引，形状 (batch_size, seq_len)
        """
        # 词嵌入
        word_emb = self.word_embedding(x)  # (batch_size, seq_len, d_model)
        
        # 添加位置编码
        word_emb = word_emb + self.pe[:, :x.size(1), :]
        
        return word_emb

# 使用示例
embedding = TokenEmbedding(vocab_size=1000, d_model=64)

# 输入词的索引
x = torch.tensor([[1, 2, 3, 4]])  # "我", "爱", "学", "习"

# 输出词向量
output = embedding(x)
print(output.shape)  # (1, 4, 64)
```

## 七、总结

### 词嵌入的作用

```
token 索引 → 词嵌入 → 向量 → 模型处理
```

### 关键点

1. **词嵌入是查找表**：把索引转换成向量
2. **向量包含语义信息**：相似的词，向量也相似
3. **需要位置编码**：补充位置信息
4. **维度可以调整**：越大表达能力越强
