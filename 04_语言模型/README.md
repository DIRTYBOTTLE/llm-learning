# 第4章 语言模型

> 语言模型就是"文字接龙"高手。这章教你理解它的秘密。

## 学习目标

学完这章，你能：
- 理解语言模型的数学定义
- 掌握 BPE 算法的原理
- 理解词嵌入的作用
- 用 GPT 生成文本

## 章节内容

### 4.1 什么是语言模型

语言模型的数学定义：
```
P(w₁, w₂, ..., wₙ) = ∏ P(wₜ | w₁, ..., wₜ₋₁)
```

自回归模型：
- 一个词一个词地生成
- 每次预测下一个词的概率

### 4.2 自回归模型

GPT 的核心思想：
```
P(wₜ | w₁, ..., wₜ₋₁) = softmax(hₜ Wₑ)
其中 hₜ = Transformer(w₁, ..., wₜ₋₁)
```

### 4.3 Tokenization

BPE 算法：
1. 初始化：每个字符是一个 token
2. 统计：找出最频繁的相邻 pair
3. 合并：将该 pair 合并为新 token
4. 重复：直到达到目标词表大小

### 4.4 词嵌入

把词变成向量：
```
Embedding: token_id → vector ∈ ℝ^d
```

维度选择：
- d = 128：小型模型
- d = 768：BERT-base
- d = 1024：GPT-2 small
- d = 4096：GPT-3

### 4.5 预训练目标

因果语言模型（CLM）：
```
L_CLM = -∑ log P(wₜ | w₁, ..., wₜ₋₁)
```

掩码语言模型（MLM）：
```
L_MLM = -∑ log P(wₜ | w_masked)
```

### 4.6 用 GPT 生成文本

实战：文本生成
- 输入：一个开头
- 输出：模型续写的内容
