# 第4章 语言模型

> 语言模型就是"文字接龙"高手。这章教你理解它的秘密。

## 学习目标

学完这章，你能：
- 理解语言模型的数学定义
- 掌握 Tokenization（分词）的原理
- 理解词嵌入的作用
- 理解 GPT 是怎么训练和生成的

## 前置知识（你已经学过）

- **第3章**：Transformer、注意力机制、编码器、解码器

## 章节内容

### 4.1 什么是语言模型

语言模型的核心任务：
- 给定前面的词，预测下一个词
- 这就是 GPT 的本质！

**对应文件**：`01_什么是语言模型.md`、`code/01_language_model_concept.py`

### 4.2 Tokenization（分词）

把文字切成 token：
- 字符级分词
- 词级分词
- BPE 算法（GPT 用的）

**对应文件**：`02_Tokenization.md`、`code/02_tokenization.py`

### 4.3 词嵌入

把 token 变成向量：
- Embedding 层的作用
- 词向量的维度选择
- 位置编码

**对应文件**：`03_词嵌入.md`、`code/03_embedding.py`

### 4.4 GPT 的训练过程

GPT 是怎么训练的：
- 训练数据的准备
- 因果语言模型（CLM）
- 损失函数和优化器

**对应文件**：`04_GPT训练过程.md`、`code/04_gpt_training.py`

### 4.5 GPT 的生成过程

GPT 是怎么生成文本的：
- 自回归生成
- 贪心解码 vs 采样解码
- 温度参数

**对应文件**：`05_GPT生成过程.md`、`code/05_gpt_generation.py`

### 4.6 实战：用 GPT 生成文本

动手实践：
- 加载预训练模型
- 生成文本
- 调整参数

**对应文件**：`06_实战_GPT生成.md`、`code/01_gpt_demo.py`
