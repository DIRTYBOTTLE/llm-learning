## 一、先搞清楚：什么是解码器？

### 编码器 vs 解码器

在第3章，我们学了 Transformer 有两个部分：

```
┌─────────────────────────────────────────────────────────┐
│                    Transformer                           │
│  ┌─────────────────┐      ┌─────────────────┐          │
│  │     编码器       │      │     解码器       │          │
│  │   (Encoder)      │      │   (Decoder)      │          │
│  │                  │      │                  │          │
│  │  理解输入的意思   │      │  生成输出的内容   │          │
│  └─────────────────┘      └─────────────────┘          │
│         ↓                        ↓                      │
│    BERT 用的                GPT 用的                     │
└─────────────────────────────────────────────────────────┘
```

### 编码器的特点

**编码器的任务**：理解输入的意思

```
输入："我 爱 学习"
  ↓
编码器
  ↓
输出：理解了这句话的意思（一个向量表示）
```

**关键特点**：
- 可以看到**所有**的输入词（双向注意力）
- 适合"理解"任务（分类、问答等）

### 解码器的特点

**解码器的任务**：生成下一个词

```
输入："我 爱"
  ↓
解码器
  ↓
输出："学习"（预测下一个词）
```

**关键特点**：
- 只能**从左到右**看（单向注意力）
- 不能"偷看"后面的词
- 适合"生成"任务（写文章、对话等）

### 为什么解码器要"从左到右"？

**因为生成的时候，后面的词还不存在！**

```
生成过程：
第1步：输入 "" → 预测 "我"（此时"爱"还不存在）
第2步：输入 "我" → 预测 "爱"（此时"学习"还不存在）
第3步：输入 "我 爱" → 预测 "学习"

如果解码器能"看到"后面的词，那就是作弊了！
```

### 解码器的核心：掩码注意力（Masked Attention）

**掩码** = 屏蔽，遮挡

在解码器中，注意力机制要"遮挡"后面的词：

```
正常注意力（编码器用的）：
  "我" 能看到：我、爱、学习
  "爱" 能看到：我、爱、学习
  "学习" 能看到：我、爱、学习

掩码注意力（解码器用的）：
  "我" 能看到：我
  "爱" 能看到：我、爱
  "学习" 能看到：我、爱、学习
```

**用矩阵来理解**：

```
正常注意力矩阵（每个位置都能看到所有位置）：
       我  爱  学习
  我  [1,  1,  1]
  爱  [1,  1,  1]
  学习 [1,  1,  1]

掩码注意力矩阵（只能看到前面的位置）：
       我  爱  学习
  我  [1,  0,  0]    ← "我"只能看到自己
  爱  [1,  1,  0]    ← "爱"能看到"我"和自己
  学习 [1,  1,  1]    ← "学习"能看到所有
```

**0 = 看不到，1 = 能看到**

## 二、GPT 的模型结构

### GPT 的完整结构

```
输入 token 索引（比如 [1, 2, 3]）
        ↓
    ┌───────────────┐
    │   词嵌入层     │  ← 把索引变成向量
    │  (Embedding)   │
    └───────────────┘
        ↓
    ┌───────────────┐
    │   位置编码     │  ← 添加位置信息
    └───────────────┘
        ↓
    ┌───────────────┐
    │  解码器层 ×N   │  ← 核心部分（掩码注意力）
    │  (Decoder)     │
    └───────────────┘
        ↓
    ┌───────────────┐
    │   线性层       │  ← 输出词表大小的向量
    └───────────────┘
        ↓
    ┌───────────────┐
    │   Softmax      │  ← 转换成概率
    └───────────────┘
        ↓
  下一个词的概率分布
```

### 用代码理解

```python
class GPT(nn.Module):
    def __init__(self, vocab_size, d_model, num_heads, num_layers, d_ff):
        super().__init__()
        
        # 1. 词嵌入：把 token 索引变成向量
        self.embedding = nn.Embedding(vocab_size, d_model)
        
        # 2. 位置编码：添加位置信息
        self.positional_encoding = PositionalEncoding(d_model)
        
        # 3. 解码器层：核心部分
        self.decoder_layers = nn.ModuleList([
            DecoderLayer(d_model, num_heads, d_ff)
            for _ in range(num_layers)
        ])
        
        # 4. 输出层：映射到词表大小
        self.output_layer = nn.Linear(d_model, vocab_size)
        
    def forward(self, x):
        """
        x: 输入 token 索引，形状 (batch_size, seq_len)
        """
        # 词嵌入
        x = self.embedding(x)  # (batch_size, seq_len, d_model)
        
        # 添加位置编码
        x = self.positional_encoding(x)
        
        # 通过解码器层
        for layer in self.decoder_layers:
            x = layer(x, mask=True)  # mask=True 表示使用掩码
        
        # 输出层
        logits = self.output_layer(x)  # (batch_size, seq_len, vocab_size)
        
        return logits
```

### 解码器层的内部结构

每个解码器层包含：

```
输入 x
  ↓
┌─────────────────────────────────┐
│  1. 掩码多头自注意力             │
│     (Masked Multi-Head Self-Attn)│
└─────────────────────────────────┘
  ↓ + 残差连接 + 层归一化
┌─────────────────────────────────┐
│  2. 前馈神经网络                 │
│     (Feed-Forward Network)       │
└─────────────────────────────────┘
  ↓ + 残差连接 + 层归一化
输出
```

## 四、训练样本的构造（重点！）

### 因果语言模型（CLM）的目标

**目标**：给定前面的词，预测下一个词

用数学公式表示：

$$P(w_t | w_1, w_2, ..., w_{t-1})$$

**大白话**：在已经知道前 t-1 个词的情况下，第 t 个词是什么？

### 构造训练样本

假设我们有一个句子："我 爱 学习 深度 学习"

**方法：输入和目标错开一位！**

```
原始句子：我  爱  学习  深度  学习
索引：    1   2    3     4    5

构造训练样本：
┌─────────────────────────────────────────────────────┐
│  输入序列：  [1,  2,  3,  4,  5]                    │
│  目标序列：  [2,  3,  4,  5,  结束符]               │
└─────────────────────────────────────────────────────┘

对应关系：
  输入位置0: "我"   → 目标位置0: "爱"
  输入位置1: "爱"   → 目标位置1: "学习"
  输入位置2: "学习" → 目标位置2: "深度"
  输入位置3: "深度" → 目标位置3: "学习"
  输入位置4: "学习" → 目标位置4: "<END>"
```

### 用具体数字例子理解

假设词表：{"我":1, "爱":2, "学习":3, "深度":4, "<END>":5}

```
句子："我 爱 学习"

步骤1：分词
  tokens = [1, 2, 3]

步骤2：构造输入和目标
  input_ids  = [1, 2, 3]      （去掉最后一个）
  target_ids = [2, 3, 5]      （去掉第一个，加上<END>）

步骤3：对齐
  位置0: 输入=1("我")   → 目标=2("爱")
  位置1: 输入=2("爱")   → 目标=3("学习")
  位置2: 输入=3("学习") → 目标=5("<END>")
```

### 为什么要错开一位？

**因为我们的目标是预测"下一个词"！**

```
当模型看到 "我" 时，它应该预测 "爱"
当模型看到 "我 爱" 时，它应该预测 "学习"
当模型看到 "我 爱 学习" 时，它应该预测 "<END>"

所以输入和目标要错开一位！
```

## 五、前向传播：模型怎么计算

### 步骤1：词嵌入

把 token 索引变成向量：

```
输入：[1, 2, 3]  （"我 爱 学习"的索引）

词嵌入：
  索引1 → [0.2, -0.5, 0.8, ...]  （"我"的向量）
  索引2 → [0.1, 0.3, -0.2, ...]  （"爱"的向量）
  索引3 → [-0.4, 0.6, 0.1, ...]  （"学习"的向量）

输出：3 × d_model 的矩阵
```

### 步骤2：添加位置编码

```
词嵌入 + 位置编码 = 最终输入

"我"的输入 = [0.2, -0.5, 0.8, ...] + [0, 0.1, 0, ...]
           = [0.2, -0.4, 0.8, ...]
```

### 步骤3：通过解码器层

**关键：掩码注意力！**

```
在位置0（"我"）：
  注意力只能看到 "我" 自己
  不能看到 "爱" 和 "学习"

在位置1（"爱"）：
  注意力能看到 "我" 和 "爱"
  不能看到 "学习"

在位置2（"学习"）：
  注意力能看到 "我"、"爱"、"学习"
```

### 步骤4：输出层

```
解码器输出 → 线性层 → logits

logits 形状：(batch_size, seq_len, vocab_size)

比如：
  位置0 的 logits: [0.1, 0.5, 0.3, 0.05, 0.05]  （5个词的概率）
  位置1 的 logits: [0.05, 0.1, 0.6, 0.2, 0.05]
  位置2 的 logits: [0.02, 0.03, 0.05, 0.1, 0.8]
```

## 六、损失函数（数学原理！）

### 为什么需要损失函数？

**损失函数衡量模型预测得有多"差"**

```
模型预测：P("爱" | "我") = 0.5  （50%的概率）
实际答案："爱" 是正确的

损失 = -log(0.5) = 0.693

如果模型预测得更准：
  P("爱" | "我") = 0.9
  损失 = -log(0.9) = 0.105  （损失更小！）
```

### 交叉熵损失（Cross-Entropy Loss）

**交叉熵是分类问题的标准损失函数**

#### 数学公式

对于单个样本：

$$L = -\log P(y|x)$$

其中：
- $y$ 是正确答案（目标词的索引）
- $P(y|x)$ 是模型预测正确答案的概率

#### 用具体数字理解

假设词表大小 = 5，目标词索引 = 1（"爱"）

```
模型输出 logits = [0.1, 0.5, 0.3, 0.05, 0.05]

步骤1：Softmax 转换成概率
  softmax([0.1, 0.5, 0.3, 0.05, 0.05])
  = [0.09, 0.45, 0.27, 0.09, 0.09]
  
  注意：0.09 + 0.45 + 0.27 + 0.09 + 0.09 ≈ 1.0

步骤2：取目标词对应的概率
  P(目标=1) = 0.45

步骤3：计算损失
  L = -log(0.45) = 0.799
```

#### Softmax 的数学公式

$$\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{V} e^{z_j}}$$

其中：
- $z_i$ 是第 i 个位置的 logits
- $V$ 是词表大小

**用具体数字算一遍**：

```
logits = [0.1, 0.5, 0.3, 0.05, 0.05]

步骤1：计算 e^z
  e^0.1 = 1.105
  e^0.5 = 1.649
  e^0.3 = 1.350
  e^0.05 = 1.051
  e^0.05 = 1.051

步骤2：求和
  1.105 + 1.649 + 1.350 + 1.051 + 1.051 = 6.206

步骤3：计算概率
  P(0) = 1.105 / 6.206 = 0.178
  P(1) = 1.649 / 6.206 = 0.266
  P(2) = 1.350 / 6.206 = 0.218
  P(3) = 1.051 / 6.206 = 0.169
  P(4) = 1.051 / 6.206 = 0.169
  
  总和 = 0.178 + 0.266 + 0.218 + 0.169 + 0.169 ≈ 1.0
```

### 整个序列的损失

**整个序列的损失 = 所有位置损失的平均值**

$$L_{total} = \frac{1}{T} \sum_{t=1}^{T} L_t$$

其中：
- $T$ 是序列长度
- $L_t$ 是第 t 个位置的损失

#### 用具体例子理解

```
序列："我 爱 学习"（长度=3）

位置0: 输入="我", 目标="爱"
  模型预测 P("爱"|"我") = 0.45
  损失 = -log(0.45) = 0.799

位置1: 输入="我 爱", 目标="学习"
  模型预测 P("学习"|"我 爱") = 0.6
  损失 = -log(0.6) = 0.511

位置2: 输入="我 爱 学习", 目标="<END>"
  模型预测 P("<END>"|"我 爱 学习") = 0.8
  损失 = -log(0.8) = 0.223

总损失 = (0.799 + 0.511 + 0.223) / 3 = 0.511
```

### 用 PyTorch 代码实现

```python
import torch
import torch.nn.functional as F

def compute_loss(logits, targets):
    """
    计算交叉熵损失
    
    参数：
    - logits: 模型输出，形状 (batch_size, seq_len, vocab_size)
    - targets: 目标索引，形状 (batch_size, seq_len)
    """
    # 获取维度信息
    batch_size, seq_len, vocab_size = logits.shape
    
    # 展平 logits 和 targets
    # logits: (batch_size, seq_len, vocab_size) → (batch_size * seq_len, vocab_size)
    logits_flat = logits.view(-1, vocab_size)
    
    # targets: (batch_size, seq_len) → (batch_size * seq_len,)
    targets_flat = targets.view(-1)
    
    # 计算交叉熵损失
    # PyTorch 的 cross_entropy 会自动做 softmax
    loss = F.cross_entropy(logits_flat, targets_flat)
    
    return loss
```

**为什么用 `view(-1, vocab_size)`？**

```
原始形状：(batch_size=2, seq_len=3, vocab_size=5)
  → 每个 batch 有 3 个位置，每个位置有 5 个词的 logits

展平后：(batch_size * seq_len=6, vocab_size=5)
  → 变成 6 个独立的分类问题

这样可以一次性计算所有位置的损失！
```

## 七、反向传播：怎么更新参数

### 梯度下降的基本思想

**目标**：让损失变小

```
损失函数 L(w) 衡量模型预测得有多差

我们的目标：找到一组参数 w，使得 L(w) 最小

方法：沿着损失函数的"下坡"方向走
```

### 梯度是什么？

**梯度 = 损失函数对参数的导数**

$$\nabla L = \frac{\partial L}{\partial w}$$

**梯度告诉我们**：
- 如果梯度 > 0：增加参数，损失会增加
- 如果梯度 < 0：增加参数，损失会减少

### 用具体例子理解

假设有一个参数 w，当前值 = 1.0

```
当前损失 L = 0.5

梯度 dL/dw = 0.3（正数）

说明：增加 w，损失会增加

所以我们应该减小 w！

更新公式：w_new = w_old - learning_rate × gradient
         w_new = 1.0 - 0.01 × 0.3
         w_new = 1.0 - 0.003
         w_new = 0.997

更新后，损失应该变小了！
```

### 学习率的作用

**学习率（learning_rate）控制更新的步长**

```
学习率太大（比如 1.0）：
  w_new = 1.0 - 1.0 × 0.3 = 0.7
  步子太大，可能跳过最优解！

学习率太小（比如 0.0001）：
  w_new = 1.0 - 0.0001 × 0.3 = 0.99997
  步子太小，训练太慢！

学习率合适（比如 0.01）：
  w_new = 1.0 - 0.01 × 0.3 = 0.997
  步子刚好，稳步下降！
```

### 完整的反向传播过程

```python
# 前向传播
logits = model(input_ids)  # 计算预测
loss = compute_loss(logits, target_ids)  # 计算损失

# 反向传播
optimizer.zero_grad()  # 清空之前的梯度
loss.backward()        # 计算梯度（自动求导）
optimizer.step()       # 更新参数
```

**每一步的作用**：

```
1. optimizer.zero_grad()
   为什么要清空？
   因为 PyTorch 默认会累加梯度
   如果不清空，梯度会越来越大！

2. loss.backward()
   从损失开始，反向计算每个参数的梯度
   使用链式法则（Chain Rule）

3. optimizer.step()
   根据梯度更新参数
   w = w - lr × gradient
```

## 八、优化器：Adam

### 为什么用 Adam？

**Adam = Adaptive Moment Estimation（自适应矩估计）**

Adam 的优点：
1. **自适应学习率**：不同参数有不同的学习率
2. **动量**：记住之前的梯度方向，加速收敛
3. **稳定**：对学习率不太敏感

### Adam 的核心思想

**动量（Momentum）**：

```
想象一个球在山坡上滚动：
- 球会记住之前的滚动方向
- 如果一直往一个方向滚，会加速
- 如果方向变了，会减速

这就是动量！
```

**自适应学习率**：

```
对于经常更新的参数：学习率小一点（避免震荡）
对于不常更新的参数：学习率大一点（加速学习）
```

### 用 PyTorch 实现

```python
import torch.optim as optim

# 创建 Adam 优化器
optimizer = optim.Adam(
    model.parameters(),  # 要优化的参数
    lr=0.001,           # 学习率
    betas=(0.9, 0.999), # 动量参数
    eps=1e-8            # 防止除以0的小数
)
```

## 九、学习率调度

### 为什么需要学习率调度？

```
训练初期：
  - 模型什么都不懂
  - 需要大学习率，快速学习

训练后期：
  - 模型已经学得差不多了
  - 需要小学习率，精细调整
```

### Warmup + Cosine Decay

**Warmup（预热）**：学习率从 0 线性增加到最大值

**Cosine Decay（余弦衰减）**：学习率按余弦曲线下降

```
学习率变化曲线：

学习率
  ↑
  │    /\
  │   /  \
  │  /    \___
  │ /         \___
  │/              \___
  └─────────────────────→ 训练步数
     ↑           ↑
   Warmup      衰减
```

### 数学公式

**Warmup 阶段**（step < warmup_steps）：

$$lr = lr_{max} \times \frac{step}{warmup\_steps}$$

**Cosine Decay 阶段**（step >= warmup_steps）：

$$lr = lr_{max} \times \frac{1}{2} \times (1 + \cos(\pi \times \frac{step - warmup\_steps}{total\_steps - warmup\_steps}))$$

### 用具体数字理解

```
参数：
  lr_max = 0.001
  warmup_steps = 100
  total_steps = 1000

步数=0:   lr = 0.001 × (0/100) = 0
步数=50:  lr = 0.001 × (50/100) = 0.0005
步数=100: lr = 0.001 × (100/100) = 0.001  （最大！）
步数=550: lr = 0.001 × 0.5 × (1 + cos(π × 450/900)) = 0.0005
步数=1000: lr = 0.001 × 0.5 × (1 + cos(π)) = 0
```

### 代码实现

```python
import math

def get_lr(step, warmup_steps, total_steps, lr_max):
    """获取当前学习率"""
    if step < warmup_steps:
        # Warmup 阶段：线性增加
        return lr_max * step / warmup_steps
    else:
        # Cosine Decay 阶段：余弦衰减
        progress = (step - warmup_steps) / (total_steps - warmup_steps)
        return lr_max * 0.5 * (1 + math.cos(math.pi * progress))
```

## 十、完整的训练代码

### 完整的训练循环

```python
def train_gpt(model, train_data, num_epochs=10, lr_max=0.001):
    """
    训练 GPT 模型
    
    参数：
    - model: GPT 模型
    - train_data: 训练数据（DataLoader）
    - num_epochs: 训练轮数
    - lr_max: 最大学习率
    """
    
    # 创建优化器
    optimizer = torch.optim.Adam(model.parameters(), lr=lr_max)
    
    # 计算总步数
    total_steps = num_epochs * len(train_data)
    warmup_steps = total_steps // 10  # 前10%用于warmup
    
    # 训练循环
    model.train()
    
    step = 0
    for epoch in range(num_epochs):
        total_loss = 0
        
        for batch in train_data:
            # 获取输入和目标
            input_ids = batch["input_ids"]      # (batch_size, seq_len)
            target_ids = batch["target_ids"]    # (batch_size, seq_len)
            
            # 更新学习率
            lr = get_lr(step, warmup_steps, total_steps, lr_max)
            for param_group in optimizer.param_groups:
                param_group['lr'] = lr
            
            # 前向传播
            logits = model(input_ids)  # (batch_size, seq_len, vocab_size)
            
            # 计算损失
            loss = compute_loss(logits, target_ids)
            
            # 反向传播
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
            step += 1
        
        # 打印训练信息
        avg_loss = total_loss / len(train_data)
        print(f"Epoch {epoch+1}, Loss: {avg_loss:.4f}, LR: {lr:.6f}")
```

### 第三步：前向传播 - 位置编码

#### 3.1 位置编码的作用

**词嵌入只能表示词的意思，不能表示位置**

"我爱学习"和"学习爱我"的词相同，但意思不同！
位置编码告诉模型每个词在哪个位置。

#### 3.2 计算位置编码（完整公式）

位置编码公式：

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

$$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

其中：
- pos = 位置（0, 1, 2, ...）
- i = 维度索引（0, 1, 2, ...）
- d_model = 向量维度

#### 3.3 用具体数字计算位置编码

```

  i=0: sin(0 / 10000^(0/4)) = sin(0) = 0.0
  i=0: cos(0 / 10000^(0/4)) = cos(0) = 1.0
  i=1: sin(0 / 10000^(2/4)) = sin(0) = 0.0
  i=1: cos(0 / 10000^(2/4)) = cos(0) = 1.0

  i=0: cos(1 / 10000^(0/4)) = cos(1) = 0.540
  i=1: sin(1 / 10000^(2/4)) = sin(1/10) = 0.0998
  i=1: cos(1 / 10000^(2/4)) = cos(1/10) = 0.995

  i=0: sin(2 / 10000^(0/4)) = sin(2) = 0.909
```

#### 5.2 层归一化（完整计算）

**层归一化公式：**

$$\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}} \times \gamma + \beta$$

其中：
- μ = 均值
- σ² = 方差
- ε = 极小数（防止除以0）
- γ, β = 可学习的参数（这里假设 γ=1, β=0）

```
计算位置0的层归一化：

输入: [0.400, 1.000, 1.600, 2.200]

步骤1：计算均值 μ
  μ = (0.400 + 1.000 + 1.600 + 2.200) / 4
    = 5.200 / 4
    = 1.300

步骤2：计算方差 σ²
  σ² = [(0.400-1.300)² + (1.000-1.300)² + (1.600-1.300)² + (2.200-1.300)²] / 4
     = [(-0.900)² + (-0.300)² + (0.300)² + (0.900)²] / 4
     = [0.810 + 0.090 + 0.090 + 0.810] / 4
     = 1.800 / 4
     = 0.450

步骤3：计算标准差 √σ²
  √0.450 = 0.671

步骤4：归一化
  x̂[0] = (0.400 - 1.300) / 0.671 = -0.900 / 0.671 = -1.341
  x̂[1] = (1.000 - 1.300) / 0.671 = -0.300 / 0.671 = -0.447
  x̂[2] = (1.600 - 1.300) / 0.671 = 0.300 / 0.671 = 0.447
  x̂[3] = (2.200 - 1.300) / 0.671 = 0.900 / 0.671 = 1.341

位置0归一化后: [-1.341, -0.447, 0.447, 1.341]

步骤2：方差
  σ² = [(1.673-1.590)² + (1.584-1.590)² + (0.054-1.590)² + (3.050-1.590)²] / 4
     = [0.083² + (-0.006)² + (-1.536)² + 1.460²] / 4
     = [0.007 + 0.000 + 2.359 + 2.132] / 4
     = 4.498 / 4 = 1.125

步骤3：标准差
  √1.125 = 1.061

步骤4：归一化
  x̂[0] = (1.673 - 1.590) / 1.061 = 0.083 / 1.061 = 0.078
  x̂[1] = (1.584 - 1.590) / 1.061 = -0.006 / 1.061 = -0.006
  x̂[2] = (0.054 - 1.590) / 1.061 = -1.536 / 1.061 = -1.448
  x̂[3] = (3.050 - 1.590) / 1.061 = 1.460 / 1.061 = 1.376

位置1归一化后: [0.078, -0.006, -1.448, 1.376]

────────────────────────────────────────────────────────────

计算位置2的层归一化：

输入: [1.097, 0.739, 0.594, 1.871]

步骤1：均值
  μ = (1.097 + 0.739 + 0.594 + 1.871) / 4 = 4.301 / 4 = 1.075

步骤2：方差
  σ² = [(1.097-1.075)² + (0.739-1.075)² + (0.594-1.075)² + (1.871-1.075)²] / 4
     = [0.022² + (-0.336)² + (-0.481)² + 0.796²] / 4
     = [0.000 + 0.113 + 0.231 + 0.634] / 4
     = 0.978 / 4 = 0.245

步骤3：标准差
  √0.245 = 0.495

步骤4：归一化
  x̂[0] = (1.097 - 1.075) / 0.495 = 0.022 / 0.495 = 0.044
  x̂[1] = (0.739 - 1.075) / 0.495 = -0.336 / 0.495 = -0.679

  x̂[3] = (1.871 - 1.075) / 0.495 = 0.796 / 0.495 = 1.608

位置2归一化后: [0.044, -0.679, -0.972, 1.608]

────────────────────────────────────────────────────────────
```

```
│  第三步：位置编码                                           │
│    用sin/cos函数计算位置编码，加到词嵌入上                   │
│                           ↓                                 │
│  第四步：解码器层（掩码自注意力）                           │
│    4.1 计算Q、K、V（输入×权重矩阵）                        │
│    4.2 计算注意力分数（Q×K^T）                             │
│    4.3 缩放（除以√d_k）                                    │
│    4.4 应用掩码（不能看的位置设为-∞）                       │
│    4.5 Softmax得到注意力权重                               │
│    4.6 加权求和得到输出（权重×V）                          │
│                           ↓                                 │
│  第五步：残差连接 + 层归一化                                │
│    输出 = 注意力输出 + 原始输入                             │
│    然后标准化（均值=0，方差=1）                             │
│                           ↓                                 │
│  第六步：前馈网络                                           │
│    线性层 → ReLU → 线性层                                  │
│    然后再次残差连接 + 层归一化                              │
│                           ↓                                 │
│  第七步：输出层                                             │
│    线性层把d_model维映射到vocab_size维                      │
│    得到logits（每个词的分数）                               │
│                           ↓                                 │
│  第八步：计算损失                                           │
│    Softmax把logits转换成概率                               │
│    交叉熵损失 = -log(P(目标))                              │
│    总损失 = 所有位置损失的平均值                            │
│                           ↓                                 │
│  第九步：反向传播 + 更新参数                                │
│    计算梯度（概率 - one_hot(目标)）                        │
│    更新参数（w = w - lr × gradient）                       │
│                           ↓                                 │
│  第十步：重复第一步到第九步                                 │
│    直到损失足够小                                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 十二、总结

### GPT 训练的关键点

| 环节 | 说明 | 数学原理 |
|------|------|----------|
| 解码器 | 只能从左到右看 | 掩码注意力 |
| 训练目标 | 预测下一个词 | $P(w_t \| w_1,...,w_{t-1})$ |
| 损失函数 | 交叉熵 | $L = -\log P(y\|x)$ |
| 优化器 | Adam | 自适应学习率 + 动量 |
| 学习率调度 | Warmup + Cosine | 先增后减 |

### 关键数学公式

```
Softmax:     P(i) = e^(z_i) / Σ e^(z_j)
交叉熵:      L = -log P(目标)
梯度下降:    w_new = w_old - lr × ∂L/∂w
学习率调度:  lr = lr_max × (warmup 或 cosine)
```

## 练习答案

### 练习1答案

1. **区别**：
   - 编码器：双向注意力，能看到所有输入
   - 解码器：单向注意力，只能看到前面的内容

2. **为什么用掩码**：
   - 因为生成时后面的词还不存在
   - 不能让模型"偷看"未来的词

### 练习2答案

```
logits = [0.1, 0.2, 0.5, 0.2]

1. Softmax:
   e^0.1 = 1.105
   e^0.2 = 1.221
   e^0.5 = 1.649
   e^0.2 = 1.221
   总和 = 5.196
   
   P = [0.213, 0.235, 0.317, 0.235]

2. 目标词索引=2 的概率:
   P(2) = 0.317

3. 交叉熵损失:
   L = -log(0.317) = 1.149
```

### 练习3答案

1. **错开一位**：
   - 因为目标是"下一个词"
   - 输入"我"时，目标应该是"爱"
   - 所以输入和目标要错开一位

2. **反向传播的作用**：
   - 计算每个参数对损失的贡献（梯度）
   - 告诉我们怎么调整参数来减小损失
