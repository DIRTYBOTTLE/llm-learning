## 一、模型剪枝

### 什么是剪枝？

```
剪枝 = 去掉模型中不重要的参数

类比：
  修剪树枝：去掉枯枝，保留主干
  剪枝模型：去掉不重要的参数，保留重要的

效果：
  模型变小
  速度变快
  效果可能略有下降
```

### 剪枝的类型

```
┌─────────────────────────────────────────────────────────────┐
│                    剪枝的类型                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 非结构化剪枝                                           │
│     - 去掉单个权重                                         │
│     - 模型大小不变（只是变成稀疏矩阵）                     │
│     - 需要专门的硬件支持                                   │
│                                                             │
│  2. 结构化剪枝                                             │
│     - 去掉整个神经元或层                                   │
│     - 模型真正变小                                         │
│     - 不需要专门的硬件                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 非结构化剪枝

```
非结构化剪枝的过程：

原始权重矩阵：
  [0.5, 0.01, -0.3, 0.002, 0.8]
     ↑      ↑            ↑
    保留   去掉         去掉

剪枝后（设阈值=0.05）：
  [0.5, 0, -0.3, 0, 0.8]

特点：
  - 去掉绝对值小于阈值的权重
  - 模型变成稀疏矩阵
  - 需要专门的稀疏计算库
```

### 结构化剪枝

```
结构化剪枝的过程：

原始模型：
  Layer1: 100 个神经元
  Layer2: 100 个神经元

剪枝后（去掉 50% 不重要的神经元）：
  Layer1: 50 个神经元
  Layer2: 50 个神经元

特点：
  - 模型真正变小
  - 不需要专门的硬件
  - 可以直接使用普通 GPU
```

### 剪枝的代码示例

```python
import torch
import torch.nn as nn
import torch.nn.utils.prune as prune

# 创建一个简单的模型
class SimpleModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear1 = nn.Linear(100, 50)
        self.linear2 = nn.Linear(50, 10)
    
    def forward(self, x):
        x = torch.relu(self.linear1(x))
        x = self.linear2(x)
        return x

model = SimpleModel()

# 查看剪枝前的参数
def count_nonzero(model):
    """计算非零参数数量"""
    total = 0
    nonzero = 0
    for param in model.parameters():
        total += param.numel()
        nonzero += torch.count_nonzero(param).item()
    return total, nonzero

total, nonzero = count_nonzero(model)
print(f"剪枝前: 总参数={total}, 非零参数={nonzero}")

# 非结构化剪枝（剪掉 50% 的权重）
prune.l1_unstructured(model.linear1, name='weight', amount=0.5)

total, nonzero = count_nonzero(model)
print(f"剪枝后: 总参数={total}, 非零参数={nonzero}")
```

## 二、知识蒸馏

### 什么是蒸馏？

```
蒸馏 = 用大模型（教师）教小模型（学生）

类比：
  老师（大模型）知识渊博
  学生（小模型）学习老师的精华
  
结果：
  学生虽然小，但学到了老师的精髓
```

### 蒸馏的原理

```
┌─────────────────────────────────────────────────────────────┐
│                    蒸馏的原理                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 教师模型                                               │
│     - 大模型，效果好                                       │
│     - 输出软标签（概率分布）                               │
│                                                             │
│  2. 学生模型                                               │
│     - 小模型，速度快                                       │
│     - 学习教师的输出                                       │
│                                                             │
│  3. 训练过程                                               │
│     - 教师模型对训练数据生成软标签                         │
│     - 学生模型学习这些软标签                               │
│     - 学生模型也学习真实标签                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 软标签 vs 硬标签

```
硬标签（真实标签）：
  输入："1+1等于几？"
  标签："2"（one-hot: [0, 0, 1, 0, 0]）

软标签（教师输出）：
  输入："1+1等于几？"
  教师输出：[0.01, 0.02, 0.90, 0.05, 0.02]
  
  软标签包含了更多信息：
    - "2" 是正确答案（0.90）
    - "3" 也有一定概率（0.05）
    - "4" 也有一定概率（0.02）
```

### 蒸馏的代码示例

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DistillationLoss(nn.Module):
    """蒸馏损失函数"""
    
    def __init__(self, temperature=4.0, alpha=0.5):
        super().__init__()
        self.temperature = temperature
        self.alpha = alpha
    
    def forward(self, student_logits, teacher_logits, labels):
        """
        参数：
          student_logits: 学生模型的输出
          teacher_logits: 教师模型的输出
          labels: 真实标签
        """
        # 软标签损失（KL 散度）
        soft_loss = F.kl_div(
            F.log_softmax(student_logits / self.temperature, dim=-1),
            F.softmax(teacher_logits / self.temperature, dim=-1),
            reduction='batchmean'
        ) * (self.temperature ** 2)
        
        # 硬标签损失（交叉熵）
        hard_loss = F.cross_entropy(student_logits, labels)
        
        # 总损失
        loss = self.alpha * soft_loss + (1 - self.alpha) * hard_loss
        
        return loss

# 使用示例
teacher_model = ...  # 教师模型（大）

distill_loss = DistillationLoss(temperature=4.0, alpha=0.5)

# 训练循环

    input_ids, labels = batch
    
    # 教师模型生成软标签
    with torch.no_grad():
        teacher_logits = teacher_model(input_ids)
    
    # 学生模型前向传播
    student_logits = student_model(input_ids)
    
    # 计算蒸馏损失
    loss = distill_loss(student_logits, teacher_logits, labels)
```

## 三、蒸馏的实际应用

### 使用 Hugging Face 进行蒸馏

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, Trainer, TrainingArguments

# 加载教师模型
teacher_model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-2-7b-hf")

# 加载学生模型（较小的模型）
student_model = AutoModelForCausalLM.from_pretrained("TinyLlama/TinyLlama-1.1B-Chat-v1.0")

# 准备训练数据
train_dataset = ...

# 自定义 Trainer
class DistillationTrainer(Trainer):
    def compute_loss(self, model, inputs, return_outputs=False):
        labels = inputs.pop("labels")
        
        # 学生模型前向传播
        outputs = model(**inputs)
        student_logits = outputs.logits
        
        # 教师模型前向传播
        with torch.no_grad():
            teacher_outputs = self.teacher_model(**inputs)
            teacher_logits = teacher_outputs.logits
        
        # 计算蒸馏损失
        loss = self.distill_loss(student_logits, teacher_logits, labels)
        
        return (loss, outputs) if return_outputs else loss

# 训练
trainer = DistillationTrainer(
    model=student_model,
    teacher_model=teacher_model,
    args=TrainingArguments(output_dir="./output", num_train_epochs=3),
    train_dataset=train_dataset,
)

trainer.train()
```

## 四、剪枝 vs 蒸馏 vs 量化

```
┌─────────────────────────────────────────────────────────────┐
│              剪枝 vs 蒸馏 vs 量化 对比                      │
├─────────────────────────────────────────────────────────────┤
│  方法      原理              效果          难度              │
├─────────────────────────────────────────────────────────────┤
│  量化      降低数值精度      缩小2-4倍     简单              │
│  剪枝      去掉不重要参数    缩小1.5-2倍   中等              │
│  蒸馏      用大模型教小模型  缩小5-10倍    困难              │
└─────────────────────────────────────────────────────────────┘
```

### 选择建议

```
快速优化：量化
  - 简单，效果好
  - 不需要训练

进一步优化：量化 + 剪枝
  - 在量化基础上进一步压缩
  
追求极致：蒸馏
  - 效果最好
  - 但需要大量计算和数据
```

## 五、总结

### 剪枝和蒸馏的关键点

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 剪枝 | 去掉不重要参数 | 简单、快速 | 效果有限 |
| 蒸馏 | 用大模型教小模型 | 效果最好 | 复杂、成本高 |

### 实际应用

```
常见的优化组合：

1. 量化（最常用）
   FP16 → INT4
   
2. 量化 + 剪枝
   先量化，再剪枝
   
3. 蒸馏 + 量化
   先蒸馏得到小模型，再量化
```

## 练习答案

### 练习1答案

1. **剪枝**：去掉模型中不重要的参数，让模型变小。
2. **区别**：
   - 非结构化剪枝：去掉单个权重，模型变成稀疏矩阵
   - 结构化剪枝：去掉整个神经元或层，模型真正变小

### 练习2答案

1. **蒸馏**：用大模型（教师）教小模型（学生）。
2. **软标签 vs 硬标签**：
   - 硬标签：真实标签（one-hot）
   - 软标签：教师输出的概率分布（包含更多信息）
3. **为什么效果好**：软标签包含了更多信息（比如"2"和"3"都可能），学生可以学到更丰富的知识。
