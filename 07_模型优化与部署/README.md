# 第7章 模型优化与部署

> 模型训练好了，怎么让它跑得更快、更省资源？

## 学习目标

学完这章，你能：
- 理解模型量化的数学原理
- 掌握模型剪枝的方法
- 理解知识蒸馏的核心思想
- 部署模型到生产环境

## 章节内容

### 7.1 模型量化

INT8 量化公式：
```
x_q = round(x / scale) + zero_point
x̄ = (x_q - zero_point) * scale
```

### 7.2 模型剪枝

结构化剪枝 vs 非结构化剪枝：
- 非结构化：随机删除权重
- 结构化：删除整个神经元/层

### 7.3 知识蒸馏

软标签和温度参数：
```
L = α * L_CE(y, p) + (1-α) * L_KD(p_s/T, p_t/T)

其中：
- p_s: 学生模型的预测
- p_t: 教师模型的预测
- T: 温度参数
```

### 7.4 KV Cache

缓存机制：
- 避免重复计算历史 token 的 Key 和 Value
- 内存计算：2 × n_layers × n_heads × d_head × seq_len × batch_size

### 7.5 推理优化

Flash Attention：
- 减少内存访问
- 分块计算注意力

vLLM：
- PagedAttention
- 动态批处理

### 7.6 部署到生产环境

ONNX, TensorRT：
- 模型格式转换
- 推理加速
