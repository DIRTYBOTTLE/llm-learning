# 第7章 模型优化与部署

> 训练好的模型怎么用起来？这一章教你优化和部署大模型！

- 理解为什么需要模型优化

- 模型太大，显存不够

- 部署成本高

### 7.2 模型量化

**对应文件**：`02_模型量化.md`

## 学习建议

1. **理解原理**：先理解为什么需要优化
2. **动手实践**：尝试量化和部署模型
3. **对比效果**：比较优化前后的效果
4. **选择合适的方法**：根据场景选择优化方法
