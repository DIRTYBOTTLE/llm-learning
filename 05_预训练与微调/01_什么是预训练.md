# 5.1 什么是预训练

> 预训练就像上大学：广泛学习各种知识，为以后的专业发展打基础。

- GPT 的任务是预测下一个词
- GPT 需要大量的文本数据来训练

**但是，GPT 具体是怎么训练的？训练数据从哪来？**

## 二、预训练的定义

### 什么是预训练？

**预训练 = 在大规模数据上训练模型，让它学会通用的知识**

```
预训练的过程：

输入：海量文本数据
  - 书籍：小说、教科书、百科全书
  - 网页：新闻、博客、论坛
  - 代码：GitHub 上的代码
  - 维基百科：知识性文本
  - ...

训练：让模型预测下一个词（语言模型任务）

输出：一个"懂很多"的基座模型
```

### 预训练的目标

**目标：让模型学会语言的规律和知识**

```
模型学到的东西：

1. 语法知识
   - "我"后面通常接"是"、"爱"、"想"...
   - "因为"后面通常接"所以"
   
2. 语义知识
   - "猫"和"狗"都是宠物
   - "北京"是中国的首都
   
3. 世界知识
   - "太阳从东方升起"
   - "水在100度沸腾"
   
4. 推理能力
   - "如果A>B，B>C，那么A>C"
```

### 数据规模

```
┌─────────────────────────────────────────────────────────────┐
│                    预训练数据规模                            │
├─────────────────────────────────────────────────────────────┤
│  模型        数据量          数据来源                       │

│  GPT-4       未公开          更大规模                       │
└─────────────────────────────────────────────────────────────┘
```

### 数据处理流程

```
原始数据
    ↓
1. 收集：从互联网、书籍、代码库收集
    ↓
2. 清洗：去除噪声、重复、低质量内容
    ↓
3. 去重：去除重复的文本
    ↓
4. 过滤：去除有害、不安全的内容
    ↓
5. 分词：Tokenization
    ↓
6. 切分：切分成固定长度的序列
    ↓
最终数据：准备好用于训练
```

## 四、预训练的过程

### 用具体例子理解

```
训练数据："今天天气真好，适合出去玩。"

步骤1：分词
  "今天" "天气" "真" "好" "，" "适合" "出去" "玩" "。"

步骤2：构造训练样本（预测下一个词）
  输入："今天" → 目标："天气"
  输入："今天 天气" → 目标："真"
  输入："今天 天气 真" → 目标："好"
  输入："今天 天气 真 好" → 目标："，"
  ...

步骤3：模型预测
  模型看到 "今天"，预测下一个词
  一开始预测得很差（随机）
  通过训练，预测越来越准

步骤4：计算损失、反向传播、更新参数
  （和第4章学的一样）
```

## 五、预训练的结果：基座模型

### 什么是基座模型？

**基座模型（Base Model）= 预训练完成的模型**

```
基座模型的特点：

1. 懂很多知识
   - 知道"北京是中国首都"
   - 知道"太阳从东方升起"
   
2. 会写文章
   - 能续写故事
   - 能写代码
   
3. 但是不会"对话"
   - 你问它问题，它可能继续写文章
   - 它不知道怎么"回答问题"
   
4. 可能会"胡说八道"
   - 因为它只是在"续写文本"
   - 不知道什么是"正确答案"
```

### 基座模型的例子

```
你：请介绍一下北京。

基座模型可能会输出：
  "请介绍一下北京。北京是中国的首都，位于华北平原..."
  （它在续写，不是在回答）

或者：
  "请介绍一下北京。上海是中国的经济中心..."
  （它可能跑题了）

因为它只是在"预测下一个词"，不是在"回答问题"！
```

## 六、为什么需要预训练？

### 从零开始训练 vs 预训练

```
从零开始训练（不用预训练）：
  - 需要大量标注数据
  - 训练时间长
  - 效果可能不好
  
预训练 + 微调：
  - 预训练用大量无标注数据（便宜）
  - 微调用少量标注数据（贵）
  - 效果通常更好
```

### 预训练的好处

```
1. 学到通用知识
   模型在预训练时学到了语言的规律
   这些知识可以迁移到下游任务
   
2. 减少标注数据需求
   微调只需要少量标注数据
   因为模型已经有了基础知识
   
3. 提高效果
   预训练模型通常比从零训练效果好
   因为它有了更好的"起点"
```

## 七、总结

### 预训练的关键点

| 概念 | 说明 |
|------|------|
| 定义 | 在大规模数据上训练，学习通用知识 |
| 数据 | 海量文本（书籍、网页、代码...） |
| 目标 | 预测下一个词（语言模型） |
| 结果 | 基座模型（懂很多，但不会对话） |
| 成本 | 非常昂贵（数百万美元） |

### 预训练的比喻

```
预训练 = 上大学
  - 广泛学习各种知识
  - 打好基础
  - 为以后的专业发展做准备

基座模型 = 大学毕业生
  - 懂很多知识
  - 但还没有专业技能
  - 需要进一步培训（微调）
```
