# 5.5 预训练 vs 微调

> 预训练和微调就像上大学和工作培训，目标不同，方法不同。

## 从你已经知道的开始

在前几节，你学了：
- 预训练：广泛学习各种知识
- 微调：学习特定任务的技能

**这一节，我们来详细对比预训练和微调！**

---

## 一、核心区别

```
┌─────────────────────────────────────────────────────────────┐
│                    预训练 vs 微调                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  预训练（Pre-training）：                                    │

│    结果：基座模型                                           │

│    结果：助手模型                                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 二、详细对比

### 数据的区别

```
预训练数据：
  - 数据量：万亿 token
  - 来源：书籍、网页、代码
  - 标注：无标注（自监督）
  - 成本：低（可以从互联网获取）
  
微调数据：
  - 数据量：几万到几百万条
  - 来源：人工构造的对话、问答
  - 标注：有标注（人工标注）
  - 成本：高（需要人工标注）
```

### 目标的区别

```
预训练目标：
  - 学习语言的规律
  - 学习世界的知识
  - 学习推理能力
  - 目标是"懂很多"

微调目标：
  - 学会对话
  - 学会回答问题
  - 学会遵循指令
  - 目标是"会做事"
```

### 成本的区别

```
预训练成本：
  - 计算成本：数百万美元
  - 时间成本：数周到数月
  - 数据成本：相对较低
  - 只有大公司能做

微调成本：
  - 计算成本：数百到数千美元
  - 时间成本：数小时到数天
  - 数据成本：相对较高（需要标注）
  - 个人也可以做
```

## 四、用比喻理解

### 上大学 vs 工作培训

```
上大学（预训练）：
  - 学习各种知识
  - 时间长（4年）
  - 成本高（学费）
  - 目标：打好基础

工作培训（微调）：
  - 学习特定技能
  - 时间短（几周）
  - 成本低
  - 目标：胜任工作
```

### 学语言的过程

```
学英语（预训练）：
  - 学习语法、词汇
  - 阅读大量文章
  - 目标：能读懂英语

专业英语（微调）：
  - 学习医学英语、法律英语
  - 练习特定场景
  - 目标：能用英语做专业工作
```

## 五、预训练和微调的关系

### 必须先预训练吗？

```
理论上：可以从零开始训练
  - 不用预训练，直接用任务数据训练
  - 但需要大量数据，效果可能不好

实际上：通常先预训练再微调
  - 预训练学到通用知识
  - 微调只需要少量数据
  - 效果通常更好
```

### 为什么不只用微调？

```
如果只用微调（不用预训练）：

问题1：需要大量标注数据
  - 预训练用万亿 token
  - 微调只用几万条
  - 如果不用预训练，需要几万亿条标注数据（不现实）

问题2：效果可能不好
  - 预训练学到的知识可以迁移到下游任务
  - 不用预训练，模型需要从零学习

问题3：成本太高
  - 从零训练需要更多计算资源
  - 预训练+微调更经济
```

## 六、实际例子

### 训练一个医学助手

```
方法1：从零训练（不推荐）
  - 收集大量医学文本
  - 训练一个语言模型
  - 成本：非常高
  - 效果：可能不好

方法2：预训练+微调（推荐）
  - 使用开源的预训练模型（如 LLaMA）
  - 用医学对话数据微调
  - 成本：相对较低
  - 效果：通常更好
```

### 训练一个法律助手

```
步骤1：选择预训练模型
  - 比如：LLaMA-7B（开源，70亿参数）

步骤2：收集法律数据
  - 法律问答数据
  - 法律文书数据
  - 法律案例数据

步骤3：微调
  - 用法律数据微调 LLaMA
  - 训练几小时到几天

步骤4：测试
  - 测试法律助手的效果
  - 调整参数，再次微调
```

### 预训练和微调的关系

```

├─────────────────────────────────────────────────────────────┤
```

### 一句话总结

```
预训练：广泛学习，打基础（贵但必要）
微调：专业培训，学技能（便宜且有效）

先预训练，再微调，是最经济、最有效的方法！
```

## 练习答案

### 练习1答案

1. **数据区别**：预训练用海量无标注文本，微调用少量有标注数据。
2. **目标区别**：预训练学习通用知识，微调学习特定任务。
3. **成本区别**：预训练成本高（数百万美元），微调成本低（数百到数千美元）。

### 练习2答案

1. **为什么不只用微调**：需要大量标注数据（不现实），效果可能不好，成本太高。
2. **关系**：预训练打基础，微调学技能，先预训练再微调是最经济有效的方法。
