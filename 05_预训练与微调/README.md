# 第5章 预训练与微调

> 训练一个大模型就像培养一个学生：先上大学（预训练），再专业培训（微调）。

## 学习目标

学完这章，你能：
- 理解什么是预训练，为什么要预训练
- 理解什么是微调，为什么要微调
- 理解预训练和微调的区别
- 了解常见的预训练方法（自监督学习）
- 了解常见的微调方法（SFT、RLHF）
- 理解为什么 ChatGPT 这么聪明

## 前置知识（你已经学过）

- **第3章**：Transformer 架构、编码器、解码器
- **第4章**：语言模型、GPT 的训练和生成
