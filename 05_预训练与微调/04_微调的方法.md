### 步骤4：训练循环

```python
def train(model, train_dataloader, optimizer, num_epochs):
    """训练循环"""
    
    model.train()
    
    for epoch in range(num_epochs):
        total_loss = 0
        
        for batch in train_dataloader:
            # 1. 前向传播
            outputs = model(
                input_ids=batch["input_ids"],
                attention_mask=batch["attention_mask"],
                labels=batch["labels"]
            )
            loss = outputs.loss
            
            # 2. 反向传播
            loss.backward()
            
            # 3. 更新参数
            optimizer.step()
            optimizer.zero_grad()
            
            total_loss += loss.item()
        
        # 打印训练信息
        avg_loss = total_loss / len(train_dataloader)
        print(f"Epoch {epoch+1}, Loss: {avg_loss:.4f}")
```

## 三、全量微调（Full Fine-tuning）

### 什么是全量微调？

**全量微调 = 更新模型的所有参数**

```
全量微调的过程：

输入：预训练模型（比如 LLaMA-7B，70亿参数）
训练：更新所有70亿个参数
输出：微调后的模型

特点：
  - 更新所有参数
  - 效果最好
  - 需要大量显存
  - 训练时间长
```

### 用具体数字理解

```
LLaMA-7B 的参数量：70亿（7B）

全量微调的显存需求：
  模型参数：7B × 4字节 = 28GB（FP32）
  优化器状态：28GB × 2 = 56GB（Adam需要存动量和方差）
  梯度：28GB
  激活值：约10-20GB
  
  总计：约120-130GB 显存

需要 A100 80GB 显卡，至少2张！
```

### 全量微调的代码

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

# 加载模型
model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-2-7b-hf")
tokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-2-7b-hf")

# 所有参数都参与训练
for param in model.parameters():
    param.requires_grad = True  # 允许梯度计算

# 训练
optimizer = AdamW(model.parameters(), lr=2e-5)
train(model, train_dataloader, optimizer, num_epochs=3)
```

### 全量微调的优缺点

```
优点：
  1. 效果最好
  2. 可以充分适应新任务
  3. 不需要额外的参数

缺点：
  1. 需要大量显存（120GB+）
  2. 训练时间长
  3. 成本高
  4. 容易过拟合（如果数据少）
```

## 四、LoRA（低秩适应）

### 什么是 LoRA？

**LoRA = Low-Rank Adaptation（低秩适应）**

```
LoRA 的核心思想：
  不更新所有参数
  而是在原始权重旁边加一个小的"旁路"
  只训练这个旁路

用比喻理解：
  全量微调：重新装修整个房子
  LoRA：只在墙上挂几幅画
```

### LoRA 的数学原理

```
原始的权重更新：
  W_new = W_old + ΔW
  
  其中 ΔW 和 W_old 形状相同（比如 768×768）
  参数量 = 768 × 768 = 589,824

LoRA 的权重更新：
  W_new = W_old + ΔW
  ΔW = A × B
  
  其中 A 是 (768, r)，B 是 (r, 768)
  r 是一个很小的数（比如 8）
  
  参数量 = 768 × 8 + 8 × 768 = 12,288
  
  参数量减少了 48 倍！
```

### 用具体数字理解

```
假设原始权重矩阵 W：768 × 768

全量微调：
  需要更新的参数 = 768 × 768 = 589,824

LoRA（r=8）：
  A 矩阵：768 × 8 = 6,144
  B 矩阵：8 × 768 = 6,144
  需要更新的参数 = 6,144 + 6,144 = 12,288
  
  参数量 = 589,824 / 12,288 = 48倍
  减少了 48 倍！
```

### LoRA 的图示

```
┌─────────────────────────────────────────────────────────────┐
│                    LoRA 结构                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  原始权重 W（冻结，不更新）                                 │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                                                     │   │
│  │                    W (768×768)                      │   │
│  │                                                     │   │
│  └─────────────────────────────────────────────────────┘   │
│                          ↓                                  │
│                      输出 = W × 输入                        │
│                                                             │
│  ─────────────────────────────────────────────────────────  │
│                                                             │
│  LoRA 旁路（可训练）                                        │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                                                     │   │
│  │  输入 → A (768×8) → B (8×768) → ΔW → 输出          │   │
│  │                                                     │   │
│  └─────────────────────────────────────────────────────┘   │
│                          ↓                                  │
│                      输出 = A × B × 输入                    │
│                                                             │
│  ─────────────────────────────────────────────────────────  │
│                                                             │
│  最终输出 = W × 输入 + A × B × 输入                        │
│           = (W + A × B) × 输入                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### LoRA 的代码实现

```python
from peft import LoraConfig, get_peft_model, TaskType

# LoRA 配置
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,  # 任务类型：因果语言模型
    r=8,                           # 低秩矩阵的秩
    lora_alpha=32,                 # 缩放因子
    lora_dropout=0.05,             # Dropout 概率
    target_modules=["q_proj", "v_proj"],  # 要应用 LoRA 的模块
)

# 加载基座模型
model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-2-7b-hf")

# 应用 LoRA
model = get_peft_model(model, lora_config)

# 查看可训练参数量
model.print_trainable_parameters()
# 输出：trainable params: 4,194,304 || all params: 6,742,609,920 || trainable%: 0.06

# 训练（只更新 LoRA 参数）
optimizer = AdamW(model.parameters(), lr=2e-4)
train(model, train_dataloader, optimizer, num_epochs=3)
```

### LoRA 的参数选择

```
r（秩）的选择：
  - r=4：参数最少，效果一般
  - r=8：常用，平衡效果和效率
  - r=16：参数较多，效果更好
  - r=64：参数很多，接近全量微调

lora_alpha（缩放因子）：
  - 通常设为 r 的 2-4 倍
  - 比如 r=8，lora_alpha=32

target_modules（目标模块）：
  - 通常选择注意力层的 Q、K、V、O
  - 也可以加上前馈网络
```

### LoRA 的优缺点

```
优点：
  1. 参数量小（减少几十倍）
  2. 显存需求低
  3. 训练速度快
  4. 效果接近全量微调
  5. 可以保存多个 LoRA，切换任务

缺点：
  1. 效果可能略差于全量微调
  2. 需要选择合适的 r 和 target_modules
```

## 五、QLoRA（量化 LoRA）

### 什么是 QLoRA？

**QLoRA = Quantized LoRA（量化 LoRA）**

```
QLoRA 的核心思想：
  在 LoRA 基础上，把基座模型量化成 4-bit
  进一步减少显存需求

用比喻理解：
  全量微调：用高清图片训练（占空间大）
  LoRA：用压缩图片训练（占空间小）
  QLoRA：用更小的压缩图片训练（占空间更小）
```

### QLoRA 的技术细节

```
┌─────────────────────────────────────────────────────────────┐
│                    QLoRA 的三个技术                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 4-bit 量化（NF4）                                       │
│     - 把模型权重从 FP16 量化成 4-bit                       │
│     - 显存减少 4 倍                                         │
│                                                             │
│  2. 双重量化（Double Quantization）                        │
│     - 对量化常数再进行量化                                 │
│     - 进一步节省显存                                        │
│                                                             │
│  3. 分页优化器（Paged Optimizers）                          │
│     - 使用 CPU 内存来处理显存溢出                           │
│     - 避免显存不足崩溃                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 显存需求对比

```
┌─────────────────────────────────────────────────────────────┐
│              显存需求对比（LLaMA-7B）                        │
├─────────────────────────────────────────────────────────────┤
│  方法          模型精度    显存需求    能用的显卡           │
├─────────────────────────────────────────────────────────────┤
│  全量微调      FP16        120GB+      A100 80GB × 2       │
│  LoRA          FP16        28GB        A100 40GB           │
│  QLoRA         4-bit       6GB         RTX 3060            │
└─────────────────────────────────────────────────────────────┘

QLoRA 让个人电脑也能微调大模型！
```

### QLoRA 的代码实现

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training

# 量化配置
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,                  # 4-bit 量化
    bnb_4bit_quant_type="nf4",          # NF4 量化类型
    bnb_4bit_compute_dtype=torch.float16,  # 计算精度
    bnb_4bit_use_double_quant=True,     # 双重量化
)

# 加载量化模型
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-7b-hf",
    quantization_config=bnb_config,
    device_map="auto",
)

# 准备模型用于 k-bit 训练
model = prepare_model_for_kbit_training(model)

# LoRA 配置
lora_config = LoraConfig(
    r=8,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
)

# 应用 LoRA
model = get_peft_model(model, lora_config)

# 查看可训练参数
model.print_trainable_parameters()
# 输出：trainable params: 4,194,304 || all params: 3,508,801,536 || trainable%: 0.12

# 训练
optimizer = AdamW(model.parameters(), lr=2e-4)
train(model, train_dataloader, optimizer, num_epochs=3)
```

### QLoRA 的显存计算

```
LLaMA-7B 的 QLoRA 显存需求：

模型权重（4-bit）：7B × 0.5字节 = 3.5GB
LoRA 参数：4M × 2字节 = 8MB
优化器状态：4M × 4字节 × 2 = 32MB
梯度：4M × 2字节 = 8MB
激活值：约1-2GB

总计：约5-6GB

一张 RTX 3060（12GB）就够了！
```

## 七、SFT（有监督微调）

### 什么是 SFT？

**SFT = Supervised Fine-Tuning（有监督微调）**

```
SFT 的过程：

输入：基座模型 + 人工标注的数据

数据格式：
  输入：用户的问题
  输出：期望的回答（人工标注）

训练：让模型学习输入→输出的映射

输出：助手模型
```

### SFT 的训练数据

```
训练数据（人工标注）：

样本1：
  输入："你好"
  输出："你好！有什么可以帮你的吗？"

样本2：
  输入："1+1等于几？"
  输出："1+1等于2。"

样本3：
  输入："请介绍一下北京。"
  输出："北京是中国的首都，也是中国的政治、文化中心。"
```

### SFT 的损失计算

```python
def compute_sft_loss(logits, labels, input_length):
    """
    计算 SFT 损失
    
    关键：只计算回答部分的损失，不计算问题部分
    """
    # logits: 模型输出，形状 (batch_size, seq_len, vocab_size)
    # labels: 目标，形状 (batch_size, seq_len)
    # input_length: 输入（问题）的长度
    
    # 把问题部分的标签设为 -100（不计算损失）
    labels[:, :input_length] = -100
    
    # 计算损失（PyTorch 会忽略 -100 的位置）
    loss = F.cross_entropy(
        logits.view(-1, logits.size(-1)),
        labels.view(-1),
        ignore_index=-100
    )
    
    return loss
```

## 八、RLHF（人类反馈强化学习）

### RLHF 的三个阶段

```
┌─────────────────────────────────────────────────────────────┐
│                    RLHF 的三个阶段                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  阶段1：SFT（有监督微调）                                   │
│    - 用人工标注的数据训练                                   │
│    - 得到一个初始的助手模型                                 │
│                                                             │
│  阶段2：训练奖励模型（Reward Model）                        │
│    - 收集人类对回答的排序                                   │
│    - 训练一个模型来预测人类偏好                             │
│                                                             │
│  阶段3：强化学习优化（PPO）                                 │
│    - 用奖励模型来指导助手模型的训练                         │
│    - 让助手模型生成更符合人类偏好的回答                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 阶段2：训练奖励模型

```
收集人类偏好数据：

问题："请介绍一下北京。"

回答A："北京是中国的首都，有着悠久的历史。"
回答B："北京是中国的首都，位于华北平原，面积16410平方公里..."
回答C："北京是一个城市。"

人类排序：A > B > C（A最好，C最差）

训练奖励模型：
  输入：问题 + 回答
  输出：分数（越高越好）
  
  损失函数：让 A 的分数 > B 的分数 > C 的分数
```

### 阶段3：PPO 优化

```
PPO（Proximal Policy Optimization）的过程：

1. 助手模型生成回答
2. 奖励模型给回答打分
3. 用 PPO 算法更新助手模型
   - 如果分数高：鼓励这种回答方式
   - 如果分数低：避免这种回答方式

重复这个过程，直到助手模型的回答让奖励模型给高分
```

## 九、总结

### 微调方法对比

| 方法 | 核心思想 | 优点 | 缺点 |
|------|----------|------|------|
| 全量微调 | 更新所有参数 | 效果最好 | 显存需求大 |
| LoRA | 只更新低秩旁路 | 显存需求小 | 效果略差 |
| QLoRA | 量化 + LoRA | 显存需求最小 | 精度损失 |
| SFT | 用标注数据训练 | 简单直接 | 需要标注数据 |
| RLHF | 用人类反馈优化 | 更符合偏好 | 实现复杂 |

### 选择建议

```
┌─────────────────────────────────────────────────────────────┐
│                    如何选择微调方法？                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  有充足资源（多张 A100）：                                   │
│    → 全量微调 + SFT + RLHF                                  │
│                                                             │
│  资源有限（单张 A100）：                                     │
│    → LoRA + SFT                                             │
│                                                             │
│  个人电脑（RTX 3060）：                                      │
│    → QLoRA + SFT                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 练习题

### 练习1：理解 LoRA

请用自己的话解释：
1. LoRA 的核心思想是什么？
2. 为什么 LoRA 能减少参数量？
3. LoRA 的 r 参数怎么选择？

### 练习2：理解 QLoRA

请用自己的话解释：
1. QLoRA 和 LoRA 有什么区别？
2. 为什么 QLoRA 能进一步减少显存需求？
3. 个人电脑能用 QLoRA 微调多大的模型？

### 练习3：选择方法

如果你有以下条件，应该选择什么微调方法？
1. 有 8 张 A100 80GB 显卡
2. 有 1 张 A100 40GB 显卡
3. 有 1 张 RTX 3060 12GB 显卡

---

## 练习答案

### 练习1答案

1. **核心思想**：不更新所有参数，而是在原始权重旁边加一个小的"旁路"，只训练这个旁路。
2. **为什么减少参数**：原始权重矩阵是 d×d，LoRA 把它分解成 d×r 和 r×d（r 很小），参数量从 d² 减少到 2dr。
3. **r 的选择**：r=4 参数最少效果一般，r=8 常用，r=16 效果更好，r=64 接近全量微调。

### 练习2答案

1. **区别**：QLoRA 在 LoRA 基础上把基座模型量化成 4-bit，进一步减少显存。
2. **为什么更省显存**：模型权重从 FP16（2字节）变成 4-bit（0.5字节），显存减少 4 倍。
3. **能微调多大模型**：RTX 3060 12GB 可以微调 7B 模型。

### 练习3答案

1. **8 张 A100**：可以全量微调 70B 模型，或者用 LoRA 微调更大的模型
2. **1 张 A100 40GB**：可以用 LoRA 微调 7B-13B 模型
3. **1 张 RTX 3060 12GB**：只能用 QLoRA 微调 7B 模型
