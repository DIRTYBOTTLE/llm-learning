## 二、有监督微调（SFT）

### 什么是 SFT？

**SFT = Supervised Fine-Tuning（有监督微调）**

```
SFT 的过程：

输入：基座模型 + 人工标注的数据

数据格式：
  输入：用户的问题
  输出：期望的回答（人工标注）

训练：让模型学习输入→输出的映射

输出：助手模型
```

### 用具体例子理解

```
训练数据（人工标注）：

样本1：
  输入："你好"
  输出："你好！有什么可以帮你的吗？"

样本2：
  输入："1+1等于几？"
  输出："1+1等于2。"

样本3：
  输入："请介绍一下北京。"
  输出："北京是中国的首都，也是中国的政治、文化中心。"

模型学习：
  看到"你好" → 回复"你好！有什么可以帮你的吗？"
  看到"1+1等于几？" → 回复"1+1等于2。"
```

### SFT 的代码示例

```python
def sft_training_step(model, batch):
    """
    SFT 的一个训练步骤
    """
    # 输入：用户的问题
    input_ids = batch["input_ids"]
    # 目标：期望的回答
    target_ids = batch["target_ids"]
    
    # 前向传播
    logits = model(input_ids)
    
    # 计算损失（只计算回答部分）
    loss = cross_entropy(logits, target_ids)
    
    # 反向传播
    loss.backward()
    
    return loss
```

### SFT 的优缺点

```
优点：
  1. 简单直接
  2. 效果明显
  3. 容易实现

缺点：
  1. 需要大量人工标注数据
  2. 标注质量影响模型质量
  3. 难以覆盖所有情况
```

## 三、人类反馈强化学习（RLHF）

### 什么是 RLHF？

**RLHF = Reinforcement Learning from Human Feedback（人类反馈强化学习）**

```
RLHF 的核心思想：
  不只是告诉模型"正确答案"
  而是告诉模型"哪个答案更好"

用比喻理解：
  SFT：老师告诉你答案是什么
  RLHF：老师告诉你两个答案哪个更好
```

### RLHF 的三个阶段

```
┌─────────────────────────────────────────────────────────────┐
│                    RLHF 的三个阶段                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  阶段1：SFT（有监督微调）                                   │
│    - 用人工标注的数据训练                                   │
│    - 得到一个初始的助手模型                                 │
│                                                             │
│  阶段2：训练奖励模型（Reward Model）                        │
│    - 收集人类对回答的排序                                   │
│    - 训练一个模型来预测人类偏好                             │
│                                                             │
│  阶段3：强化学习优化（PPO）                                 │
│    - 用奖励模型来指导助手模型的训练                         │
│    - 让助手模型生成更符合人类偏好的回答                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 阶段2：训练奖励模型

```
收集人类偏好数据：

问题："请介绍一下北京。"

回答A："北京是中国的首都，有着悠久的历史。"
回答B："北京是中国的首都，位于华北平原，面积16410平方公里..."
回答C："北京是一个城市。"

人类排序：A > B > C（A最好，C最差）

训练奖励模型：
  输入：问题 + 回答
  输出：分数（越高越好）
  
  奖励模型学习：
    A 的分数应该最高
    B 的分数次之
    C 的分数最低
```

### 阶段3：强化学习优化

```
用奖励模型指导助手模型训练：

1. 助手模型生成回答
2. 奖励模型给回答打分
3. 根据分数调整助手模型
   - 分数高 → 鼓励这种回答方式
   - 分数低 → 避免这种回答方式

重复这个过程，直到助手模型生成的回答让奖励模型给高分
```

### RLHF 的代码示例

```python
def rlhf_training_step(assistant_model, reward_model, prompt):
    """
    RLHF 的一个训练步骤
    """
    # 1. 助手模型生成回答
    response = assistant_model.generate(prompt)
    
    # 2. 奖励模型给回答打分
    reward = reward_model.score(prompt, response)
    
    # 3. 用强化学习更新助手模型
    # PPO 算法更新
    loss = -reward  # 最大化奖励 = 最小化负奖励
    loss.backward()
    
    return reward
```

### RLHF 的优缺点

```
优点：
  1. 更符合人类偏好
  2. 可以优化"难以量化"的目标
  3. ChatGPT 就是用 RLHF 训练的

缺点：
  1. 实现复杂
  2. 需要大量人类反馈数据
  3. 训练不稳定
```

## 四、指令微调（Instruction Tuning）

### 什么是指令微调？

**指令微调 = 用指令数据训练模型，让它学会遵循指令**

```
指令数据的例子：

指令："请用三句话总结以下文章。"
文章："北京是中国的首都..."
输出："北京是中国首都，历史悠久，文化丰富。"

指令："请翻译成英文。"
输入："我爱学习。"
输出："I love learning."

指令："请判断以下句子的情感。"
输入："这部电影太好看了！"
输出："正面情感"
```

### 指令微调的好处

```
1. 通用性
   一个模型可以处理多种任务
   不需要为每个任务训练一个模型
   
2. 灵活性
   用户可以用自然语言描述任务
   模型会按照指令执行
   
3. 泛化能力
   模型可以处理没见过的指令
   因为它学会了"遵循指令"这个能力
```

## 六、总结

### 微调方法对比

| 方法 | 核心思想 | 优点 | 缺点 |
|------|----------|------|------|
| SFT | 用标注数据训练 | 简单直接 | 需要大量标注 |
| RLHF | 用人类反馈优化 | 更符合人类偏好 | 实现复杂 |
| 指令微调 | 用指令数据训练 | 通用灵活 | 需要指令数据 |

### ChatGPT 的成功秘诀

```
ChatGPT = 预训练 + SFT + RLHF

预训练：学习语言和知识
SFT：学会对话
RLHF：更符合人类偏好
```

## 练习答案

### 练习1答案

1. **SFT**：用人工标注的数据训练模型，让它学会输入→输出的映射。
2. **RLHF**：用人类反馈来优化模型，让它更符合人类偏好。
3. **区别**：SFT 直接告诉模型答案，RLHF 告诉模型哪个答案更好。

### 练习2答案

1. **三个阶段**：SFT → 训练奖励模型 → 强化学习优化。
2. **为什么更好**：RLHF 可以优化"难以量化"的目标（如"回答是否友好"），而 SFT 只能优化"正确性"。
