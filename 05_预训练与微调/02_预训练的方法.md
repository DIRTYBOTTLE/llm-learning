## 一、自监督学习

### 什么是自监督学习？

**自监督学习 = 从数据本身构造标签，不需要人工标注**

```
传统监督学习：
  数据：图片
  标签：人工标注（"这是猫"）
  问题：需要大量人工标注，成本高

自监督学习：
  数据：文本
  标签：从数据本身构造（下一个词）
  优点：不需要人工标注，成本低
```

### 用具体例子理解

```
原始文本："今天 天气 真 好"

自监督学习构造标签：
  输入："今天" → 标签："天气"（自动构造）
  输入："今天 天气" → 标签："真"（自动构造）
  输入："今天 天气 真" → 标签："好"（自动构造）

不需要人工标注！标签就是下一个词！
```

## 三、因果语言模型（CLM）

### 核心思想

**给定前面的词，预测下一个词**

```
训练数据："我 爱 学习 深度 学习"

构造训练样本：
  输入："我" → 目标："爱"
  输入："我 爱" → 目标："学习"
  输入："我 爱 学习" → 目标："深度"
  输入："我 爱 学习 深度" → 目标："学习"
```

### 数学公式

$$P(w_t | w_1, w_2, ..., w_{t-1})$$

**大白话**：在知道前面所有词的情况下，下一个词是什么？

### 用代码理解

```python
def prepare_clm_data(tokens):
    """
    准备因果语言模型的训练数据
    """
    input_ids = tokens[:-1]   # 去掉最后一个
    target_ids = tokens[1:]    # 去掉第一个
    
    return input_ids, target_ids

# 例子
tokens = [1, 2, 3, 4, 5]  # "我 爱 学习 深度 学习"
input_ids, target_ids = prepare_clm_data(tokens)
# input_ids = [1, 2, 3, 4]    "我 爱 学习 深度"
# target_ids = [2, 3, 4, 5]   "爱 学习 深度 学习"
```

### CLM 的特点

```
优点：
  1. 适合生成任务（写文章、对话）
  2. 可以自回归生成（一个词一个词生成）
  3. GPT 系列使用，效果很好

缺点：
  1. 只能看前面的词（单向）
  2. 对于理解任务（如分类），效果可能不如 MLM
```

## 四、掩码语言模型（MLM）

### 核心思想

**把一些词遮住，让模型预测被遮住的词**

```
原始文本："我 爱 学习 深度 学习"

随机遮住一些词：
  输入："我 [MASK] 学习 [MASK] 学习"
  目标："爱" 和 "深度"

模型需要根据上下文，预测被遮住的词！
```

### 具体例子

```
句子："今天 天气 真 好 ， 适合 出去 玩 。"

随机选择15%的词进行遮掩：
  选择："天气"、"好"、"出去"

构造训练样本：
  输入："今天 [MASK] 真 [MASK] ， 适合 [MASK] 玩 。"
  目标：预测 "天气"、"好"、"出去"
```

### 数学公式

$$P(w_{mask} | w_{其他所有词})$$

**大白话**：在知道其他所有词的情况下，被遮住的词是什么？

### 用代码理解

```python
def prepare_mlm_data(tokens, mask_prob=0.15):
    """
    准备掩码语言模型的训练数据
    """
    input_ids = tokens.copy()
    target_ids = [-100] * len(tokens)  # -100 表示不计算损失
    
    for i in range(len(tokens)):
        if random.random() < mask_prob:
            # 80% 的概率替换为 [MASK]
            if random.random() < 0.8:
                input_ids[i] = MASK_TOKEN
            # 10% 的概率替换为随机词
            elif random.random() < 0.5:
                input_ids[i] = random.randint(0, vocab_size)
            # 10% 的概率保持不变
            # （什么都不做）
            
            target_ids[i] = tokens[i]  # 目标是原始词
    
    return input_ids, target_ids

# 例子
tokens = [1, 2, 3, 4, 5]  # "我 爱 学习 深度 学习"
input_ids, target_ids = prepare_mlm_data(tokens)
# 可能的结果：
# input_ids = [1, MASK, 3, MASK, 5]  "我 [MASK] 学习 [MASK] 学习"
# target_ids = [-100, 2, -100, 4, -100]  只计算被遮住位置的损失
```

### MLM 的特点

```
优点：
  1. 能看到所有上下文（双向）
  2. 适合理解任务（分类、问答）
  3. BERT 使用，效果很好

缺点：
  1. 不能直接用于生成
  2. 训练时 [MASK] 在实际使用时不存在
  3. 只有15%的词被预测，训练效率较低
```

## 五、CLM vs MLM 对比

```
┌─────────────────────────────────────────────────────────────┐
│                    CLM vs MLM 对比                          │
├─────────────────────────────────────────────────────────────┤
│  特点            CLM（GPT）          MLM（BERT）            │
├─────────────────────────────────────────────────────────────┤
│  预测目标        下一个词            被遮住的词             │
│  注意力方向      单向（左→右）       双向                   │
│  适合任务        生成                理解                   │
│  代表模型        GPT、LLaMA          BERT、RoBERTa          │
│  生成能力        ✓ 强                ✗ 弱                   │
│  理解能力        ✓ 中等              ✓ 强                   │
└─────────────────────────────────────────────────────────────┘
```

## 六、用具体例子对比

### 任务1：文本生成（写文章）

```
提示："从前有座山，山里有座庙，"

CLM（GPT）：
  输入："从前有座山，山里有座庙，"
  输出："庙里有个老和尚在讲故事。"
  
  ✓ 擅长！因为它就是预测下一个词

MLM（BERT）：
  不擅长，因为它不是为生成设计的
```

### 任务2：情感分类（判断好评差评）

```
输入："这部电影太好看了！"

CLM（GPT）：
  可以做，但效果可能不如 MLM
  
MLM（BERT）：
  擅长！因为它能看到整个句子的上下文
  
  输出："正面情感"
```

## 七、总结

### 预训练方法的关键点

| 方法 | 核心思想 | 代表模型 | 适合任务 |
|------|----------|----------|----------|
| CLM | 预测下一个词 | GPT | 生成 |
| MLM | 预测被遮住的词 | BERT | 理解 |

### 自监督学习的好处

```
1. 不需要人工标注
   标签从数据本身构造
   
2. 可以用海量数据
   互联网上有大量文本
   
3. 学到通用知识
   模型学会了语言的规律
```
