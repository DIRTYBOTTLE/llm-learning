# 第8章 综合项目

> 把前面学的全部用上，完成一个完整的 LLM 项目。

## 学习目标

学完这章，你能：
- 独立完成一个完整的 LLM 微调项目
- 从数据准备到模型部署的全流程
- 评估和优化模型性能

## 章节内容

### 8.1 项目规划

确定目标：
- 任务类型：文本分类、问答、生成
- 模型选择：GPT-2, LLaMA, BERT
- 数据来源：公开数据集、自定义数据

### 8.2 数据准备

数据处理流程：
1. 数据收集
2. 数据清洗
3. 数据格式化
4. Tokenization

### 8.3 模型训练

训练流程：
1. 加载预训练模型
2. 配置训练参数
3. 训练和验证
4. 模型保存

### 8.4 评估与部署

评估指标：
- 准确率、精确率、召回率、F1
- BLEU, ROUGE（生成任务）

部署方式：
- API 服务
- Web 应用
- 边缘设备

- 所有前置章节

## 预计学习时间

- 项目实践：8-12 小时
- 代码调试：4-6 小时
- 优化迭代：4-6 小时
