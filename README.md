# 大模型从零教程

从数学原理到代码实现，手把手带你从零构建大语言模型。

## 适用人群

- **完全零基础**，无需机器学习背景
- **想深入理解 LLM 原理**的开发者
- **希望在 Apple M1 上实践**的工程师

## 特色

- **数学原理优先**：每个概念都从数学公式推导开始
- **生活化比喻**：用"带伞决策"讲神经元，用"找最小值"讲梯度下降
- **ASCII 图表**：不用复杂数学符号，一目了然
- **手写代码**：先用 NumPy 理解原理，再用 PyTorch 实践
- **从入门到精通**：循序渐进，每一步都有详细推导

## 环境要求

- Python 3.9+
- Apple M1 / 16GB RAM（或同等配置）

```bash
pip install numpy torch torchvision matplotlib
```

## 代码风格

每个核心概念提供两种实现：

| 文件类型 | 说明 | 示例 |
|----------|------|------|
| `xxx_from_scratch.py` | 纯 NumPy/PyTorch 手写 | 理解底层原理 |

## M1 适配

所有代码针对 Apple M1 / MPS 后端优化：

- 使用 `torch.device("mps")` 后端
- 手写示例控制在 10M-50M 参数
- 小 batch + 梯度累积模拟大 batch 训练
