# 微积分与梯度

> 大模型的"学习"本质上就是沿着梯度方向不断调整参数。理解微积分，就是理解模型如何从数据中学习。

## 1. 导数：变化的速率

### 什么是导数

导数描述的是函数在某一点的**瞬时变化率**。

想象你在开车：
- **位置函数** f(t) = 你在时刻 t 的位置
- **导数** f'(t) = 你在时刻 t 的**速度**（位置的变化率）

```
f(x) = x²

f'(x) = 2x

当 x = 3 时，f'(3) = 6
意思是：在 x=3 这个点，函数值以每单位 6 的速率增长
```

### 导数的几何意义

导数就是函数图像在某一点的**切线斜率**。

```
    y
    |        /
    |       / ← 切线（斜率 = 导数）
    |      /
    |     * ← 这一点的导数
    |    /
    |   /
    |  /
    | /
    |/__________ x
```

### 常见函数的导数

| 函数 | 导数 | 直觉 |
|------|------|------|
| f(x) = c | f'(x) = 0 | 常数不变 |
| f(x) = x | f'(x) = 1 | 线性增长 |
| f(x) = x² | f'(x) = 2x | 越大增长越快 |
| f(x) = sin(x) | f'(x) = cos(x) | 周期性变化 |
| f(x) = eˣ | f'(x) = eˣ | 自身就是变化率 |
| f(x) = ln(x) | f'(x) = 1/x | 越大增长越慢 |

## 2. 链式法则：复合函数的导数

### 什么是链式法则

如果一个函数是另一个函数的"嵌套"，那么导数就是**外层导数 × 内层导数**。

```
y = f(g(x))

dy/dx = f'(g(x)) × g'(x)
```

### 举例

```
y = (2x + 1)³

外层函数：u³，导数是 3u²
内层函数：2x + 1，导数是 2

dy/dx = 3(2x + 1)² × 2 = 6(2x + 1)²
```

### 为什么链式法则如此重要？

**反向传播算法就是链式法则的系统应用！**

神经网络有很多层，每一层都是一个函数。要计算最终损失对某一层参数的导数，就需要用链式法则"一层层往回传"。

```
Loss = f₃(f₂(f₁(x)))

dLoss/dx = f₃' × f₂' × f₁'   # 链式法则
```

## 3. 偏导数：多变量函数的导数

### 什么是偏导数

当函数有多个变量时，我们一次只对一个变量求导，其他变量视为常数。

```
f(x, y) = x² + y²

∂f/∂x = 2x   # 对 x 求导，y 看作常数
∂f/∂y = 2y   # 对 y 求导，x 看作常数
```

### 几何意义

偏导数表示函数在**某个方向**上的变化率。

```
∂f/∂x：函数在 x 方向上的斜率
∂f/∂y：函数在 y 方向上的斜率
```

## 4. 梯度：多变量的导数

### 什么是梯度

梯度是所有偏导数组成的**向量**，指向函数增长最快的方向。

```
∇f = [∂f/∂x, ∂f/∂y]

对于 f(x, y) = x² + y²
∇f = [2x, 2y]
```

### 梯度的几何意义

```
    y
    |     ↑ ∇f (梯度方向)
    |    /
    |   /
    |  * ← 当前点 (x, y)
    | /
    |/__________ x

梯度指向函数值增长最快的方向
-∇f 指向函数值下降最快的方向
```

### 梯度下降：模型学习的核心

**模型学习就是沿着负梯度方向不断调整参数**。

```
新参数 = 旧参数 - 学习率 × 梯度

θ_new = θ_old - η × ∇L(θ)

θ：模型参数
η：学习率（步长）
∇L(θ)：损失函数对参数的梯度
```

## 5. 损失函数的梯度

### 均方误差（MSE）

用于回归任务：

```
L = (1/n) × Σ(yᵢ - ŷᵢ)²

∂L/∂ŷ = (2/n) × (ŷ - y)
```

### 交叉熵（Cross Entropy）

用于分类任务：

```
L = -Σ yᵢ × log(ŷᵢ)

∂L/∂ŷ = -y/ŷ
```

## 7. 本章小结

| 概念 | 公式 | 在大模型中的应用 |
|------|------|-----------------|
| 导数 | f'(x) = lim(h→0) [f(x+h)-f(x)]/h | 理解变化率 |
| 链式法则 | dy/dx = f'(g(x)) × g'(x) | 反向传播算法 |
| 偏导数 | ∂f/∂x | 多参数梯度计算 |
| 梯度 | ∇f = [∂f/∂x, ∂f/∂y, ...] | 参数更新方向 |
| 梯度下降 | θ = θ - η × ∇L | 模型训练核心 |
