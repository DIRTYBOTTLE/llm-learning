# 概率论与信息论

> 大模型的本质是预测下一个词的概率分布。理解概率论，就是理解模型如何"思考"。

## 1. 概率基础

### 什么是概率

概率描述事件发生的**可能性大小**，取值范围是 [0, 1]。

```
P(正面) = 0.5    # 抛硬币出现正面的概率
P(反面) = 0.5    # 抛硬币出现反面的概率
P(六点) = 1/6    # 掷骰子出现六点的概率
```

### 概率的性质

```
1. 所有概率非负：P(A) ≥ 0
2. 所有可能结果的概率之和为 1：ΣP(Aᵢ) = 1
3. 互斥事件的概率可加：P(A∪B) = P(A) + P(B)
```

## 2. 条件概率与贝叶斯定理

### 条件概率

在事件 B 已经发生的条件下，事件 A 发生的概率：

```
P(A|B) = P(A∩B) / P(B)

例如：
- P(下雨) = 0.3
- P(带伞) = 0.4
- P(下雨∩带伞) = 0.25

P(下雨|带伞) = 0.25 / 0.4 = 0.625
意思是：如果看到有人带伞，天下雨的概率是 62.5%
```

### 贝叶斯定理

贝叶斯定理是条件概率的"翻转"：

```
P(A|B) = P(B|A) × P(A) / P(B)

- P(A|B)：后验概率（看到证据后更新的信念）
- P(B|A)：似然（假设 A 成立，看到 B 的概率）
- P(A)：先验概率（看到证据前的信念）
- P(B)：证据（B 发生的总概率）
```

### 贝叶斯定理的直觉

```
后验 ∝ 似然 × 先验

你对世界的初始信念（先验）+ 看到的新证据（似然）= 更新后的信念（后验）
```

**在大模型中**：模型看到前面的词（证据），更新对下一个词的预测（后验）。

## 3. 常见概率分布

### 离散分布

**伯努利分布**：只有两个结果（成功/失败）

```
P(X=1) = p    # 成功概率
P(X=0) = 1-p  # 失败概率
```

**二项分布**：n 次伯努利试验中成功的次数

```
P(X=k) = C(n,k) × pᵏ × (1-p)ⁿ⁻ᵏ
```

**多项分布**：n 次试验中每个结果出现的次数

```
P(X₁=k₁, X₂=k₂, ...) = n! / (k₁!×k₂!×...) × p₁ᵏ¹ × p₂ᵏ² × ...
```

### 连续分布

**正态分布（高斯分布）**：最常见的分布

```
f(x) = (1/√(2πσ²)) × e^(-(x-μ)²/(2σ²))

μ：均值（中心位置）
σ²：方差（离散程度）
```

```
    |
    |     ***
    |    *   *
    |   *     *
    |  *       *
    | *         *
    |*           *
    |_______________
         μ
```

**在大模型中**：权重初始化通常使用正态分布。

## 4. 期望与方差

### 期望（均值）

期望是随机变量的"平均值"：

```
离散：E(X) = Σ xᵢ × P(xᵢ)
连续：E(X) = ∫ x × f(x) dx

例如：掷骰子的期望
E = 1×(1/6) + 2×(1/6) + 3×(1/6) + 4×(1/6) + 5×(1/6) + 6×(1/6) = 3.5
```

### 方差

方差描述随机变量的"离散程度"：

```
Var(X) = E[(X - E(X))²]

方差越大，数据越分散
方差越小，数据越集中
```

### 标准差

标准差是方差的平方根，与原始数据同单位：

```
σ = √Var(X)
```

## 5. 信息论基础

### 信息量（自信息）

一个事件的"信息量"与其发生的概率成反比：

```
I(x) = -log₂(P(x))

概率越小的事件，信息量越大
- P(必然发生) = 1 → I = 0（没有新信息）
- P(极不可能) = 0.01 → I = 6.64 bits（信息量大）
```

### 熵

熵是随机变量的**平均信息量**：

```
H(X) = -Σ P(xᵢ) × log₂(P(xᵢ))

熵越大，不确定性越高
熵越小，确定性越高
```

**例子**：

```
公平硬币：H = -(0.5×log₂0.5 + 0.5×log₂0.5) = 1 bit
不公平硬币（P=0.9）：H = -(0.9×log₂0.9 + 0.1×log₂0.1) = 0.47 bits
```

### 交叉熵

交叉熵衡量用**一个分布去编码另一个分布**的效率：

```
H(P, Q) = -Σ P(xᵢ) × log₂(Q(xᵢ))

P：真实分布
Q：预测分布
```

**在大模型中**：交叉熵就是损失函数！

```
Loss = -Σ P(真实词) × log(Q(模型预测))

模型的目标就是让 Q 尽可能接近 P
```

### KL 散度

KL 散度衡量两个分布之间的**差异**：

```
KL(P||Q) = Σ P(xᵢ) × log(P(xᵢ)/Q(xᵢ))
          = H(P, Q) - H(P)

KL 散度 ≥ 0，当且仅当 P = Q 时等于 0
```

**在大模型中**：
- 知识蒸馏：让学生模型的分布接近教师模型的分布
- RLHF：让模型的输出分布接近人类偏好的分布

## 6. 极大似然估计

### 核心思想

给定一组观测数据，找到**最有可能产生这组数据的参数**。

```
假设数据 x₁, x₂, ..., xₙ 来自参数为 θ 的分布

似然函数：L(θ) = P(x₁|θ) × P(x₂|θ) × ... × P(xₙ|θ)

最优参数：θ* = argmax L(θ)
```

### 对数似然

为了计算方便，通常取对数：

```
log L(θ) = Σ log P(xᵢ|θ)

取对数不改变最大值点，但把乘法变成加法
```

### 与交叉熵的关系

**语言模型的训练就是极大似然估计！**

```
目标：最大化 P(w₁, w₂, ..., wₙ)

等价于：最小化 -log P(w₁, w₂, ..., wₙ)

这就是交叉熵损失！
```
