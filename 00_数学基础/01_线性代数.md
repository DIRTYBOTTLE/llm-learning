# 线性代数基础

> 大模型的每一个运算，本质上都是矩阵乘法。理解线性代数，就是理解大模型的"语言"。

## 1. 向量：方向与大小

### 什么是向量

向量是一组有序的数，可以表示空间中的一个点或一个方向。

```
v = [3, 4]    # 一个二维向量
```

### 向量的几何意义

想象一个平面坐标系，向量 `[3, 4]` 就是从原点 `(0,0)` 指向点 `(3,4)` 的箭头。

```
    y
    |
  4 |     * (3,4)
    |    /
    |   /
    |  /
    | /
    |/__________ x
   0
```

### 向量的基本运算

**加法**：对应位置相加

```
[1, 2] + [3, 4] = [4, 6]
```

**数乘**：每个元素乘以同一个数

```
2 * [1, 2] = [2, 4]
```

### 向量的长度（范数）

向量的长度就是从原点到该点的距离，用勾股定理计算：

```
‖v‖ = √(v₁² + v₂² + ... + vₙ²)

例如：‖[3, 4]‖ = √(3² + 4²) = √(9 + 16) = √25 = 5
```

## 2. 矩阵：数据的容器

### 什么是矩阵

矩阵是一个由数字组成的矩形网格。在深度学习中，**数据和参数都以矩阵形式存储**。

```
A = | 1  2  3 |    # 一个 2×3 矩阵（2行3列）
    | 4  5  6 |
```

### 矩阵的几何意义

矩阵可以看作是对空间的**变换**：

- **旋转**：把向量绕原点旋转一定角度
- **缩放**：把向量拉长或缩短
- **剪切**：把空间"推斜"

```
旋转矩阵（旋转 θ 角）：
| cos(θ)  -sin(θ) |
| sin(θ)   cos(θ) |
```

### 矩阵乘法：大模型的核心运算

矩阵乘法是大模型中**最频繁的运算**。规则是：**行 × 列，求和**。

```
A (2×3) × B (3×2) = C (2×2)

A = | 1  2  3 |    B = | 7  8 |
    | 4  5  6 |        | 9  10|
                        | 11 12|

C[0,0] = 1×7 + 2×9 + 3×11 = 7 + 18 + 33 = 58
C[0,1] = 1×8 + 2×10 + 3×12 = 8 + 20 + 36 = 64
C[1,0] = 4×7 + 5×9 + 6×11 = 28 + 45 + 66 = 139
C[1,1] = 4×8 + 5×10 + 6×12 = 32 + 50 + 72 = 154

C = | 58   64  |
    | 139  154 |
```

### 为什么矩阵乘法如此重要？

在神经网络中，每一层的计算本质上就是：

```
输出 = 输入 × 权重矩阵 + 偏置
```

这就是为什么理解矩阵乘法是理解大模型的第一步。

## 3. 转置：行列互换

矩阵转置就是把行变成列，列变成行。

```
A = | 1  2  3 |      Aᵀ = | 1  4 |
    | 4  5  6 |            | 2  5 |
                           | 3  6 |
```

### 转置的应用

在 Transformer 中，Q、K、V 的计算就用到了转置：

```
Q = X × W_Q
K = X × W_K    # W_Q, W_K, W_V 是权重矩阵
V = X × W_V
```

## 4. 点积：相似度的度量

两个向量的点积（内积）反映它们的**相似程度**。

```
a · b = a₁×b₁ + a₂×b₂ + ... + aₙ×bₙ

例如：
a = [1, 2, 3]
b = [4, 5, 6]
a · b = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
```

### 点积的几何意义

```
a · b = ‖a‖ × ‖b‖ × cos(θ)

其中 θ 是两个向量之间的夹角
```

- **点积 > 0**：夹角 < 90°，方向相似
- **点积 = 0**：夹角 = 90°，完全正交（无关）
- **点积 < 0**：夹角 > 90°，方向相反

**在 Attention 中**：Q 和 K 的点积就是用来衡量"query"和"key"的相似度。

## 5. 特征值与特征向量（直觉理解）

### 什么是特征向量

对于一个矩阵 A，如果某个向量 v 经过 A 变换后，**方向不变，只是长度变了**，那么 v 就是 A 的特征向量。

```
A × v = λ × v

A：变换矩阵
v：特征向量（方向不变的向量）
λ：特征值（缩放倍数）
```

### 直觉理解

想象一张纸被拉伸：

```
变换前：        变换后：
  →              →→→
  ↑              ↑
  
水平方向被拉伸了 3 倍，垂直方向不变
水平向量就是特征向量，特征值是 3
```

### 为什么重要？

- **主成分分析（PCA）**：用特征向量找到数据的主方向
- **理解矩阵性质**：特征值反映矩阵的"行为"
- **优化**：特征值影响训练的稳定性
