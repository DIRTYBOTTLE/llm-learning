# BERT vs GPT：两种 Transformer 的对比

> 理解这两种模型的区别，是理解现代 AI 的关键！

---

## 一、一句话总结

```
BERT = 只用编码器 = 理解语言 = "读懂文章"
GPT = 只用解码器 = 生成语言 = "写文章"
```

---

## 二、核心区别

### 1. 架构不同

**BERT（只用编码器）**：
```
输入："我 爱 学习"
  ↓
编码器（双向注意力）
  ↓
输出：每个词的新表示
```

**GPT（只用解码器）**：
```
输入："今天天气"
  ↓
解码器（单向注意力 + 掩码）
  ↓
输出：下一个词的概率
```

### 2. 注意力方向不同

**BERT：双向注意力**
```
"我"可以看到：我、爱、学习（全部）
"爱"可以看到：我、爱、学习（全部）
"学习"可以看到：我、爱、学习（全部）

每个词都能看到整个句子！
```

**GPT：单向注意力（带掩码）**
```
"我"只能看到：我
"爱"只能看到：我、爱
"学习"只能看到：我、爱、学习

每个词只能看到它前面的词！
```

### 3. 训练方式不同

**BERT：掩码语言模型（MLM）**
```
输入："我 [MASK] 学习"
目标：预测 [MASK] 是"爱"

特点：随机遮住一些词，让模型预测
```

**GPT：因果语言模型（CLM）**
```
输入："我 爱"
目标：预测下一个词"学习"

特点：从左到右，预测下一个词
```

### 4. 用途不同

**BERT：理解任务**
- 文本分类（判断情感）
- 命名实体识别（找人名、地名）
- 问答系统（回答问题）
- 相似度计算（两句话是否相似）

**GPT：生成任务**
- 文本生成（写文章）
- 对话系统（聊天）
- 代码生成（写代码）
- 翻译（生成另一种语言）

---

## 三、用表格对比

| 特性 | BERT | GPT |
|------|------|-----|
| 架构 | 只用编码器 | 只用解码器 |
| 注意力 | 双向（看前后文） | 单向（只看前面） |
| 训练方式 | 掩码语言模型 | 因果语言模型 |
| 用途 | 理解任务 | 生成任务 |
| 代表模型 | BERT, RoBERTa | GPT, ChatGPT |
| 输入输出 | 输入→理解→输出 | 输入→生成下一个词 |

---

## 四、为什么会有这两种模型？

### BERT 的设计哲学

**"理解比生成更重要"**

```
很多任务需要"理解"整个句子：
- 判断情感：需要理解整个句子的意思
- 回答问题：需要理解问题和答案的关系
- 找实体：需要理解上下文

所以 BERT 用双向注意力，能看前后文
```

### GPT 的设计哲学

**"生成是智能的体现"**

```
生成文本需要：
- 理解前面说了什么
- 预测接下来应该说什么
- 保持连贯性和逻辑性

所以 GPT 用单向注意力，从左到右生成
```

## 五、实际例子对比

### 例子1：情感分析

**任务**：判断"这部电影太棒了！"是正面还是负面

**BERT 的做法**：
```
输入："这部电影太棒了！"
  ↓
编码器（双向注意力）
  ↓
输出：[0.2, 0.8, 0.1, 0.9, 0.3]（每个词的表示）
  ↓
取 [CLS] token 的输出
  ↓
分类：正面（95%）
```

**GPT 的做法**：
```
输入："这部电影太棒了！情感是："
  ↓
解码器（单向注意力）
  ↓
输出："正面"的概率 = 92%
```

### 例子2：文本生成

**任务**：根据"今天天气"生成后续

**BERT 不能做这个任务**：
```
BERT 是理解模型，不是生成模型
它只能给每个词一个表示，不能生成新词
```

**GPT 的做法**：
```
输入："今天天气"
  ↓
预测："真"（概率80%）
输入："今天天气真"
  ↓
预测："好"（概率90%）
输入："今天天气真好"
  ↓
预测："！"（概率85%）

生成结果："今天天气真好！"
```

## 六、代码对比

### BERT 的使用（理解任务）

```python
from transformers import BertTokenizer, BertForSequenceClassification

# 加载 BERT
tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
model = BertForSequenceClassification.from_pretrained('bert-base-chinese')

# 输入
text = "这部电影太棒了！"
inputs = tokenizer(text, return_tensors="pt")

# 前向传播
outputs = model(**inputs)
logits = outputs.logits

# 分类
prediction = torch.argmax(logits, dim=1)
print(f"情感：{'正面' if prediction == 1 else '负面'}")
```

### GPT 的使用（生成任务）

```python
from transformers import GPT2Tokenizer, GPT2LMHeadModel

# 加载 GPT
tokenizer = GPT2Tokenizer.from_pretrained('gpt2')
model = GPT2LMHeadModel.from_pretrained('gpt2')

# 输入
text = "Today the weather is"
inputs = tokenizer(text, return_tensors="pt")

# 生成
outputs = model.generate(**inputs, max_length=20)
generated_text = tokenizer.decode(outputs[0])

print(f"生成结果：{generated_text}")
```

## 七、总结

### 选择 BERT 还是 GPT？

| 任务类型 | 推荐模型 | 原因 |
|----------|----------|------|
| 文本分类 | BERT | 需要理解整个句子 |
| 情感分析 | BERT | 需要理解整体含义 |
| 命名实体识别 | BERT | 需要理解上下文 |
| 问答系统 | BERT | 需要理解问题和答案 |
| 文本生成 | GPT | 需要逐词生成 |
| 对话系统 | GPT | 需要生成回复 |
| 代码生成 | GPT | 需要生成代码 |
| 翻译 | 都可以 | BERT用编码器-解码器，GPT用生成 |

### 一句话记忆

```
BERT = 理解专家 = "读懂文章"
GPT = 生成专家 = "写文章"
```

## 练习答案

### 练习1答案

1. **架构区别**：
   - BERT 只用编码器
   - GPT 只用解码器

2. **注意力方向**：
   - BERT 用双向注意力，因为需要理解整个句子
   - GPT 用单向注意力，因为需要从左到右生成

3. **适用任务**：
   - BERT：理解任务（分类、问答、实体识别）
   - GPT：生成任务（对话、写作、代码生成）

### 练习2答案

1. **判断好评差评**：BERT（理解任务）
2. **生成故事**：GPT（生成任务）
3. **回答问题**：BERT（理解任务）
4. **写代码**：GPT（生成任务）
