# 解码器详解

> GPT、ChatGPT 用的就是解码器，这是生成文本的核心！

---

## 一、为什么需要学解码器？

### 当前教程只介绍了编码器

```
编码器（Encoder）：理解输入
  - BERT 用的
  - 双向注意力，能看前后文
```

### 但 GPT 用的是解码器

```
解码器（Decoder）：生成输出
  - GPT、ChatGPT 用的
  - 单向注意力，只能看前面的词
  - 自回归生成：一个词一个词地生成
```

**所以你需要学解码器，才能理解 ChatGPT 是怎么工作的！**

---

## 二、解码器和编码器的核心区别

### 区别1：注意力方向不同

**编码器：双向注意力**
```
句子："我 爱 学习"

"我"可以看到：我、爱、学习（全部）
"爱"可以看到：我、爱、学习（全部）
"学习"可以看到：我、爱、学习（全部）

每个词都能看到整个句子！
```

**解码器：单向注意力（掩码注意力）**
```
句子："我 爱 学习"

"我"只能看到：我（只能看自己）
"爱"只能看到：我、爱（只能看前面的）
"学习"只能看到：我、爱、学习（只能看前面的）

每个词只能看到它前面的词，不能"偷看"后面的词！
```

### 为什么解码器要用单向注意力？

因为解码器的任务是**生成下一个词**：

```
训练数据："我 爱 学习"

训练目标：
  看到"我" → 预测下一个词"爱"
  看到"我 爱" → 预测下一个词"学习"
  看到"我 爱 学习" → 预测下一个词（可能是"<END>"）

如果"爱"能看到"学习"，那就是"偷看答案"了！
所以必须用掩码，让每个词只能看前面的词。
```

### 区别2：解码器有额外的交叉注意力层

**编码器的结构**：
```
输入
  ↓
多头自注意力（双向）
  ↓
残差连接 + 层归一化
  ↓
前馈网络
  ↓
残差连接 + 层归一化
  ↓
输出
```

**解码器的结构**：
```
输入
  ↓
多头自注意力（单向，带掩码）  ← 第1个注意力
  ↓
残差连接 + 层归一化
  ↓
交叉注意力（看编码器的输出）   ← 第2个注意力（额外的！）
  ↓
残差连接 + 层归一化
  ↓
前馈网络
  ↓
残差连接 + 层归一化
  ↓
输出
```

**交叉注意力**：让解码器能"看到"编码器的输出（用于机器翻译等任务）。

## 三、掩码注意力详解

### 什么是掩码？

**掩码（Mask）**：一个矩阵，告诉模型哪些位置可以看，哪些位置不能看。

```
掩码矩阵：
[[1, 0, 0],    ← 第1个词只能看自己
 [1, 1, 0],    ← 第2个词能看前两个
 [1, 1, 1]]    ← 第3个词能看全部

1 表示可以看，0 表示不能看
```

### 掩码是怎么用的？

在计算注意力分数后，把不能看的位置设为**负无穷**（-∞），这样 softmax 后就会变成 0。

```
scores = [[0.5, 0.3, 0.2],    ← "我"和每个词的相似度
          [0.1, 0.6, 0.3],    ← "爱"和每个词的相似度
          [0.2, 0.4, 0.4]]    ← "学习"和每个词的相似度

应用掩码（把不能看的位置设为-∞）：
scores = [[0.5, -∞, -∞],    ← "我"只能看自己
          [0.1, 0.6, -∞],    ← "爱"只能看前两个
          [0.2, 0.4, 0.4]]    ← "学习"能看全部

softmax 后：
weights = [[1.0, 0, 0],        ← "我"只关注自己
           [0.37, 0.63, 0],    ← "爱"关注"我"和自己
           [0.3, 0.35, 0.35]]  ← "学习"关注所有
```

### 掩码注意力的代码实现

```python
def attention_with_mask(Q, K, V, mask=None):
    """
    带掩码的注意力
    
    参数：
    - Q, K, V: 注意力的三个输入
    - mask: 掩码矩阵，1表示可以看，0表示不能看
    """
    d_k = Q.size(-1)
    
    # 计算注意力分数
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    
    # 应用掩码
    if mask is not None:
        # 把不能看的位置设为负无穷
        scores = scores.masked_fill(mask == 0, -1e9)
    
    # softmax 归一化
    attention_weights = torch.softmax(scores, dim=-1)
    
    # 加权求和
    output = torch.matmul(attention_weights, V)
    
    return output, attention_weights
```

## 四、交叉注意力详解

### 什么是交叉注意力？

**交叉注意力**：让解码器能"看到"编码器的输出。

```
编码器处理输入："I love you" → 得到编码器输出
解码器生成输出："我 爱 你"

在生成"爱"时，解码器需要知道英文的"love"是什么意思
交叉注意力让解码器能"关注"编码器的输出
```

### 交叉注意力和自注意力的区别

| 类型 | Q 来自 | K, V 来自 | 用途 |
|------|--------|-----------|------|
| 自注意力 | 解码器 | 解码器 | 关注已生成的词 |
| 交叉注意力 | 解码器 | 编码器 | 关注输入序列 |

### 交叉注意力的计算

```
Q = 解码器的当前状态 × W_Q
K = 编码器的输出 × W_K
V = 编码器的输出 × W_V

Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
```

## 五、解码器的完整结构

### 单个解码器层

```
输入 x（已生成的词）
  ↓
掩码多头自注意力（只能看前面的词）
  ↓
残差连接 + 层归一化
  ↓
交叉注意力（看编码器的输出）  ← 用于机器翻译等任务
  ↓
残差连接 + 层归一化
  ↓
前馈网络
  ↓
残差连接 + 层归一化
  ↓
输出 x
```

### GPT 的解码器（简化版）

GPT 只用解码器，没有交叉注意力（因为没有编码器）：

```
输入 x（已生成的词）
  ↓
掩码多头自注意力（只能看前面的词）
  ↓
残差连接 + 层归一化
  ↓
前馈网络
  ↓
残差连接 + 层归一化
  ↓
输出 x
```

## 六、解码器的代码实现

```python
class DecoderLayer(nn.Module):
    """解码器层（用于机器翻译等任务）"""
    
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        
        # 掩码多头自注意力（只能看前面的词）
        self.masked_attention = MultiHeadAttention(d_model, num_heads)
        self.norm1 = nn.LayerNorm(d_model)
        
        # 交叉注意力（看编码器的输出）
        self.cross_attention = MultiHeadAttention(d_model, num_heads)
        self.norm2 = nn.LayerNorm(d_model)
        
        # 前馈网络
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Linear(d_ff, d_model)
        )
        self.norm3 = nn.LayerNorm(d_model)
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, x, encoder_output, mask=None):
        """
        参数：
        - x: 解码器输入，形状 (batch_size, tgt_len, d_model)
        - encoder_output: 编码器输出，形状 (batch_size, src_len, d_model)
        - mask: 掩码，防止看到未来的词
        """
        
        # 第1步：掩码多头自注意力
        attn_output = self.masked_attention(x, mask)
        x = self.norm1(x + self.dropout(attn_output))
        
        # 第2步：交叉注意力
        # Q 来自解码器，K、V 来自编码器
        cross_output = self.cross_attention(x, encoder_output)
        x = self.norm2(x + self.dropout(cross_output))
        
        # 第3步：前馈网络
        ffn_output = self.ffn(x)
        x = self.norm3(x + self.dropout(ffn_output))
        
        return x


class GPTDecoderLayer(nn.Module):
    """GPT 解码器层（只有自注意力，没有交叉注意力）"""
    
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        
        # 掩码多头自注意力
        self.attention = MultiHeadAttention(d_model, num_heads)
        self.norm1 = nn.LayerNorm(d_model)
        
        # 前馈网络
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Linear(d_ff, d_model)
        )
        self.norm2 = nn.LayerNorm(d_model)
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, x, mask=None):
        """
        参数：
        - x: 输入，形状 (batch_size, seq_len, d_model)
        - mask: 掩码
        """
        
        # 掩码多头自注意力
        attn_output = self.attention(x, mask)
        x = self.norm1(x + self.dropout(attn_output))
        
        # 前馈网络
        ffn_output = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_output))
        
        return x
```

## 七、生成文本的过程

### GPT 生成文本的步骤

```
第1步：输入 "<start>"
  模型预测下一个词："我"

第2步：输入 "<start> 我"
  模型预测下一个词："爱"

第3步：输入 "<start> 我 爱"
  模型预测下一个词："学习"

第4步：输入 "<start> 我 爱 学习"
  模型预测下一个词："<end>"

生成结束！
```

### 代码示例

```python
def generate_text(model, start_token, max_len=50):
    """
    生成文本
    
    参数：
    - model: GPT 模型
    - start_token: 起始词的索引
    - max_len: 最大生成长度
    """
    
    # 初始化输入
    tokens = [start_token]
    
    for _ in range(max_len):
        # 把当前输入转换成张量
        x = torch.tensor([tokens])
        
        # 前向传播，得到下一个词的概率
        with torch.no_grad():
            output = model(x)  # (1, seq_len, vocab_size)
        
        # 取最后一个位置的输出
        next_token_logits = output[0, -1, :]  # (vocab_size,)
        
        # 贪心解码：选择概率最大的词
        next_token = torch.argmax(next_token_logits).item()
        
        # 如果生成了结束符，就停止
        if next_token == END_TOKEN:
            break
        
        # 把新词加入序列
        tokens.append(next_token)
    
    return tokens
```

## 八、总结

### 编码器 vs 解码器

| 特性 | 编码器 | 解码器 |
|------|--------|--------|
| 注意力方向 | 双向（看前后文） | 单向（只看前面） |
| 用途 | 理解输入 | 生成输出 |
| 代表模型 | BERT | GPT、ChatGPT |
| 掩码 | 不需要 | 需要（防止偷看） |
| 交叉注意力 | 没有 | 有（看编码器输出） |

### 解码器的核心特性

1. **掩码注意力**：只能看前面的词，不能偷看后面的词
2. **交叉注意力**：可以看编码器的输出（用于翻译等任务）
3. **自回归生成**：一个词一个词地生成

### GPT 用的是什么？

```
GPT 用的是"只有解码器"的架构：
- 没有编码器
- 没有交叉注意力
- 只有掩码自注意力 + 前馈网络
- 自回归生成文本
```

## 练习答案

### 练习1答案

1. **掩码**是一个矩阵，告诉模型哪些位置可以看，哪些位置不能看。
2. **为什么需要**：解码器的任务是预测下一个词，如果能看到后面的词，就是"偷看答案"了。
3. **如果没有**：模型在训练时会偷看答案，导致训练效果很差，生成的文本也会有问题。

### 练习2答案

1. **交叉注意力**：让解码器能"看到"编码器的输出。
2. **区别**：
   - 自注意力：Q、K、V 都来自同一个序列
   - 交叉注意力：Q 来自解码器，K、V 来自编码器
3. **GPT 不需要**：因为 GPT 没有编码器，只有解码器。

### 练习3答案

GPT 生成文本的过程：
1. 输入起始词 "<start>"
2. 模型预测下一个词
3. 把新词加入输入
4. 重复步骤2-3，直到生成结束符 "<end>" 或达到最大长度

这就是"自回归生成"：每次生成一个词，然后把它加入输入，继续生成下一个词。
