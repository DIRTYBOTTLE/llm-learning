# 3.3 RNN 的三个大问题

> RNN 有记忆，但它的记忆有三个大问题。

## 从你已经知道的开始

上一节我们学了 RNN：
- RNN 有"记忆"，能记住之前看到的信息
- RNN 可以处理序列数据

**但是，RNN 有三个大问题，让它在很多场景下不够好。**

## 问题一：梯度消失

### 什么是梯度消失

在第1章你学了**反向传播**：通过梯度来更新权重。

**梯度消失**：在反向传播过程中，梯度会越来越小，最后接近于0。

### 为什么会发生

RNN 的梯度需要经过很多个时间步才能传回去。

```
时间步1 → 时间步2 → ... → 时间步100

梯度从时间步100传回时间步1，需要经过100次乘法
每次乘法都会让梯度变小一点
最后梯度变得非常非常小，接近于0
```

### 用数字感受一下

假设每个时间步的梯度衰减因子是 0.9：

| 时间步 | 梯度 |
|--------|------|
| 100 | 1.0 |
| 90 | 0.9^10 ≈ 0.35 |
| 50 | 0.9^50 ≈ 0.005 |
| 1 | 0.9^99 ≈ 0.00003 |

**梯度从 1.0 衰减到了 0.00003！**

### 实际影响

```
句子："我昨天去了北京，那里很冷，所以我买了羽绒服"

如果模型要学习"北京"和"很冷"的关系：
- "北京"在位置 4
- "很冷"在位置 6
- 梯度需要从位置6传回位置4

由于梯度消失，模型很难学到"北京→很冷"这个关系
```

## 问题二：不能并行计算

### 什么是并行计算

**并行计算**：多个计算任务同时进行。

在第2章你学了 CNN：
- CNN 的所有卷积核可以同时计算
- 这就是为什么 CNN 训练很快

### RNN 的问题

RNN 必须**按顺序**计算：

```
时间步1: 计算 h₁（需要 h₀ 和 x₁）
时间步2: 计算 h₂（需要 h₁ 和 x₂）← 必须等 h₁ 算完
时间步3: 计算 h₃（需要 h₂ 和 x₃）← 必须等 h₂ 算完
...
```

**不能并行！必须一个一个算！**

### 实际影响

```
处理一个长度为100的句子：
- CNN：可以同时处理所有位置，很快
- RNN：必须按顺序处理100步，很慢

训练时间：RNN 比 CNN 慢很多
```

## 问题三：记不住太远的东西

### 什么是长距离依赖

**长距离依赖**：句子中相隔很远的词之间有关系。

```
句子："我昨天去了北京，那里很冷，所以我买了羽绒服"

长距离依赖：
- "北京" ↔ "那里"（相隔3个词）
- "很冷" ↔ "羽绒服"（相隔4个词）
```

### RNN 的问题

由于**梯度消失**，RNN 很难学习长距离依赖。

```
位置1: "我"        → 信息 100%
位置2: "昨天"      → 信息 90%
位置3: "去了"      → 信息 81%
位置4: "北京"      → 信息 73%
...
位置10: "羽绒服"   → 信息 35%

信息衰减严重！模型很难把"北京"和"很冷"联系起来
```

### 实际影响

```
短句子："我很开心" → RNN 处理得很好
长句子："我昨天去了北京，那里很冷，所以我买了羽绒服" → RNN 处理得不好

句子越长，RNN 的效果越差
```

## 三个问题的总结

| 问题 | 原因 | 影响 |
|------|------|------|
| 梯度消失 | 梯度经过太多时间步 | 无法学习长距离依赖 |
| 不能并行 | 必须按顺序计算 | 训练速度慢 |
| 记不住远的东西 | 信息经过太多步会衰减 | 句子越长效果越差 |

## LSTM 和 GRU：部分解决方案

后来有人提出了 **LSTM** 和 **GRU** 来缓解梯度消失问题。

**核心思想**：加入"门"机制，让信息可以选择性地保留或遗忘。

```
LSTM 的结构：
- 遗忘门：决定忘记哪些旧信息
- 输入门：决定记住哪些新信息
- 输出门：决定输出哪些信息
```

**但是**：
- LSTM/GRU 仍然需要按顺序计算（问题二没解决）
- 对于很长的序列，效果仍然有限（问题三只是缓解）

## 我们需要什么

我们需要一种新模型，能够：
1. ✅ 解决梯度消失 → 让梯度能直接传回去
2. ✅ 能并行计算 → 不用按顺序处理
3. ✅ 能捕捉长距离依赖 → 任意两个位置都能直接联系

**答案：注意力机制 + Transformer**

下一节我们来学习注意力机制。

## 练习题

### 练习1：理解梯度消失

请用自己的话解释，什么是梯度消失？为什么 RNN 会有这个问题？

### 练习2：对比并行和串行

请解释：
1. 什么是并行计算？
2. 为什么 RNN 不能并行计算？
3. 不能并行计算会带来什么问题？

### 练习3：理解长距离依赖

请用自己的话解释，什么是长距离依赖？为什么 RNN 处理不好长距离依赖？

---

## 答案

### 练习1答案

梯度消失是指在反向传播过程中，梯度会越来越小，最后接近于0。

RNN 有这个问题是因为：梯度需要经过很多个时间步才能传回去。每个时间步的梯度都会衰减一点，经过很多步之后，梯度就变得非常小了。

### 练习2答案

1. **并行计算**：多个计算任务同时进行。比如 CNN 的所有卷积核可以同时计算。
2. **RNN 不能并行**：因为每一步的计算都依赖于上一步的结果（h_t 需要 h_{t-1}），所以必须按顺序计算。
3. **影响**：训练速度慢，无法充分利用 GPU 的并行计算能力。

### 练习3答案

长距离依赖是指句子中相隔很远的词之间有关系。比如"北京"和"很冷"相隔很远，但它们有关系（北京很冷）。

RNN 处理不好长距离依赖是因为梯度消失：信息经过很多个时间步后会衰减，模型很难学到相隔很远的词之间的关系。
