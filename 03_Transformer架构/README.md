# 第3章 序列模型与 Transformer 架构

> 从"处理一张图片"到"处理一段文字"，理解 AI 是怎么读懂语言的。

## 学习目标

学完这章，你能：
- 理解什么是序列数据，为什么需要专门的模型
- 理解 RNN 的基本原理和它的三个大问题
- 理解注意力机制是怎么工作的
- 理解 Transformer 的完整结构（编码器和解码器）
- 理解 BERT 和 GPT 的区别
- 用 Transformer 做一个情感分析项目

## 前置知识（你已经学过）

- **第0章**：矩阵乘法、梯度
- **第1章**：神经网络、前向传播、反向传播、激活函数、损失函数
- **第2章**：CNN、批归一化、优化器

## 章节内容

### 3.1 序列数据是什么

从"一张图片"到"一段文字"：
- 什么是序列数据
- 为什么 CNN 处理不好文字
- 我们需要什么样的新模型

**对应文件**：`01_序列数据是什么.md`、`code/01_sequence_data.py`

### 3.2 循环神经网络（RNN）

让网络有"记忆"：
- RNN 的核心思想
- RNN 是怎么工作的
- RNN 是怎么训练的（BPTT）

**对应文件**：`02_循环神经网络.md`、`code/02_rnn_basics.py`

### 3.2b RNN 应用实例

用具体例子看 RNN 怎么做三个任务：
- 情感分析
- 文本生成
- 机器翻译

**对应文件**：`02b_RNN应用实例.md`

### 3.3 RNN 的三个大问题

为什么 RNN 还不够好：
- 问题一：梯度消失
- 问题二：不能并行计算
- 问题三：记不住太远的东西

**对应文件**：`03_RNN的局限性.md`、`code/03_rnn_problems.py`

### 3.4 注意力机制

学会"看重点"：
- 注意力机制的直觉
- 注意力是怎么计算的
- 注意力为什么更好

**对应文件**：`04_注意力机制.md`、`code/04_attention.py`

### 3.5 Transformer 编码器

把注意力变成一个完整的网络：
- 自注意力机制
- 多头注意力
- 位置编码
- Transformer 编码器

**对应文件**：`05_Transformer架构.md`、`05b_多头注意力详解.md`、`code/05_transformer.py`

### 3.5b Transformer 解码器

GPT、ChatGPT 用的就是解码器：
- 掩码注意力（防止偷看）
- 交叉注意力（看编码器输出）
- 解码器的完整结构
- 生成文本的过程

**对应文件**：`05c_解码器详解.md`

### 3.6 实战：电影评论情感分析

用 Transformer 判断好评还是差评：
- 数据准备
- 搭建模型
- 训练和测试

**对应文件**：`06_实战_情感分析.md`、`code/06_sentiment_analysis.py`

### 3.7 BERT vs GPT

两种 Transformer 的对比：
- 架构区别（编码器 vs 解码器）
- 注意力方向（双向 vs 单向）
- 训练方式（MLM vs CLM）
- 用途（理解 vs 生成）

**对应文件**：`07_BERT_vs_GPT.md`
