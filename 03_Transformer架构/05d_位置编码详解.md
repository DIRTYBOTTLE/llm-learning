# 位置编码详解

> 位置编码告诉模型每个词在什么位置。我会用最详细的步骤来解释！

---

## 一、为什么需要位置编码？

### 问题：自注意力分不清顺序

```
句子1："我 爱 学习"
句子2："学习 爱 我"

自注意力看到的：
句子1 → {我, 爱, 学习}
句子2 → {学习, 爱, 我}  → 也是 {我, 爱, 学习}

自注意力觉得这两个句子一样！但其实意思完全不同！
```

### 解决方案：给每个位置一个"编号"

```
句子："我 爱 学习"

位置0的"我"   → 编号 [0, 1, 0, 1]
位置1的"爱"   → 编号 [0.84, 0.54, 0.01, 1.0]
位置2的"学习" → 编号 [0.91, -0.42, 0.02, 1.0]

现在两个句子不一样了！
"我爱学习"：位置0的编号给"我"
"学习爱我"：位置0的编号给"学习"
```

## 二、位置编码的公式（一步一步解释）

### 公式

```
PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

### 每个符号是什么意思？

| 符号 | 意思 | 例子 |
|------|------|------|
| pos | 第几个词（从0开始） | 第1个词 pos=0，第2个词 pos=1 |
| i | 第几对维度（从0开始） | 第1对 i=0，第2对 i=1 |
| d_model | 每个词用几个数字表示 | 比如4个数字 |
| 2i | 偶数维度（第0,2,4...个数字） | 0, 2, 4, ... |
| 2i+1 | 奇数维度（第1,3,5...个数字） | 1, 3, 5, ... |

### 大白话翻译

```
- 位置0的第0个数字 = sin(0 / 10000^(0/4))
- 位置0的第1个数字 = cos(0 / 10000^(0/4))
- 位置0的第2个数字 = sin(0 / 10000^(2/4))
- 位置0的第3个数字 = cos(0 / 10000^(2/4))
...
```

## 三、用最简单的例子演示

### 设定

```
d_model = 4  （每个词用4个数字表示）
句子："我 爱 学习"（3个词）
```

### 第1步：确定 i 的范围

```
d_model = 4
i 的范围 = 0, 1  （因为 d_model/2 = 2）

i = 0 → 对应维度 0 和 1（第0对）
i = 1 → 对应维度 2 和 3（第1对）
```

### 第2步：计算分母 10000^(2i/d_model)

```
i = 0: 10000^(2×0/4) = 10000^0 = 1
i = 1: 10000^(2×1/4) = 10000^0.5 = 100

所以：
- 维度0和1的分母是 1
- 维度2和3的分母是 100
```

### 第3步：计算每个位置的位置编码

#### 位置0（pos=0）：

```
维度0（偶数）：sin(0 / 1) = sin(0) = 0
维度1（奇数）：cos(0 / 1) = cos(0) = 1
维度2（偶数）：sin(0 / 100) = sin(0) = 0
维度3（奇数）：cos(0 / 100) = cos(0) = 1

PE(0) = [0, 1, 0, 1]
```

#### 位置1（pos=1）：

```
维度0（偶数）：sin(1 / 1) = sin(1) = 0.841
维度1（奇数）：cos(1 / 1) = cos(1) = 0.540
维度2（偶数）：sin(1 / 100) = sin(0.01) = 0.01
维度3（奇数）：cos(1 / 100) = cos(0.01) = 1.0

PE(1) = [0.841, 0.540, 0.01, 1.0]
```

#### 位置2（pos=2）：

```
维度0（偶数）：sin(2 / 1) = sin(2) = 0.909
维度1（奇数）：cos(2 / 1) = cos(2) = -0.416
维度2（偶数）：sin(2 / 100) = sin(0.02) = 0.02
维度3（奇数）：cos(2 / 100) = cos(0.02) = 1.0

PE(2) = [0.909, -0.416, 0.02, 1.0]
```

### 第4步：汇总

```
位置0：PE(0) = [0,     1,     0,    1   ]
位置1：PE(1) = [0.841, 0.540, 0.01, 1.0 ]
位置2：PE(2) = [0.909, -0.416, 0.02, 1.0]
```

**每个位置的编码都不一样！**

## 四、怎么使用位置编码？

### 第1步：准备词嵌入

```
假设词嵌入（每个词用4个数字表示）：

"我"   → [0.2, -0.5, 0.8, 0.1]
"爱"   → [0.1, 0.3, -0.2, 0.7]
"学习" → [-0.4, 0.6, 0.1, -0.3]
```

### 第2步：准备位置编码

```
位置0：PE(0) = [0,     1,     0,    1   ]
位置1：PE(1) = [0.841, 0.540, 0.01, 1.0 ]
位置2：PE(2) = [0.909, -0.416, 0.02, 1.0]
```

### 第3步：相加（词嵌入 + 位置编码）

```
"我"在位置0：
  最终输入 = [0.2, -0.5, 0.8, 0.1] + [0, 1, 0, 1]
           = [0.2+0, -0.5+1, 0.8+0, 0.1+1]
           = [0.2, 0.5, 0.8, 1.1]

"爱"在位置1：
  最终输入 = [0.1, 0.3, -0.2, 0.7] + [0.841, 0.540, 0.01, 1.0]
           = [0.1+0.841, 0.3+0.540, -0.2+0.01, 0.7+1.0]
           = [0.941, 0.840, -0.19, 1.7]

"学习"在位置2：
  最终输入 = [-0.4, 0.6, 0.1, -0.3] + [0.909, -0.416, 0.02, 1.0]
           = [-0.4+0.909, 0.6-0.416, 0.1+0.02, -0.3+1.0]
           = [0.509, 0.184, 0.12, 0.7]
```

### 第4步：验证效果

```
现在再看两个句子：

句子1："我 爱 学习"
  "我"在位置0 → [0.2, 0.5, 0.8, 1.1]
  "爱"在位置1 → [0.941, 0.840, -0.19, 1.7]
  "学习"在位置2 → [0.509, 0.184, 0.12, 0.7]

句子2："学习 爱 我"
  "学习"在位置0 → [-0.4, 0.6, 0.1, -0.3] + [0, 1, 0, 1] = [-0.4, 1.6, 0.1, 0.7]
  "爱"在位置1 → [0.1, 0.3, -0.2, 0.7] + [0.841, 0.540, 0.01, 1.0] = [0.941, 0.840, -0.19, 1.7]
  "我"在位置2 → [0.2, -0.5, 0.8, 0.1] + [0.909, -0.416, 0.02, 1.0] = [1.109, -0.916, 0.82, 1.1]

现在两个句子不一样了！
  句子1的"我" = [0.2, 0.5, 0.8, 1.1]
  句子2的"我" = [1.109, -0.916, 0.82, 1.1]
  
  同一个词在不同位置，最终输入不同！
```

## 六、为什么用 sin 和 cos？

### 原因1：每个位置都不同

```
位置0：[0, 1, 0, 1]
位置1：[0.841, 0.540, 0.01, 1.0]
位置2：[0.909, -0.416, 0.02, 1.0]

没有两个位置的编码是一样的！
```

### 原因2：可以表示相对位置

```
数学性质：PE(pos+k) 可以用 PE(pos) 的线性变换表示

意思是：如果模型想知道"下一个位置"是什么样的
它可以通过学习一个矩阵，把当前位置的编码变换成下一个位置的编码
```

### 原因3：可以处理任意长度

```
sin 和 cos 可以计算任意位置的值

训练时最大长度 = 100
推理时可以用 200（甚至更长）
```

## 七、代码实现

```python
import math

def positional_encoding(pos, d_model):
    """
    计算单个位置的位置编码
    
    参数：
    - pos: 位置（第几个词）
    - d_model: 模型维度（每个词用几个数字表示）
    
    返回：
    - pe: 位置编码向量，长度为 d_model
    """
    pe = [0] * d_model
    
    for i in range(0, d_model, 2):
        # 偶数维度用 sin
        pe[i] = math.sin(pos / (10000 ** (i / d_model)))
        # 奇数维度用 cos
        pe[i + 1] = math.cos(pos / (10000 ** (i / d_model)))
    
    return pe

# 计算位置0, 1, 2 的位置编码
for pos in range(3):
    pe = positional_encoding(pos, d_model=4)
    print(f"位置{pos}: {[round(x, 3) for x in pe]}")
```

输出：
```
位置0: [0, 1, 0, 1]
位置1: [0.841, 0.54, 0.01, 1.0]
位置2: [0.909, -0.416, 0.02, 1.0]
```

## 八、总结

### 位置编码的作用

```
告诉模型每个词在什么位置
让模型能区分"我爱学习"和"学习爱我"
```

### 计算步骤

```
1. 确定 d_model（每个词用几个数字）
2. 对于每个位置 pos：
   - 对于每对维度 i：
     - 偶数维度：PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
     - 奇数维度：PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
3. 最终输入 = 词嵌入 + 位置编码
```

### 关键理解

```
- 位置编码是固定的（不需要学习）
- 每个位置的编码都不同
- 用 sin 和 cos 是因为它们有好的数学性质
```
