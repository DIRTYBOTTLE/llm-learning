# RNN 应用实例：情感分析、文本生成、机器翻译

> 用具体的数字例子，看看 RNN 是怎么完成这三类任务的。

---

## 一、情感分析

### 任务描述

```
输入："我 爱 学习"
输出：正面（1）或 负面（0）
```

**目标**：读完整句话后，判断是好评还是差评。

### 数据准备

先建立一个简单的词表：

```
词表：
  "我"   → [1, 0, 0]
  "爱"   → [0, 1, 0]
  "学习" → [0, 0, 1]
  "讨厌" → [1, 0, 0]  （简化处理）
  "这个" → [0, 1, 0]
  "电影" → [0, 0, 1]
```

训练数据：

| 句子 | 标签 |
|------|------|
| "我 爱 学习" | 1（正面） |
| "我 讨厌 这个" | 0（负面） |

### 模型结构

```
输入序列：x₁, x₂, x₃
    ↓
RNN 逐个处理，得到最终记忆 h₃
    ↓
把 h₃ 送入分类层
    ↓
输出：正面(1) 或 负面(0)
```

具体来说：

```
分类层：ŷ = sigmoid(W · h₃ + b)

如果 ŷ > 0.5 → 正面
如果 ŷ ≤ 0.5 → 负面
```

### 训练过程（用数字演示）

假设我们有简单参数：

```
W_xh = [[0.1, 0.2],    ← 输入权重
         [0.3, 0.4]]

W_hh = [[0.5, 0.1],    ← 记忆权重
         [0.2, 0.6]]

W = [0.7, 0.8]          ← 分类权重
b = -0.5                 ← 分类偏置
```

**训练样本**："我 爱 学习"，标签 y = 1

**第1步：前向传播**

```
时间步1：输入"我" = [1, 0, 0]，取前2维 [1, 0]
  h₁ = tanh(W_xh · [1, 0] + W_hh · [0, 0])
     = tanh([0.1, 0.3])
     = [0.0997, 0.2913]

时间步2：输入"爱" = [0, 1, 0]，取前2维 [0, 1]
  h₂ = tanh(W_xh · [0, 1] + W_hh · h₁)
     = tanh([0.2, 0.4] + [0.079, 0.195])
     = tanh([0.279, 0.595])
     = [0.2717, 0.5311]

时间步3：输入"学习" = [0, 0, 1]，取前2维 [0, 0]
  h₃ = tanh(W_xh · [0, 0] + W_hh · h₂)
     = tanh([0, 0] + [0.1886, 0.3731])
     = tanh([0.1886, 0.3731])
     = [0.1867, 0.3567]
```

**第2步：分类**

```
ŷ = sigmoid(W · h₃ + b)
  = sigmoid([0.7, 0.8] · [0.1867, 0.3567] + (-0.5))
  = sigmoid(0.1307 + 0.2854 - 0.5)
  = sigmoid(-0.0839)
  = 0.4790
```

**第3步：计算损失**

```
损失 = -(y·log(ŷ) + (1-y)·log(1-ŷ))
     = -(1·log(0.4790) + 0·log(0.5210))
     = -log(0.4790)
     = 0.7361
```

**第4步：反向传播（BPTT）**

```
梯度从 ŷ → h₃ → h₂ → h₁ → W_xh, W_hh

PyTorch 自动完成，得到：
  ∂L/∂W_xh = ...
  ∂L/∂W_hh = ...
  ∂L/∂W = ...
  ∂L/∂b = ...
```

**第5步：更新参数**

```
W_xh = W_xh - lr × ∂L/∂W_xh
W_hh = W_hh - lr × ∂L/∂W_hh
W = W - lr × ∂L/∂W
b = b - lr × ∂L/∂b
```

### 预测过程

训练好模型后，预测新句子：

```
输入："我 爱 学习"

前向传播得到 h₃ = [0.1867, 0.3567]
分类：ŷ = sigmoid(W · h₃ + b) = 0.92

因为 0.92 > 0.5，所以预测为：正面 ✓
```

## 二、文本生成

### 任务描述

```
输入："今天天气"
生成："今天天气 真 好"
```

**目标**：给定前缀，逐个生成下一个词。

### 数据准备

词表：

```
"今天" → 0
"天气" → 1
"真"   → 2
"好"   → 3
"很"   → 4
"不错" → 5
```

训练数据（把句子拆成输入-目标对）：

| 输入 | 目标（下一个词） |
|------|-----------------|
| "今天" | "天气" |
| "今天 天气" | "真" |
| "今天 天气 真" | "好" |

### 模型结构

```
输入序列：x₁, x₂, ..., xₜ
    ↓
RNN 逐个处理，得到每个位置的记忆 h₁, h₂, ...
    ↓
每个位置都预测下一个词
    ↓
输出：下一个词的概率分布
```

具体来说：

```
在时间步 t，预测下一个词：
  p(下一个词) = softmax(W_vocab · hₜ + b)
```

### 训练过程（用数字演示）

**训练样本**：输入 "今天 天气"，目标 "真"

```
词向量（简化，用1维）：
  "今天" → [1]
  "天气" → [2]
  "真"   → [3]
```

**第1步：前向传播**

```
时间步1：输入"今天" = [1]
  h₁ = tanh(W_xh · 1 + W_hh · 0) = tanh(0.1) = 0.0997

时间步2：输入"天气" = [2]
  h₂ = tanh(W_xh · 2 + W_hh · 0.0997) = tanh(0.25) = 0.2449
```

**第2步：预测下一个词**

```
用 h₂ 预测下一个词：
  logits = W_vocab · h₂ + b
  logits = [0.1, 0.3, 0.8, 0.2, 0.1, 0.1]  （假设）
  
  p = softmax(logits) = [0.12, 0.15, 0.35, 0.13, 0.12, 0.12]
  
  预测的下一个词 = argmax(p) = 2（"真"）
```

**第3步：计算损失**

```
目标词是"真"（索引2）
损失 = -log(p[2]) = -log(0.35) = 1.05
```

**第4步：反向传播 + 更新参数**

```
PyTorch 自动完成 BPTT，更新所有参数
```

### 预测过程（文本生成）

训练好模型后，生成文本：

```
输入："今天天气"

第1步：用 RNN 处理 "今天天气"，得到 h₂
第2步：用 h₂ 预测下一个词 → "真"
第3步：输入变成 "今天天气真"，用 RNN 处理，得到 h₃
第4步：用 h₃ 预测下一个词 → "好"
第5步：输入变成 "今天天气真好"，用 RNN 处理，得到 h₄
第6步：用 h₄ 预测下一个词 → <END>（结束符）

生成结果："今天天气真好"
```

**关键点**：每生成一个词，就把它加入输入，继续生成下一个词。

## 三、机器翻译

### 任务描述

```
输入（英文）："I love you"
输出（中文）："我 爱 你"
```

**目标**：把一种语言翻译成另一种语言。

### 模型结构：编码器-解码器

```
编码器（Encoder）：
  输入英文序列 → RNN → 得到记忆向量
  
解码器（Decoder）：
  从记忆向量开始 → RNN → 逐个生成中文词
```

```
"I love you"
     ↓
  [编码器 RNN]
     ↓
  记忆向量 c
     ↓
  [解码器 RNN]
     ↓
  "我 爱 你"
```

### 训练过程（用数字演示）

**词表**：

```
英文词表：I=0, love=1, you=2
中文词表：<start>=0, 我=1, 爱=2, 你=3, <end>=4
```

**第1步：编码器处理英文**

```
输入："I love you"

时间步1：输入"I" = [1,0,0]
  h₁ = tanh(W_xh · [1,0,0] + W_hh · [0,0])
  h₁ = [0.1, 0.2]

时间步2：输入"love" = [0,1,0]
  h₂ = tanh(W_xh · [0,1,0] + W_hh · h₁)
  h₂ = [0.3, 0.4]

时间步3：输入"you" = [0,0,1]
  h₃ = tanh(W_xh · [0,0,1] + W_hh · h₂)
  h₃ = [0.5, 0.6]  ← 这就是记忆向量 c
```

**第2步：解码器生成中文**

```
初始输入：<start>
初始记忆：c = [0.5, 0.6]（来自编码器）

时间步1：
  输入：<start>
  记忆：h₀' = c = [0.5, 0.6]
  h₁' = tanh(W_xh' · <start> + W_hh' · h₀')
  预测：p = softmax(W_vocab' · h₁') → "我"

时间步2：
  输入："我"
  h₂' = tanh(W_xh' · "我" + W_hh' · h₁')
  预测：p = softmax(W_vocab' · h₂') → "爱"

时间步3：
  输入："爱"
  h₃' = tanh(W_xh' · "爱" + W_hh' · h₂')
  预测：p = softmax(W_vocab' · h₃') → "你"

时间步4：
  输入："你"
  h₄' = tanh(W_xh' · "你" + W_hh' · h₃')
  预测：p = softmax(W_vocab' · h₄') → "<end>"

生成结束！
```

**第3步：计算损失**

```
解码器每个时间步都有损失：
  L₁ = -log(p("我"))     ← 时间步1的损失
  L₂ = -log(p("爱"))     ← 时间步2的损失
  L₃ = -log(p("你"))     ← 时间步3的损失
  L₄ = -log(p("<end>"))  ← 时间步4的损失

总损失 L = L₁ + L₂ + L₃ + L₄
```

**第4步：反向传播**

```
梯度从解码器 → 记忆向量 → 编码器

PyTorch 自动完成，更新编码器和解码器的所有参数
```

### 预测过程

训练好模型后，翻译新句子：

```
输入："I love you"

编码器：
  处理 "I love you" → 得到记忆向量 c

解码器：
  从 <start> 开始
  → 预测 "我"
  → 输入 "我"，预测 "爱"
  → 输入 "爱"，预测 "你"
  → 输入 "你"，预测 "<end>"
  → 结束

输出："我 爱 你"
```

## 四、三个任务的对比

| 任务 | 输入 | 输出 | RNN 的作用 |
|------|------|------|-----------|
| 情感分析 | 整句话 | 一个类别 | 用最终记忆 h_T 做分类 |
| 文本生成 | 前缀 | 下一个词序列 | 每个时间步都预测下一个词 |
| 机器翻译 | 源语言 | 目标语言 | 编码器编码，解码器生成 |

### 关键区别

```
情感分析：
  只用最后一个时间步的记忆 h_T 做预测
  
文本生成：
  每个时间步的记忆 h_t 都用来预测下一个词
  
机器翻译：
  有两个 RNN：编码器和解码器
  编码器的记忆传递给解码器
```

---

## 五、代码对比

### 情感分析

```python
# 只用最终记忆做分类
h_final = rnn(input_sequence)       # 得到 h_T
output = classifier(h_final)         # 用 h_T 分类
```

### 文本生成

```python
# 每个时间步都预测
outputs = rnn(input_sequence)        # 得到 h₁, h₂, ..., h_T
predictions = []
for h in outputs:
    next_word = predict_next_word(h)  # 用每个 h 预测
    predictions.append(next_word)
```

### 机器翻译

```python
# 编码器-解码器
memory = encoder(source_sequence)    # 编码英文
output = decoder(memory, target)     # 解码成中文
```

---

## 六、总结

| 任务 | 训练数据 | 模型结构 | 预测方式 |
|------|----------|----------|----------|
| 情感分析 | (句子, 类别) | RNN + 分类层 | 读完整句后分类 |
| 文本生成 | (前缀, 下一个词) | RNN + 词预测层 | 逐个生成词 |
| 机器翻译 | (源语言, 目标语言) | 编码器RNN + 解码器RNN | 编码后逐个生成 |

**核心思想**：
- RNN 读序列，积累记忆
- 不同任务用记忆的方式不同
- 训练时用 BPTT 更新参数
- 预测时用训练好的参数做推理
