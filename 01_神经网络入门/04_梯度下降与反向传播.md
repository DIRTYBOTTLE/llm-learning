# 1.4 梯度下降与反向传播

> 梯度下降告诉网络"往哪走"，反向传播告诉网络"怎么算"。这两个是神经网络学习的核心。

## 1. 梯度：告诉我们要往哪调

### 问题

网络有成千上万个参数，应该调哪个？往哪个方向调？

### 答案：计算梯度

**梯度**（Gradient）告诉我们：**如果稍微改变这个参数，损失会变大还是变小**。

```
假设有一个参数 w，当前值是 2.0

计算：
- 如果 w 增加一点（变成 2.01），损失从 0.5 变成 0.49
  → 损失变小了！说明应该增大 w
  
- 如果 w 增加一点（变成 2.01），损失从 0.5 变成 0.51
  → 损失变大了！说明应该减小 w
```

### 梯度的数学定义

```
梯度 = 损失的变化量 / 参数的变化量

∂L/∂w = lim(Δw→0) [L(w+Δw) - L(w)] / Δw

其中：
- ∂L/∂w：损失对参数 w 的梯度（偏导数）
- L：损失函数
- w：参数
- Δw：参数的微小变化
```

### 举个例子

```
当前：w = 2.0，损失 L = 0.5

尝试：w = 2.01，损失 L = 0.49

梯度 = (0.49 - 0.5) / (2.01 - 2.0)
     = -0.01 / 0.01
     = -1.0

解读：梯度是负数，说明增大 w 会让损失减小
```

### 梯度的几何意义

```
损失 L
   ↑
   |    /  ← 梯度 > 0，损失随 w 增大而增大
   |   /
   |  /
   | /
   |/______→ 参数 w

梯度是损失曲面的"斜率"：
- 梯度 > 0：斜向上，增大 w 会增加损失
- 梯度 < 0：斜向下，增大 w 会减少损失
- 梯度 = 0：平坦，可能是最优点
```

## 2. 梯度下降：沿着梯度方向调整参数

### 核心思想

**梯度指向损失增大的方向，所以我们往反方向走**。

```
梯度是正的 → 减小参数
梯度是负的 → 增大参数

参数更新公式：
w_new = w_old - η × ∂L/∂w

其中：
- η（学习率）：决定每步走多大
- ∂L/∂w：梯度
```

### 学习率的选择

```
学习率太大：可能跨过最优点，来回震荡甚至发散

损失
  ↑
  |  *     *     *     *     ← 来回震荡
  |    *     *     *
  |      *     *
  |        *
  └─────────────────────→ 迭代次数

学习率太小：收敛太慢，需要很多步

损失
  ↑
  |*
  | *
  |  *
  |   *
  |    *  *  *  *  *  *  *  ← 收敛太慢
  └─────────────────────→ 迭代次数

通常取 0.01 或 0.001
```

### 一个具体例子

```
目标：找到使 f(x) = (x-3)² 最小的 x
最小值在 x = 3

当前：x = 0，学习率 = 0.3

第1步：
  f(0) = (0-3)² = 9
  梯度 = df/dx = 2(x-3) = 2(0-3) = -6
  x = 0 - 0.3×(-6) = 0 + 1.8 = 1.8

第2步：
  f(1.8) = (1.8-3)² = 1.44
  梯度 = 2(1.8-3) = -2.4
  x = 1.8 - 0.3×(-2.4) = 1.8 + 0.72 = 2.52

第3步：
  f(2.52) = (2.52-3)² = 0.23
  梯度 = 2(2.52-3) = -0.96
  x = 2.52 - 0.3×(-0.96) = 2.52 + 0.288 = 2.808

...继续...
  
第10步：x ≈ 2.99 → 接近最优解！
```

### 可视化

```
损失
  ↑
 9|*
  |  *
  |    *
  |      *  *  *
  |              *  *  *  *  → 接近最小值
  └─────────────────────→ 参数 x
  0    1    2    3    4
```

## 3. 链式法则：反向传播的数学基础

### 什么是链式法则？

**链式法则**是微积分中求复合函数导数的方法。

```
如果 y = f(g(x))

那么 dy/dx = f'(g(x)) × g'(x)
```

### 为什么需要链式法则？

神经网络是多层复合函数：

```
输入 x → 线性变换 z₁ → 激活 a₁ → 线性变换 z₂ → 激活 a₂ → 输出 ŷ → 损失 L

L = loss(ŷ, y)
ŷ = σ(z₂)
z₂ = W₂ᵀa₁ + b₂
a₁ = σ(z₁)
z₁ = W₁ᵀx + b₁
```

要计算 ∂L/∂W₁，需要用链式法则：

```
∂L/∂W₁ = ∂L/∂ŷ × ∂ŷ/∂z₂ × ∂z₂/∂a₁ × ∂a₁/∂z₁ × ∂z₁/∂W₁
```

### 一个简单例子

```
网络：x → [×w] → [×2] → y

即：y = 2 × (w × x)

当前：x = 3, w = 1, 真实值 = 10
计算：y = 2 × (1 × 3) = 6
损失：L = (6 - 10)² = 16

反向传播：
∂L/∂y = 2×(6-10) = -8    (损失对输出的梯度)
∂y/∂(wx) = 2              (输出对中间值的梯度)
∂(wx)/∂w = x = 3          (中间值对参数的梯度)

链式法则：
∂L/∂w = ∂L/∂y × ∂y/∂(wx) × ∂(wx)/∂w
       = (-8) × 2 × 3
       = -48

结论：梯度是 -48，说明应该增大 w
```

## 4. 反向传播算法

### 核心思想

**反向传播**就是链式法则的系统应用，从输出层一层层往回算梯度。

```
前向传播（从左到右）：
x → z₁ → a₁ → z₂ → a₂ → ŷ → L

反向传播（从右到左）：
∂L/∂W₂ → ∂L/∂a₁ → ∂L/∂W₁

每一步都复用前一步的计算结果！
```

### 两层网络的反向传播推导

**网络结构**：

```
x → [线性变换] → [ReLU] → [线性变换] → ŷ

前向传播：
z₁ = W₁ᵀx + b₁
a₁ = ReLU(z₁) = max(0, z₁)
z₂ = W₂ᵀa₁ + b₂
ŷ = z₂  （回归问题，输出不激活）

损失：L = (1/2)(ŷ - y)²
```

**为什么损失函数用 `1/2`？**

```
标准 MSE：L = (ŷ - y)²
梯度：∂L/∂ŷ = 2(ŷ - y)  ← 有个 2

带 1/2：L = (1/2)(ŷ - y)²
梯度：∂L/∂ŷ = (ŷ - y)  ← 更简洁！

1/2 和 2 抵消，让梯度计算更简单
```

**反向传播推导（完整步骤）**：

```
目标：计算 ∂L/∂W₁, ∂L/∂b₁, ∂L/∂W₂, ∂L/∂b₂

步骤1：∂L/∂ŷ（损失对输出的梯度）
L = (1/2)(ŷ - y)²
∂L/∂ŷ = ŷ - y

步骤2：∂L/∂z₂（因为 ŷ = z₂）
ŷ = z₂，所以 ∂ŷ/∂z₂ = 1
∂L/∂z₂ = ∂L/∂ŷ × ∂ŷ/∂z₂ = (ŷ - y) × 1 = ŷ - y

步骤3：∂L/∂W₂ 和 ∂L/∂b₂
z₂ = W₂ᵀa₁ + b₂
∂z₂/∂W₂ = a₁
∂z₂/∂b₂ = 1
∂L/∂W₂ = ∂L/∂z₂ × ∂z₂/∂W₂ = (ŷ - y) × a₁
∂L/∂b₂ = ∂L/∂z₂ × ∂z₂/∂b₂ = (ŷ - y) × 1 = ŷ - y

步骤4：∂L/∂a₁（关键！连接两层的桥梁）
z₂ = W₂ᵀa₁ + b₂
∂z₂/∂a₁ = W₂
∂L/∂a₁ = ∂L/∂z₂ × ∂z₂/∂a₁ = (ŷ - y) × W₂

步骤5：∂L/∂z₁
a₁ = ReLU(z₁)
∂a₁/∂z₁ = ReLU'(z₁) = 1 if z₁ > 0, else 0
∂L/∂z₁ = ∂L/∂a₁ × ∂a₁/∂z₁ = (ŷ - y) × W₂ × ReLU'(z₁)

步骤6：∂L/∂W₁ 和 ∂L/∂b₁
z₁ = W₁ᵀx + b₁
∂z₁/∂W₁ = x
∂z₁/∂b₁ = 1
∂L/∂W₁ = ∂L/∂z₁ × ∂z₁/∂W₁ = (ŷ - y) × W₂ × ReLU'(z₁) × x
∂L/∂b₁ = ∂L/∂z₁ × ∂z₁/∂b₁ = (ŷ - y) × W₂ × ReLU'(z₁) × 1
```

**关键洞察**：

```
∂L/∂a₁ 是连接两层梯度的桥梁！

输出层梯度 ∂L/∂z₂
    ↓
通过 W₂ 传到 ∂L/∂a₁
    ↓
通过 ReLU'(z₁) 传到 ∂L/∂z₁
    ↓
输入层梯度 ∂L/∂W₁
```

**反向传播就是"链式法则的系统应用"**：

```
从输出层开始，一层层往前算梯度：
∂L/∂W₂ → ∂L/∂a₁ → ∂L/∂W₁

每一步都复用前一步的计算结果！
```

## 5. 梯度消失和梯度爆炸

### 问题

当网络很深时，梯度可能在反向传播中**指数级减小或增大**。

```
梯度消失（Sigmoid）：

∂L/∂W₁ = ∂L/∂ŷ × ∂ŷ/∂aₙ × ... × ∂a₂/∂a₁ × ∂a₁/∂W₁

如果每层的梯度 < 1，连乘后会趋近于 0：
0.5 × 0.5 × 0.5 × ... = 0.5^n → 0

结果：前面的层几乎学不到东西！
```

```
梯度爆炸：

如果每层的梯度 > 1，连乘后会趋向无穷大：
2 × 2 × 2 × ... = 2^n → ∞

结果：参数更新太大，网络发散！
```

### 解决方案

```
1. 使用 ReLU 激活函数
   - z > 0 时梯度恒为 1，不会消失

2. 残差连接（ResNet）
   - 跳跃连接，让梯度直接传到前面

3. 批归一化（BatchNorm）
   - 稳定每层的输入分布

4. 梯度裁剪
   - 限制梯度的最大值，防止爆炸
```

## 6. 完整的训练循环

### 一个 epoch 的步骤

```
1. 前向传播：用当前参数计算预测
   ŷ = f(x; w, b)

2. 计算损失：预测和真实值的差距
   L = loss(ŷ, y)

3. 反向传播：计算所有参数的梯度
   ∂L/∂w, ∂L/∂b

4. 更新参数：w = w - 学习率 × 梯度
   w_new = w_old - η × ∂L/∂w

5. 重复 1-4，直到损失足够小
```

### 具体演示

```
任务：学习一个简单函数 y = 2x + 1

训练数据：
x = [1, 2, 3, 4, 5]
y = [3, 5, 7, 9, 11]

初始化：w = 0, b = 0, 学习率 = 0.01

第1轮：
  前向传播：ŷ = 0×x + 0 = [0, 0, 0, 0, 0]
  损失 = MSE = (1/5)×[(0-3)² + (0-5)² + (0-7)² + (0-9)² + (0-11)²]
                = (1/5)×[9 + 25 + 49 + 81 + 121]
                = 57
  
  反向传播：
    ∂L/∂w = (2/5) × Σ(ŷᵢ-yᵢ)×xᵢ
          = (2/5) × [(0-3)×1 + (0-5)×2 + (0-7)×3 + (0-9)×4 + (0-11)×5]
          = (2/5) × [-3 -10 -21 -36 -55]
          = (2/5) × (-125)
          = -50
    
    ∂L/∂b = (2/5) × Σ(ŷᵢ-yᵢ)
          = (2/5) × [-3 -5 -7 -9 -11]
          = (2/5) × (-35)
          = -14
  
  更新：
    w = 0 - 0.01×(-50) = 0.5
    b = 0 - 0.01×(-14) = 0.14

第2轮：
  前向传播：ŷ = 0.5×x + 0.14 = [0.64, 1.14, 1.64, 2.14, 2.64]
  损失 = MSE = 21.67
  
  继续更新...

...重复很多轮...

第100轮：
  w ≈ 1.95, b ≈ 0.85
  预测 ≈ [2.8, 4.75, 6.7, 8.65, 10.6]
  接近真实值 [3, 5, 7, 9, 11]！
```

## 7. 本节小结

| 概念 | 公式 | 为什么重要 |
|------|------|------------|
| 梯度 | ∂L/∂w | 告诉我们参数该往哪调 |
| 梯度下降 | w = w - η×∂L/∂w | 学习的核心算法 |
| 链式法则 | ∂L/∂w = ∂L/∂ŷ × ∂ŷ/∂w | 复合函数求导 |
| 反向传播 | 从输出到输入计算梯度 | 高效计算所有参数的梯度 |
| 梯度消失 | 梯度连乘趋近于 0 | 深层网络的挑战 |
