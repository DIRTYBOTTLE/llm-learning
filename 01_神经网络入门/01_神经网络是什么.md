# 1.1 神经网络是什么？

> 大模型的核心就是神经网络。理解神经网络，就是理解 AI 如何"思考"。

## 1. 从人脑说起

### 生物神经元是什么？

人的大脑由约 860 亿个神经元组成。每个神经元就是一个小小的"决策者"。

**当你碰到热水时发生了什么？**

```
热水 → [皮肤感受器] → [神经信号] → [大脑] → [判断: 烫!] → [缩手]

       树突           轴突         细胞体       轴突
      (接收)        (传递)        (处理)       (传递)
```

- **树突**：接收信号（比如"热水的温度"）
- **细胞体**：处理信号（判断"这个温度会不会烫伤"）
- **轴突**：输出信号（告诉手"快缩回来"）

### 人工神经元就是模仿这个过程

科学家想：能不能用数学公式模仿这个"决策过程"？

**答案是可以！** 人工神经元就是生物神经元的"数学简化版"：

```
生物神经元                        人工神经元
─────────────────────────────────────────────────────
热水的温度 ──→ 树突接收         输入 x₁ = 热水温度
过去的经历 ──→ 细胞体处理       权重 w₁ = 这个信息有多重要
缩手的决定 ──→ 轴突输出         输出 y = 最终决定
```

### 对比表：一一对应

| 生物神经元 | 人工神经元 | 例子（带伞决策） |
|------------|------------|------------------|
| 树突（接收信号） | 输入 x | 天空是否乌云密布？ |
| 信号强度 | 权重 w | 这个信息有多重要？ |
| 细胞体（处理） | 加权求和 + 偏置 | 把所有信息综合起来 |
| 激活阈值 | 激活函数 | 超过阈值就"激活" |
| 轴突（输出信号） | 输出 y | 决定：带伞！ |

## 2. 人工神经元的数学公式

### 单个神经元的计算

```
输入信号 × 重要性 + 基础判断 = 输出决定

数学公式：
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
  = wᵀx + b

y = f(z)

其中：
- x = [x₁, x₂, ..., xₙ]ᵀ：输入向量
- w = [w₁, w₂, ..., wₙ]ᵀ：权重向量
- b：偏置（bias）
- f()：激活函数
- y：输出
```

### 每个符号对应什么？

```
生物神经元          人工神经元          带伞例子
────────────────────────────────────────────
树突接收的信号  →   输入 x           天气信息
信号的强度    →   权重 w           信息的重要性
细胞体处理    →   加权求和         综合所有信息
激活阈值     →   偏置 b           基础判断门槛
轴突输出     →   输出 y           最终决定
```

### 用生活例子串起来

**场景：你的大脑决定要不要带伞**

```
你（生物神经元）的思考过程：

1. 看到天空乌云密布 → 树突接收信号
2. 想起天气预报说有雨 → 树突接收另一个信号
3. 记得上次没带伞被淋湿 → 树突接收记忆信号

4. 大脑处理（细胞体）：
   - 乌云很重要 → 信号强度 0.5
   - 天气预报比较准 → 信号强度 0.3
   - 上次经历很重要 → 信号强度 0.4

5. 综合判断：0.5 + 0.3 + 0.4 = 1.2

6. 超过阈值 → 输出：带伞！
```

**人工神经元做同样的事**：

```
输入：x = [乌云, 天气预报, 上次经历] = [1, 1, 1]
权重：w = [0.5, 0.3, 0.4]  （每个信息的重要性）
偏置：b = -0.5  （基础判断门槛）

计算：
z = wᵀx + b = 0.5×1 + 0.3×1 + 0.4×1 + (-0.5) = 0.7
y = sigmoid(0.7) ≈ 0.67 > 0.5 → 带伞！
```

## 3. 前向传播：从输入到输出

### 什么是前向传播？

**从输入到输出的计算过程，叫做"前向传播"**（Forward Propagation）。

```
输入 x → [线性变换] → [激活函数] → 输出 y

数学表示：
z = wᵀx + b     （线性变换）
y = f(z)         （激活）
```

### 多个神经元的情况

当有多个神经元时，用矩阵乘法一次性计算所有结果：

```
输入向量：x = [x₁, x₂, x₃]ᵀ

权重矩阵：W = | w₁₁  w₁₂  w₁₃ |   (第1个神经元的权重)
              | w₂₁  w₂₂  w₂₃ |   (第2个神经元的权重)

偏置向量：b = [b₁, b₂]ᵀ

计算：
z = Wx + b
a = f(z)    （逐元素激活）

结果：a = [a₁, a₂]ᵀ  (两个神经元的输出)
```

**这就是第0章学的矩阵乘法的应用！**

### 完整例子：判断要不要出去玩

**任务**：根据 3 个信息，判断今天要不要出去玩

```
输入信息：
- x₁：是否周末 (1=是，0=否)
- x₂：天气是否晴朗 (1=是，0=否)
- x₃：是否有朋友约 (1=是，0=否)

网络结构：
输入层(3个神经元) → 隐藏层(2个神经元) → 输出层(1个神经元)
```

**第一步：初始化参数**

```
隐藏层有 2 个神经元，每个神经元有 3 个权重（对应 3 个输入）

隐藏层神经元1 的权重：w₁ = [0.4, -0.3, -0.2]，偏置 b₁ = 0.1
隐藏层神经元2 的权重：w₂ = [0.3, 0.5, 0.1]，偏置 b₂ = -0.2

输出层神经元 的权重：w₃ = [0.6, 0.4]，偏置 b₃ = 0.05
```

**第二步：隐藏层计算**

```
输入：x = [1, 1, 0]  (周末，晴朗，没人约)

隐藏层神经元1：
z₁ = w₁ · x + b₁
   = 0.4×1 + (-0.3)×1 + (-0.2)×0 + 0.1
   = 0.4 - 0.3 + 0 + 0.1
   = 0.2

隐藏层神经元2：
z₂ = w₂ · x + b₂
   = 0.3×1 + 0.5×1 + 0.1×0 + (-0.2)
   = 0.3 + 0.5 + 0 - 0.2
   = 0.6

激活（用 ReLU）：
a₁ = ReLU(0.2) = 0.2  (因为 0.2 > 0)
a₂ = ReLU(0.6) = 0.6  (因为 0.6 > 0)

隐藏层输出：a = [0.2, 0.6]
```

**第三步：输出层计算**

```
输出层神经元：
z₃ = w₃ · a + b₃
   = 0.6×0.2 + 0.4×0.6 + 0.05
   = 0.12 + 0.24 + 0.05
   = 0.41

激活（用 sigmoid）：
y = sigmoid(0.41) ≈ 0.60
```

**第四步：得出结论**

```
输出 y = 0.60

解读：0.60 > 0.5，表示"可以出去玩"的概率是 60%

结论：可以出去玩！
```

**用矩阵表示（更简洁）**：

```
隐藏层：z₁ = W₁x + b₁
输出层：z₂ = W₂ᵀa₁ + b₂

其中：
W₁ = | 0.4  -0.3  -0.2 |   (两个神经元的权重，每行一个)
     | 0.3   0.5   0.1 |

b₁ = [0.1, -0.2]ᵀ

W₂ = [0.6, 0.4]ᵀ   (输出层权重)
b₂ = 0.05
```

## 4. 为什么网络能"学习"？

### 问题

上面的参数是随便设的。如果预测不准怎么办？

### 答案：调整参数

```
第1次预测：y = 0.60，但真实答案是"不去"
           → 预测错了！
           
第2次：调整权重，让预测更接近 0
       y = 0.45
       
第3次：再调整
       y = 0.35
       
...重复很多次...
       
最后：y ≈ 0.1 → 预测正确！
```

### 如何知道往哪个方向调整？

这就是**反向传播**和**梯度下降**要解决的问题（后面几节讲）。

## 5. 本节小结

| 概念 | 公式 | 为什么重要 |
|------|------|------------|
| 输入 | x | 看到的信息 |
| 权重 | w | 信息的重要性 |
| 偏置 | b | 基础判断门槛 |
| 线性变换 | z = wᵀx + b | 综合所有信息 |
| 前向传播 | y = f(wᵀx + b) | 从输入到输出的计算 |
