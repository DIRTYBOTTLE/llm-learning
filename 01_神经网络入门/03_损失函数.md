# 1.3 损失函数

> 损失函数告诉我们"预测准不准"。没有它，网络就不知道该往哪个方向学习。

## 1. 什么是损失函数？

### 定义

**损失函数**（Loss Function）衡量模型预测值和真实值之间的差距。

```
损失 = L(预测值, 真实值)

损失越小 → 预测越准
损失越大 → 预测越差
```

### 目标

**训练神经网络的目标就是最小化损失函数**。

```
找到一组参数 w*, b*，使得：

w*, b* = argmin L(y_pred, y_true)

其中：
- y_pred = f(x; w, b) 是模型预测
- y_true 是真实标签
```

## 2. 均方误差（MSE）- 回归任务

### 公式

```
MSE = (1/n) × Σᵢ(ŷᵢ - yᵢ)²

其中：
- n：样本数量
- ŷᵢ：第 i 个样本的预测值
- yᵢ：第 i 个样本的真实值
```

### 例子

```
预测：ŷ = [0.8, 0.5, 0.3]
真实：y = [0.2, 0.2, 0.2]

MSE = (1/3) × [(0.8-0.2)² + (0.5-0.2)² + (0.3-0.2)²]
    = (1/3) × [0.36 + 0.09 + 0.01]
    = (1/3) × 0.46
    = 0.1533
```

### 梯度

```
∂MSE/∂ŷᵢ = 2(ŷᵢ - yᵢ) / n

推导：
MSE = (1/n) × Σ(ŷᵢ - yᵢ)²

∂MSE/∂ŷᵢ = (1/n) × 2(ŷᵢ - yᵢ) × 1
          = 2(ŷᵢ - yᵢ) / n
```

### 适用场景

- 回归问题（预测连续值）
- 例如：房价预测、温度预测

## 3. 平均绝对误差（MAE）- 回归任务

### 公式

```
MAE = (1/n) × Σᵢ|ŷᵢ - yᵢ|
```

### 与 MSE 的对比

```
MSE：对大误差惩罚更重（因为平方）
MAE：对所有误差一视同仁

例子：
误差 = 0.1 → MSE = 0.01, MAE = 0.1
误差 = 1.0 → MSE = 1.00, MAE = 1.0

MSE 对大误差的惩罚是 MAE 的 10 倍！
```

### 梯度

```
∂MAE/∂ŷᵢ = sign(ŷᵢ - yᵢ) / n

其中 sign(x) = 1 if x > 0, -1 if x < 0, 0 if x = 0
```

## 4. 交叉熵损失（Cross Entropy）- 分类任务

### 二分类交叉熵

```
L = -[y × log(ŷ) + (1-y) × log(1-ŷ)]

其中：
- y：真实标签（0 或 1）
- ŷ：预测概率（0~1 之间）
```

**例子**：

```
真实标签：y = 1（是猫）
预测概率：ŷ = 0.9（90% 可能是猫）

L = -[1 × log(0.9) + 0 × log(0.1)]
  = -log(0.9)
  = 0.1054

如果预测不准：ŷ = 0.1
L = -[1 × log(0.1) + 0 × log(0.9)]
  = -log(0.1)
  = 2.3026  ← 损失更大！
```

**梯度**：

```
∂L/∂ŷ = -y/ŷ + (1-y)/(1-ŷ)

当 y=1 时：∂L/∂ŷ = -1/ŷ
当 y=0 时：∂L/∂ŷ = 1/(1-ŷ)
```

### 多分类交叉熵

```
L = -Σᵢ yᵢ × log(ŷᵢ)

其中：
- yᵢ：one-hot 编码的真实标签（只有一个是 1，其他是 0）
- ŷᵢ：softmax 输出的概率
```

**例子**：

```
真实标签：y = [0, 1, 0]（是第 2 类）
预测概率：ŷ = [0.1, 0.7, 0.2]

L = -[0×log(0.1) + 1×log(0.7) + 0×log(0.2)]
  = -log(0.7)
  = 0.3567
```

### 为什么用交叉熵而不是 MSE？

```
分类问题用交叉熵的原因：

1. 梯度更好：交叉熵的梯度在预测错误时更大
   - MSE：∂L/∂ŷ = 2(ŷ-y)
   - 交叉熵：∂L/∂ŷ = -y/ŷ

2. 概率意义：交叉熵衡量两个分布的差异
   - 当预测分布 = 真实分布时，交叉熵最小

3. 数值稳定：避免 MSE 在概率接近 0 或 1 时梯度消失
```

## 5. 交叉熵的数学推导

### 信息熵

```
信息熵衡量一个分布的不确定性：

H(p) = -Σ p(x) × log₂(p(x))

例子：
公平硬币：p = [0.5, 0.5]
H = -[0.5×log₂(0.5) + 0.5×log₂(0.5)]
  = -[0.5×(-1) + 0.5×(-1)]
  = 1 bit

不公平硬币：p = [0.9, 0.1]
H = -[0.9×log₂(0.9) + 0.1×log₂(0.1)]
  = -[0.9×(-0.152) + 0.1×(-3.322)]
  = 0.469 bits

越均匀 → 熵越大 → 不确定性越高
```

### 相对熵（KL 散度）

```
KL 散度衡量两个分布的差异：

KL(p||q) = Σ p(x) × log(p(x)/q(x))

性质：
- KL ≥ 0
- KL = 0 当且仅当 p = q
```

### 交叉熵与 KL 散度的关系

```
交叉熵 = 信息熵 + KL 散度

H(p, q) = H(p) + KL(p||H)

证明：
H(p, q) = -Σ p(x) × log(q(x))
        = -Σ p(x) × log(p(x)) + Σ p(x) × log(p(x)) - Σ p(x) × log(q(x))
        = H(p) + Σ p(x) × log(p(x)/q(x))
        = H(p) + KL(p||q)
```

### 最小化交叉熵 = 最小化 KL 散度

```
因为 H(p) 是常数（真实分布不变），所以：

min H(p, q) = min KL(p||q)

即：最小化交叉熵等价于让预测分布 q 接近真实分布 p
```

## 6. 损失函数选择指南

| 任务类型 | 损失函数 | 公式 |
|----------|----------|------|
| 回归 | MSE | (1/n)×Σ(ŷ-y)² |
| 回归 | MAE | (1/n)×Σ|ŷ-y| |
| 二分类 | 二分类交叉熵 | -[y×log(ŷ)+(1-y)×log(1-ŷ)] |
| 多分类 | 多分类交叉熵 | -Σyᵢ×log(ŷᵢ) |

## 7. 本节小结

| 概念 | 公式 | 为什么重要 |
|------|------|------------|
| 损失函数 | L(ŷ, y) | 衡量预测准不准 |
| MSE | (1/n)×Σ(ŷ-y)² | 回归任务 |
| 交叉熵 | -Σy×log(ŷ) | 分类任务 |
| KL 散度 | Σp×log(p/q) | 衡量分布差异 |
